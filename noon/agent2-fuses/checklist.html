After the referee (added 24 November, 06:54 UTC). Eleven findings. What the list had and had not caught:

  • Caught by the list, and still not enough. Question 48 had me break the program on purpose, and the README named the copies the tests let through. But I filed all of them under one explanation ("how far down the loops reach") without running each against the unbroken program. The referee ran one: it is wrong at 29 points of a grid I had already used. The question should have a second half: of each broken copy that passes, find an input where it differs from the true program, or say that you looked and found none.
  • Missed by the list, though the list has the question. Question 44 (who already knows) was asked and answered with three web searches.   • Missed by the list, and not in it. A budget that bounded each link of a chain and not the chain, so that the page could stall for minutes. My page test went only to places I had built the page around; the referee went to the place just beside them.
