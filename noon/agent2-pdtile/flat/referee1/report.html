Section 6, line by line

Facts 1 and 2 — correct. - A character of Z_{p^a} × Z_{q^b} has order p^a q^b exactly when it is nontrivial on both minimal subgroups K_p and K_q, so the condition is N ∈ (K_p-invariant) + (K_q-invariant). - On each coset of K_p × K_q that is N(i,j) = u(i) + w(j), which is the same as "row differences are constant across the coset". The converse holds because invariance is coset-local. - Exact check: both sides are linear in the weight vector, so I verified equality of kernels (inclusion in exact integers, plus a rank bound) for every d of the right shape at M = 12, 36, 72, 108, 144, 200, 225, 324, 400, with either prime in either role. - Literal check: all subsets of Z_12 and Z_18, and 180 random or structured sets per d at M = 36, 72, 144, 400, gave 0 disagreements, with both outcomes well represented.

Fact 3 — correct. A(X) = A′(X^q), and ζ ↦ ζ^q maps primitive d-th roots onto primitive d/gcd(d,q)-th roots. Verified as a kernel identity for all d | M at M = 36, 72, 144, 324, 400. For d = q it degenerates to "A′(1) = 0", which is correct but worth saying.

Fact 4 — correct, second clause loosely worded (see imprecise sentences).

Lemma A — every step follows. - Step 1: δ is independent of j, summing over j gives qδ = 0 by Fact 1, so N_{3,1} = p·N_{4,1} ∈ pZ. - Step 2: ε ∈ pZ and ε = q·η with η an integer, so ε ∈ pqZ since p ≠ q. If ε ≠ 0 then |ε| ≥ pq, giving q disjoint classes of at least pq elements each, so |A| ≥ pq² > p²q. This is the only place p < q is used. Then N_{2,1} ∈ p²Z and N_{2,2} ∈ pZ. - Step 3: the difference qθ lies in p²Z, hence θ ∈ p²Z and the difference lies in p²qZ. If nonzero, one class holds at least p²q = |A| elements, contradicting equal classes mod q. So N_{1,1} ∈ p³Z. - Step 4: the column sum is p², which is not a multiple of p³. - All six hypotheses are used.

The hypothesis p < q in Lemma A is unnecessary. Replace the counting bound in Step 2 as follows. - Fix j. On each coset of p²Z_{p³} the entries of N_{3,1}(·, j) are congruent mod pq, with minimum x_c ∈ pZ. - So the coset sum is p·x_c + pq·m_c with m_c ≥ 0, and m_c = 0 exactly when the coset is constant. - Summing and using Φ_q gives p² = p²k + pq·m, i.e. p = pk + qm. If m > 0 then p | m, so qm ≥ pq > p, which is impossible. Hence ε = 0 for any p ≠ q. - My CP-SAT model agrees for the reversed pairs (3,2) and (5,2): Lemma A is infeasible.

Lemma B — every step follows, and no ordering is needed. - N_{1,1} ∈ pZ ∩ qZ = pqZ, and e has total p. - If w is non-constant, the differences are nonzero integers, so one column is at least 1 everywhere and takes the whole total p. - If w is constant, q | p, which is impossible. - Translation preserves divisibility, B′ is a genuine set in Z_{p⁴q}, and Fact 3 gives Φ_p, Φ_{p²}, Φ_{p³}, Φ_q | B′. Then p³q | p²q is the contradiction. - CP-SAT agrees for (3,2) and (5,2).

Corollary — correct. - I transcribed the two tables from Final_version.tex lines 833–877 independently. Zero entries of f are at orders {p, q, p⁴, p³q, p⁴q, p²q², p³q²}; of g at {p², p³, q², pq, p²q, pq², p⁴q²}. - All other entries are strictly positive for p < q < p², so "exactly" is justified. The two lists partition the 14 divisors greater than 1. - For all 98 prime pairs with p < q < p² and p, q < 60, exact rational arithmetic confirms f̂ = p²q·f and ĝ = p²q·g; an FFT cross-check agrees for the four smallest. This eigenfunction property is what turns "c_m = 0" into "Φ_{M/m} divides", and the Corollary says so correctly. - Parts (i) and (ii) follow. Part (i) is in fact implied by (ii). - At M = 144 the two lists are the first two rows of the Section 5 table. My own LP gives D⁺ = 12 for each, and both are minimal.

Section 2

Prop 1 — correct. - (i): v̂ = (M/|A|²)·1_A∗1_{−A}, the supports of h and v meet only at 0, and Parseval with all terms nonnegative gives the bound. - (ii): averaging over units preserves all the conditions, and both directions check, including the constants. - (iii): Gauss's lemma. - "Minimal pattern" equivalence: correct.

Prop 2 — correct, with one definitional gap. - Case (b) does give (T1) and (T2) in the Coven–Meyerowitz sense for the integer set in {0,…,M−1}. From k(Z₀) | k(Z_A) | n = k(Z₀) we get k(Z_A) = n. Since the product of Φ_s(1) over all prime-power s with Φ_s | A(X) divides A(1), no prime power outside the divisors of M can occur. So S_A is the set of prime powers of Z₀, and closure gives (T2). - "Period dividing M": the complement B(X) = ∏ Φ_s(X^{t(s)}), over prime-power factors s of N = lcm(S_A) not in S_A, gives A ⊕ B = Z_N with N | M. I checked this by hand.

Prop 3, covering equations, class-size caps — correct. The cap uses that differences within a class mod D have the same order in Z_{M/D} as in Z_M, then [KLMS, Prop. 2.5] in Z_{M/D}.

Imprecise or overstated sentences

  1. (T1)/(T2) for a subset of Z_M is never defined. Case (c) of Prop 2 and the search clause use the Z_M-internal reading (k(Z_A) = n, closure among divisors of M). The bridge to the CM sense appears only in the parenthesis in case (b), yet "in case (c) there is nothing to prove" silently needs it too. Fix: one line stating that Z_M-sense (T1) forces S_A^{CM} ⊂ Div(M), so the two senses agree, independent of representatives.
  2. Fact 4, "the same holds counting all prime powers s with Φ_s | A". This is only meaningful for a fixed integer representative set; for s ∤ M it depends on representatives. It is true as a statement about A(X) ∈ Z[X].
  3. "(Coven–Meyerowitz, Theorem A)" for the period. The period comes from the proof (the explicit complement), not the statement, and not from the form quoted in [KLMS], which Section 7 says is the source.
  4. Lemma A, "Let p < q". The hypothesis is used but not needed (argument above). The Corollary needs p < q < p² anyway.
  5. Fact 3. The case d = q should be mentioned ("vanishes at 1", i.e. never for nonempty A′).
  6. "Decision procedure" / "Problem 1.1 … reduces to". Prop 2 is a sufficient test. A set violating only (T2) would still need a direct tiling check when |A| has three or more prime factors. This is harmless here since no violation was found.
  7. Lemma B, minor. u and w can be taken integer-valued, which the proof uses implicitly in "≥ 1"; the contradiction in the last line is left implicit.
