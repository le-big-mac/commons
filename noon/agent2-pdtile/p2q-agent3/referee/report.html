  1. Lemma 2(e), "differ by (Δu, Δw) with Δu ≠ 0 and Δw ≠ 0". This is asserted, not shown. - Δu = (c−c′) + (i−i′)p with |c−c′| < p and 0 < |i−i′| < t ≤ p. R. An observation the note misses. It is not an error, but it changes what the note's machine check is worth. For sets in Z_{p²q}, five of the seven Case-2 patterns are never a zero set at all, pd-tiling or not:

  • R1: pq, p² ∈ Z_A and p ∉ Z_A ⇒ q ∈ Z_A; indeed A is a union of cosets of the subgroup of order pq.
  • N_{1,1} = a + α_ρ + β_j ≤ p, because a cell has p elements.
  • Φ_{p²} makes every row sum a multiple of p, so every α_ρ ∈ pZ.
  • α ≢ 0 then forces some α_ρ = p, hence a = 0 and β ≡ 0.
  • R2: p, p²q ∈ Z_A ⇒ p² ∈ Z_A or q ∈ Z_A.
  • With 0/1 entries, each box in Lemma 3(b) is empty, full, α-only (total q·A_c, 1 ≤ A_c ≤ p−1) or β-only (total p·B_c, 1 ≤ B_c ≤ q−1).
  • Φ_p makes the totals equal, and q·A = p·B with A < p is impossible.
  • R3: pq, p²q ∈ Z_A and q ∉ Z_A ⇒ A = Z_{p²} × J, so p, p² ∈ Z_A.
  • Φ_{pq} on the column sums gives β^c = β for all c.
  • β ≢ 0 with 0/1 entries then gives a_c = 0 and α^c ≡ 0.

So {p², pq}, {p², pq, p²q}, {p, p²q}, {p, pq, p²q} and {pq, p²q} never occur; only {pq} and {p²q} do. By the same kind of argument the non-closed patterns {p, q, p²q} and {p², q, pq} never occur either. Consequences:

  • The second bullets of (X) and (Y) are correct but vacuous for sets. R1 and R2 could replace them, and Lemma 2(a), (b) would no longer be needed.
  • No enumeration of sets can exercise those bullets. In mine they have 0 instances at M = 12, 18, 20, 28.
  • Lemma 3(c)'s hypothesis is met only by 2, 9, 2, 2 sets at those moduli.
  • To test the arguments I used multisets, where Lemma 3 and the counting are equally valid and the patterns do occur. They hold there.
