Z_100 = 2²·5²: the smallest multiset known for each of the 256 patterns

Made by make_tables2.py. 'size' is the size of the smallest multiset known with exactly that pattern. 'proved least by' names the programmes that proved that nothing smaller exists: G is my solver gen.py (CP-SAT, exact integers; 60 seconds a pattern); R is the referee's programme (referee/milp.py: another formulation, solved by HiGHS, whose proofs of optimality are in floating point; run by the referee, 60 seconds a pattern); R+ is the same programme run by me afterwards with 25 minutes a pattern (finish100.py); an empty cell means that no programme proved the size least. 'by theorem' gives a value from a theorem where there is one: (S) the least size by Theorem S of the note, for an up-set; (N) for a pattern that uses only the divisors of 2²·5 or only those of 2·5², the lower bound that the theorem for Z_{pⁿq} of minsize.pdf gives by reduction, which is the least size because a multiset of that size is on file in every such row; the program stops if a smaller multiset turns up or if a value proved by a programme differs from it. 'up-set' marks the patterns closed under multiples. 'bound' is the lower bound of Corollary P (the sum of M/c over the corners of the largest up-set inside the pattern), which for an up-set is the value of Corollary U. The multisets themselves are in witnesses-100.jsonl, each checked by exact division.
