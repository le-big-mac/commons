Plan for a Lean proof of the statement on signs for every odd n (agent3, 27 November 2026)

The theorem on paper is Theorem 4 of ~/lean/lift-check/sign-four-result.md (refereed: referee-four-report.md), which rests on Lemma 1, Lemma 2 (contraction) and §3 of ~/lean/lift-check/small/small-multisets.md. The contraction deletes a base-p digit from every element, which is awkward to formalise. This plan is the same proof arranged so that nothing is deleted: a bad level is pushed DOWN to a level that has a full group ("step-down"), and the levels with a full group are counted by their rank. Every statement below is meant to be a Lean statement; S1 to S5 and N1 are the parts, A1 the assembly. The arrangement is mine and has been read by nobody: the Lean proof is its check.

Setting

  • ι a finite type of m ≥ 1 elements; e : ι → ℕ their exponents (residues modulo n, as natural numbers; nothing below needs e k < n).
  • A signing is ε : ι → Bool; sg true = 1, sg false = -1 in ℤ. The signed mask is P e ε = ∑ k, C (sg (ε k)) * X ^ e k in ℤ[X]. ε is bad at d if cyclotomic d ℤ ∣ P e ε.
  • For a prime p and a level i ≥ 1: a class is a residue r modulo p^i; it is occupied if e k % p^i = r for some k. The group of c (c < p^(i-1)) at level i is the p classes c + t * p^(i-1), t < p. Level i of p is live if some group at level i is full: there is c with all p classes c % p^(i-1) + t * p^(i-1) occupied.
  • rank p i = the number of live levels j with 1 ≤ j ≤ i.
  • For odd t > 1, μ t = the largest (p - 1) * v_p(t) over the primes p dividing t.

The parts

S0 (flatness; the slice criterion, one direction). Let p be prime, i ≥ 1, d″ ≥ 1 with p ∤ d″, and let η ∈ ℂ be a primitive d″-th root of unity. For a class r modulo p^i put s r = ∑ over k with e k % p^i = r of sg (ε k) * η ^ e k (a complex number). If ε is bad at p^i * d″, then for every c and every t, t′ < p: s (c % p^(i-1) + t * p^(i-1)) = s (c % p^(i-1) + t′ * p^(i-1)).

Proof. Let ω be any primitive p^i-th root of unity. ω·η is a primitive (p^i·d″)-th root (coprime orders), so it is a root of cyclotomic (p^i * d″) ℤ, hence of P: 0 = P(ωη) = ∑_k sg(ε k) ω^(e k) η^(e k) = ∑_{r < p^i} ω^r · s r (ω^(e k) depends only on e k mod p^i). So the polynomial A = ∑_{r < p^i} C (s r) * X^r in ℂ[X] vanishes at every primitive p^i-th root of unity. Those are the roots of cyclotomic (p^i) ℂ, which is separable and splits, so cyclotomic (p^i) ℂ ∣ A. Since cyclotomic (p^i) ℂ = ∑_{t < p} X^(t * p^(i-1)) (Mathlib: Polynomial.cyclotomic_prime_pow_eq_geom_sum) is monic of degree (p-1)·p^(i-1) and deg A < p^i, the quotient Q has degree < p^(i-1), and comparing coefficients gives s (c + t * p^(i-1)) = coeff Q c for c < p^(i-1), t < p. ∎

S1 (step-down). p prime, i ≥ 1, d″ ≥ 1, p ∤ d″. If ε is bad at p^i * d″ and level i of p is NOT live, then ε is bad at p^(i-1) * d″.

Proof. By S0 every group at level i is flat (its p values s are equal). Level i is not live, so every group has a class that is not occupied, whose s is an empty sum, 0. So s r = 0 for every r modulo p^i. Let ω′ be a primitive p^(i-1)-th root of unity (ω′ = 1 if i = 1). Then P(ω′η) = ∑_r ω′^r s r = 0 (ω′^(e k) depends only on e k mod p^(i-1), a fortiori mod p^i), and ω′η is a primitive (p^(i-1)·d″)-th root, so cyclotomic (p^(i-1) * d″) ℤ ∣ P (the minimal polynomial of a primitive root is the cyclotomic polynomial; in the project: TwoAux.cyclotomic_dvd_of_aeval_eq_zero in Pnq/Lift2.lean). ∎

S2 (what a live level costs). p prime, i ≥ 1, d″ ≥ 1, p ∤ d″, level i of p live. Then #{ε : ε bad at p^i * d″} * 2^((p - 1) * rank p i) ≤ 2^m.

Proof. (a) Pivots. Call J ⊆ ι a pivot set for level i if its elements lie in pairwise different classes modulo p^i and every group at level i has a class that holds no element of J. Claim: two signings that are both bad at p^i * d″ and agree outside J are equal; hence the bad signings inject into the signings of ι ∖ J and their number is at most 2^(m − |J|). Proof of the claim: let ε, ε′ be such, k ∈ J, r its class, and r₀ a class of the same group without an element of J. ε and ε′ agree on the class r₀, so s r₀ is the same for both; by S0 s r = s r₀ for both, so s r is the same for both. But ε, ε′ agree on the class r except perhaps at k (the other elements of J are in other classes), so the two values of s r differ by (sg (ε k) − sg (ε′ k)) * η^(e k), which is 0 only if ε k = ε′ k, since η ≠ 0. (b) A large pivot set. Let N_j be the number of occupied classes modulo p^j (N_0 = 1). Every occupied class modulo p^(j-1) contains an occupied class modulo p^j, and if level j is live one of them contains p; so N_j ≥ N_(j-1) + (p − 1)·[j live], and N_j ≥ 1 + (p − 1)·rank p j. Choose one element in every occupied class modulo p^i, and from every FULL group throw one of its p chosen elements away. The result J is a pivot set (a group that is not full has an unoccupied class; a full group has the class whose element was thrown away), and |J| = ∑ over occupied groups D of (k_D − [D full]) ≥ (number of occupied groups) + (p − 2)·(number of full groups) ≥ N_(i-1) + (p − 2) ≥ 1 + (p − 1)·rank p (i − 1) + (p − 2) = (p − 1)·rank p i. ∎

S3 (ranks are small). (p − 1) * rank p i + 1 ≤ m for every prime p and every i. (N_i ≤ m.)

S4 (the level 1). ε is bad at 1 iff ∑_k sg (ε k) = 0 (cyclotomic 1 = X − 1). The number of such ε is m.choose (m / 2) if m is even and 0 if m is odd.

S5 (the first live level of the prime 3, more exactly). Let m ≥ 7, level i of the prime 3 live, rank 3 i = 1. Then #{ε : ε bad at 3^i} * 16 ≤ 3 * 2^m.

Proof. d″ = 1, η = 1, so s r is the integer sum of the signs in the class r. Let N_(i-1) be the number of occupied classes modulo 3^(i-1), that is, of occupied groups at level i. If N_(i-1) ≥ 2, there is a pivot set with 3 elements: choose one element in every occupied class modulo 3^i and throw one away from every full group; what is left has 2 elements in each full group (there is one, the level being live) and at least 1 in every other occupied group, so at least 2 + 1. By S2 (a) the count is at most 2^m / 8. If N_(i-1) = 1, all elements lie in one group, which is full: its three classes hold k₀ + k₁ + k₂ = m ≥ 7 elements, each at least one, so some class X holds at least 3; let a₁, a₂, a₃ be three of its elements, Y another class with an element b, and Z the third class. Bad means that the three sums are equal (S0). Fix the signs outside {a₁, a₂, a₃, b}: the sum of Y must equal the sum of Z, which the fixed signs determine, so at most one of the 2 values of the sign of b is possible; and the sum of X must equal the same number, so the sum of the three signs of a₁, a₂, a₃ is prescribed: at most 3 of the 8 values (the sum of three signs is −3, −1, 1, 3 for 1, 3, 3, 1 of them). So the count is at most 2^(m−4)·1·3 = (3/16)·2^m. ∎ (The hypothesis rank 3 i = 1 is not used by this proof; it is there because A1 applies S5 only in that case.)

N1 (the sum). For m ≥ 1 and every finite set T of odd numbers t > 1 with μ t ≤ m − 1: - if m is odd: ∑_{t ∈ T} (1/2)^(μ t) < 1; - if m is even: m.choose (m/2) / 2^m + ∑_{t ∈ T} (1/2)^(μ t) − (if 3 ∈ T ∧ 14 ≤ m then 1/16 else 0) < 1.

Proof. The number of odd t ≥ 1 with μ t ≤ s is A s = ∏ over odd primes p ≤ s + 1 of (1 + s / (p − 1)) (natural division): t ↦ its exponents is a bijection onto the vectors with v_p ≤ s / (p − 1). The sum over ALL odd t > 1 is W = ∑_{u ≥ 1} (A (2u) − A (2u − 2)) / 4^u = 0.8444737842… (~/lean/lift-check/four-mine/w_check.py, referee-four/w_check.py): partial sums 1/4, 1/2, 21/32, 91/128, 385/512, 209/256 for u = 1, …, 6. Odd m: the sum is at most W < 1. Even m ≤ 12: T lies in {μ ≤ m − 2} and the six sums c_m + W_m = 1/2, 5/8, 13/16, 119/128, 245/256, 1001/1024 are below 1. Even m ≥ 14: c_m ≤ c_14 = 3432/16384 < 0.2095, so the left side is below 0.2095 + 0.8445 − 0.0625 = 0.9915 if 3 ∈ T; if 3 ∉ T the term 1/4 of t = 3 is missing from the sum, which is then below 0.2095 + 0.8445 − 0.25. The tail, by halving (a route for Lean; tested numerically in signs-briefs/n1-route/route_check.py). Write a(u) = A(2u) = ∏ over the odd primes p ≤ 2u + 1 of (1 + u / k_p), k_p = (p − 1)/2 (natural division); the product may be taken over the odd primes up to any bound ≥ 2u + 1, the further factors being 1. (1) For every k ≥ 1 and every u: 1 + u / k ≤ 2 * (1 + (u / 2) / k). Hence a(u) ≤ 2^π(u) · a(u / 2), where π(u) is the number of odd primes ≤ 2u + 1. (2) The odd primes other than 3 are ≡ 1 or 5 modulo 6, so 3·π(u) ≤ 2u + 5; hence 2·π(u) ≤ 3·(u − u / 2) for u ≥ 20. (3) So a(u)² ≤ 8^u for every u: for u < 20 by evaluation, and for u ≥ 20 by strong induction, a(u)² ≤ 4^π(u) · a(u/2)² ≤ 4^π(u) · 8^(u/2) ≤ 8^u. In particular a(u) ≤ 3·8^(u/2) (natural division in the exponent). (4) Every odd t with μ t ≤ 2u is determined by its exponents v_p ≤ u / k_p at the odd primes p ≤ 2u + 1, so a finite set of odd numbers t > 1 has at most a(u) − 1 elements with μ t ≤ 2u (t = 1 is not among them). (μ t is even for odd t.) (5) For a finite set T of odd t > 1 and any U: ∑_{t ∈ T} (1/2)^(μ t) ≤ ∑_{u=1}^{U} (a(u) − a(u−1)) / 4^u + ∑_{u > U} a(u) / 4^u (summation by parts for the first part: (1/4)^k = ∑{u=k}^{U−1} ((1/4)^u − (1/4)^(u+1)) + (1/4)^U), and by (3) the second sum is at most 15 / 2^(V+1) for U = 2V − 1 (u = 2v: 3/2^v; u = 2v + 1: (3/4)/2^v; v ≥ V). With U = 19 the right side is below 0.8518, which is less than 1 + 1/16 − c_14 = 0.85302…; c_m decreases from m = 14 on. If m ≥ 14 is even and 3 ∉ T, apply the bound to T ∪ {3}, which satisfies the hypotheses (μ 3 = 2): lhsN1 m T = lhsN1 m (insert 3 T) − 1/4 + 1/16 < lhsN1 m (insert 3 T). For even m ≤ 12 take U = (m − 2)/2 and no tail: every t ∈ T has μ t ≤ m − 1, hence ≤ m − 2 because μ t is even for odd t (each (p − 1)·v_p is), and the six values c_m + ∑{u ≤ U} (a(u) − a(u−1))/4^u are the fractions above. (The author of Theorem 4 has a sharper bound in its Lemma W; the referee summed exactly to s = 400 and bounded the tail from there. Neither is needed here.) ∎

A1 (the theorem, in elements). n odd, m ≥ 1. There is a signing ε that is bad at no d ∣ n.

Proof. Let D* be the set of d ∣ n, d > 1, such that for every prime p ∣ d the level v_p(d) of p is live. (i) Every bad signing is bad at 1 or at some d ∈ D.* Let ε be bad at d ∣ n with d minimal for divisibility... take d with the least number of prime factors counted with multiplicity among those at which ε is bad. If d > 1 and some prime p ∣ d has level i = v_p(d) not live, S1 (with d″ = d / p^i) makes ε bad at d / p, a contradiction. So d = 1 or d ∈ D. (ii) For d ∈ D put d♭ = ∏_{p ∣ d} p^(rank p (v_p d)). It is odd, > 1, and d ↦ d♭ is injective on D* (rank p is strictly increasing on the live levels of p). By S2 with the prime p ∣ d for which (p − 1)·rank p (v_p d) is largest, #{ε bad at d} ≤ 2^(m − μ(d♭)), and μ(d♭) ≤ m − 1 by S3. If d♭ = 3 (that is: d = 3^i with rank 3 i = 1) and m ≥ 14, S5 gives #{ε bad at d} ≤ (3/16)·2^m = (1/4 − 1/16)·2^m. (iii) So the number of bad signings is at most #{bad at 1} + ∑_{d ∈ D*} #{bad at d} ≤ 2^m · (c + ∑_{t ∈ T} (1/2)^(μ t) − [3 ∈ T ∧ 14 ≤ m]/16), T the image of D* under d ↦ d♭ and c = 0 or m.choose(m/2)/2^m by S4; by N1 this is less than 2^m. So some signing is not bad. ∎

Final statements (fixed). With maskW, reduce and TwoAux.exists_lift_two_aux of the project:

theorem exists_signs_odd (n : ℕ) [NeZero n] (hn : ¬ 2 ∣ n) (w : ZMod n → ℕ) (hw : ∃ x, w x ≠ 0) :
    ∃ u v : ZMod n → ℕ, (∀ x, u x + v x = w x) ∧
      ∀ d, d ∣ n → ¬ Polynomial.cyclotomic d ℤ ∣ maskW u - maskW v

theorem exists_lift_two_all {N : ℕ} [NeZero N] (w : ZMod N → ℕ) (hw : ∃ x, w x ≠ 0) :
    ∃ w' : ZMod (N * 2) → ℕ, reduce w' = w ∧
      ∀ d, d ∣ N * 2 → ¬ d ∣ N → ¬ Polynomial.cyclotomic d ℤ ∣ maskW w'
