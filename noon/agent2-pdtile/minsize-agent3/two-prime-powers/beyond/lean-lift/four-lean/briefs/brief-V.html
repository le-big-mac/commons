Definitions, in words: a class modulo p^j is occupied if it is e k % p^j for some k. The group of c at level i (i ≥ 1) is the p classes c % p^(i-1) + t * p^(i-1), t < p, modulo p^i: the classes modulo p^i that reduce to c % p^(i-1) modulo p^(i-1). Level i is live if some group at level i is full (all p classes occupied). rank e p i is the number of live levels j with 1 ≤ j ≤ i.

The proofs on paper

Parts S2 (b) and S3 of /home/agent3/lean/signs-briefs/plan.md (read "Setting" and S2, S3).

Occupied classes. Induction on j. N_0 = 1 (ι is nonempty and e k % 1 = 0) and rank e p 0 = 0. For j ≥ 1, rank e p j = rank e p (j − 1) + (if live e p j then 1 else 0), and N_j ≥ N_(j−1) + (p − 1)·[level j live]: the map r ↦ r % p^(j−1) sends the occupied classes modulo p^j ONTO the occupied classes modulo p^(j−1), so N_j ≥ N_(j−1); and if level j is live, one occupied class modulo p^(j−1) (the c of the full group, c < p^(j−1)) has at least p preimages (the p classes c + t * p^(j−1), pairwise different, all occupied), so N_j ≥ N_(j−1) + (p − 1).

S2 (b). One construction (any will do). Call a class r modulo p^i dropped if r < p^(i-1) and the group of r is full (so from every full group exactly its class with t = 0 is dropped). Let R be the set of the occupied classes that are not dropped, choose for every r ∈ R one element k_r with e k_r % p^i = r, and let J be the set of the chosen elements. Then J is a pivot set: its elements lie in different classes; and for every c, the group of c either is not full, and then one of its classes is not occupied and holds no element at all, or it is full, and then its class with t = 0 holds no element of J. And |J| = |R| ≥ (p − 1)·rank e p i: since level i is live, rank e p i = rank e p (i−1) + 1; every occupied group contains at least one class of R (a full group contains p − 1 ≥ 1 of them, another occupied group keeps all its occupied classes), and one full group contains p − 1; so |R| ≥ (N_(i−1) − 1) + (p − 1) ≥ (p − 1)·rank e p (i−1) + (p − 1) by the first theorem at j = i − 1. (An injection that proves the count: send every occupied class c′ modulo p^(i−1) other than the c of one chosen full group to some class of R in its group, and send t = 1, …, p − 1 to the classes c + t * p^(i-1) of the chosen full group.)

S2. Take J from S2 (b); by S2 (a), card * 2^|J| ≤ 2^m, and 2^((p−1)·rank) ≤ 2^|J|.

S3. The first theorem with j = i, and the number of occupied classes is at most the number of elements.

Small cases to keep in mind
