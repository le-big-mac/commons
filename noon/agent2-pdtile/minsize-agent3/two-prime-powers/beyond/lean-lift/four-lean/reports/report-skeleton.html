Definitions (SignDefs.lean, namespace Pnq, {ι : Type*} [Fintype ι]) — the plan's Setting, plus badSet, classSum, IsPivot, lhsN1:

def sg (b : Bool) : ℤ := if b then 1 else -1

noncomputable def P (e : ι → ℕ) (ε : ι → Bool) : Polynomial ℤ :=
  ∑ k, Polynomial.C (sg (ε k)) * Polynomial.X ^ e k

def BadAt (e : ι → ℕ) (ε : ι → Bool) (d : ℕ) : Prop :=
  Polynomial.cyclotomic d ℤ ∣ P e ε

open Classical in
noncomputable def badSet (e : ι → ℕ) (d : ℕ) : Finset (ι → Bool) :=
  Finset.univ.filter fun ε => BadAt e ε d

noncomputable def classSum (e : ι → ℕ) (ε : ι → Bool) (η : ℂ) (M r : ℕ) : ℂ :=
  ∑ k, if e k % M = r then (sg (ε k) : ℂ) * η ^ e k else 0

def live (e : ι → ℕ) (p i : ℕ) : Bool :=
  decide (∃ c, c < p ^ (i - 1) ∧ ∀ t, t < p → ∃ k, e k % p ^ i = c + t * p ^ (i - 1))

def rank (e : ι → ℕ) (p i : ℕ) : ℕ :=
  ((Finset.Icc 1 i).filter fun j => live e p j = true).card

def IsPivot (e : ι → ℕ) (p i : ℕ) (J : Finset ι) : Prop :=
  (∀ k ∈ J, ∀ k' ∈ J, e k % p ^ i = e k' % p ^ i → k = k') ∧
    ∀ c, ∃ t, t < p ∧ ∀ k ∈ J, e k % p ^ i ≠ c % p ^ (i - 1) + t * p ^ (i - 1)

def μ (t : ℕ) : ℕ :=
  t.primeFactors.sup fun p => (p - 1) * t.factorization p

def lhsN1 (m : ℕ) (T : Finset ℕ) : ℚ :=
  (if Even m then (m.choose (m / 2) : ℚ) / 2 ^ m else 0) + ∑ t ∈ T, (1 / 2 : ℚ) ^ μ t
    - (if Even m ∧ 3 ∈ T ∧ 14 ≤ m then 1 / 16 else 0)

3. Departures from the plan, and doubts

Corrections - S3 is false for m = 0 as the plan writes it ("for every prime p and every i"): the rank is 0 and 0 + 1 ≤ 0 fails. The Setting's m ≥ 1 is made explicit as [Nonempty ι] in S3, in rank_lt_card_image and in A1. - μ 11025 = 12, not 6: 11025 = 3²·5²·7², so μ = max(4, 8, 12). - cyclotomic 0 ℤ = 1, so every signing is bad at 0. No statement is touched: ¬ p ∣ d forces d ≠ 0 in S0, S1, S2, and ¬ 2 ∣ n forces n ≠ 0 in A1. A prover must not generalise to n = 0.

Choices where the plan left one - Slices in ℂ, not modulo cyclotomic d″ ℤ: S2's pivot step needs only η ≠ 0, S5 takes η = 1, and the project's tools (Complex.isPrimitiveRoot_exp, TwoAux.cyclotomic_dvd_of_aeval_eq_zero) are in ℂ. - Counts as (badSet e d).card, a Finset built with classical decidability. No statement mentions Finset.univ : Finset (ι → Bool); 2^m is written 2 ^ Fintype.card ι. So no DecidableEq ι instance can clash; provers should go through mem_badSet and open with classical. - N1 in ℚ, so the left side can be #eval-ed and A1 only casts natural numbers. A prover who wants exp can cast to ℝ inside the proof.

Changes of form - live is a Bool (no new instance allowed), with c < p^(i−1) and class c + t * p^(i-1) instead of the plan's arbitrary c and c % p^(i-1) + …. These are equivalent for p ≥ 1. live e p 0 = false for p ≥ 2, so hi in S2 is redundant (kept, as in the plan) and S5 needs none. - N1 is one statement over the definition lhsN1. I put Even m into the condition of the −1/16 term so that for odd m it is exactly the plan's bare sum. The hypothesis reads μ t + 1 ≤ m (no natural subtraction) and ¬ 2 ∣ t (the form the final statement uses for n). - S2 is split into (a) card_badSet_mul_two_pow_card_le and (b) exists_isPivot, with IsPivot as a definition; S5's first case reuses (a) with a 3-element pivot set. The N_j inequality is fixed once as rank_lt_card_image, for S2 (b) at j = i − 1 and S3 at j = i. - S4 is two statements (the iff and the count). - S5 is stated for d = 3^i (d″ = 1 dropped); A1 has to rewrite its d in that form. - Finals: Lift.reduce where the plan writes reduce; otherwise the plan's binders and conclusions. The third is Lift.sizes_eq_two word for word without p, q, k, a, b.

Not fixed - A1 is a single statement. D* and d♭ are not fixed as definitions; its prover will want them as computable ones (n.divisors.filter …, ∏ p ∈ d.primeFactors, p ^ rank e p (d.factorization p)).

Usability, thought through on paper only - A1 gets from S2 a natural-number inequality for d = p^i · (d / p^i), via Nat.ordProj_mul_ordCompl_eq_self and Nat.not_dvd_ordCompl. - N1's hypothesis on T = image of D* under d♭ comes from n odd, d > 1 with live levels, and S3 through Finset.sup_le. - The −1/16 term comes from S5 at the one d with d♭ = 3.

Observations (statements kept as the plan has them) - S5's hypothesis rank e 3 i = 1 is not needed on paper; m ≥ 7 is not sharp, but some bound is needed (m = 3, e = 0, 1, 2 gives 2/8; m = 5 with classes of sizes 3, 1, 1 gives exactly 3/16). - S2 also holds without "live" (by S1); the sweep printed no counterexample.
