The two statements (fixed; they are in your file with sorry)

  • Pnq.card_signedSum_eq_le_real: a : ι → ℝ with every a i ≠ 0, v : ℝ. The signings ε : ι → Bool with ∑ i, (sg (ε i) : ℝ) * a i = v number at most (Fintype.card ι).choose (Fintype.card ι / 2).
  • Pnq.card_signedSum_eq_le_complex: the same for a : ι → ℂ, v : ℂ.

A proof on paper (Erdős 1945, through Sperner's theorem)

Real case. Let S = {i | 0 < a i}. To a signing ε attach the set A(ε) = {i | ε i = true ↔ 0 < a i} (the elements whose signed term sg (ε i) * a i is positive). Then ∑ i, sg (ε i) * a i = ∑_{i ∈ A(ε)} |a i| − ∑_{i ∉ A(ε)} |a i| = 2 ∑_{i ∈ A(ε)} |a i| − ∑_i |a i|, and ε ↦ A(ε) is a bijection from signings to subsets of ι. If A(ε) ⊊ A(ε′) the second sum is strictly larger (every |a i| > 0), so the sets A(ε) of the signings with one value v form an antichain in Finset ι, and by Sperner's theorem (IsAntichain.sperner) there are at most (Fintype.card ι).choose (Fintype.card ι / 2) of them. Mind: IsAntichain.sperner is stated for a Finset (Finset α) with [Fintype α]; ε ↦ A(ε) is injective, so Finset.card_image_of_injective (or Finset.card_le_card_of_injOn) carries the count over.

Complex case. Find a real-linear f : ℂ → ℝ with f (a i) ≠ 0 for every i, and apply the real case to f ∘ a and f v: a signing with ∑ sg (ε i) * a i = v has ∑ sg (ε i) * f (a i) = f v (the signs are integers, so f (sg (ε i) * a i) = sg (ε i) * f (a i)), so the complex set is contained in the real one. One way to find f: f z = (z * (1 + t * I)).re = z.re − t * z.im for a real t; for a given a i ≠ 0 at most one t makes a i.re − t * a i.im = 0 (if a i.im = 0 then a i.re ≠ 0 and none does; otherwise t = a i.re / a i.im), so the bad t form a finite set, and ℝ is infinite (Set.Finite.exists_not_mem, Infinite.exists_not_mem_finset, or take t larger than every bad one). Any other correct route will do.
