The mathematics

r is a prime, N ≥ 1, M = N·r. reduce w' is the multiset on ZMod N of the residues modulo N of the elements of a multiset w' on ZMod M.

sum_reduce. Each y is counted once, at x = y mod N.

cyclotomic_dvd_reduce_iff. Two routes. (i) Polynomials: maskW (reduce w') − maskW w' is divisible by X^N − 1 (because x.val = y.val % N when x is the residue of y, and X^(y.val) − X^(y.val % N) is divisible by X^N − 1), and Φ_d ∣ X^N − 1 for d ∣ N, N ≠ 0. (ii) Characters: a frequency ξ' : ZMod M of order d ∣ N is r·ξ for a frequency ξ : ZMod N of order d, and stdAddChar (ξ' * y) depends on y mod N only; then use zeroAtW_iff_cyclotomic_dvd on both sides. Route (i) is probably shorter.

exists_lift (the lemma; r odd). Write N = r^k·N' with r ∤ N', so M = r^(k+1)·N'. For y ∈ ZMod M put β(y) = y.val % r^(k+1), a number in [0, r^(k+1)).

Key lemma. Let w' be a multiset on ZMod M such that (1) every y with w' y ≠ 0 has β(y) < (r − 1)·r^k, and (2) there is a number b such that exactly one y with w' y ≠ 0 has β(y) = b. Then no Φ_d with d ∣ M, d ∤ N divides maskW w'.

Proof. A divisor of M that does not divide N is d = d'·r^(k+1) with d' ∣ N'. Φ_d ∣ maskW w' means that the mask vanishes at every primitive d-th root of unity ζ (in the project: hatW w' ξ = 0 for every ξ with Pqr.ord ξ = d). By the Chinese remainder theorem ζ^y = ω^(y mod N')·η^(β(y)), where ω is a root of unity of order d' and η one of order r^(k+1), and every pair (ω of order d', η of order r^(k+1)) comes from a primitive d-th root ζ. Fix ω. The polynomial ℓ(Y) = ∑_b g_b·Y^b, with g_b = ∑_{y : β(y) = b} w'(y)·ω^(y mod N'), has degree < (r − 1)·r^k by (1), and ℓ(η) = 0 for all (r − 1)·r^k primitive r^(k+1)-th roots η. A polynomial with more roots than its degree is zero, so every g_b = 0. But by (2) one g_b is a single term w'(y)·ω^(…), which is not 0. ∎

The lift. Each x ∈ ZMod N has r lifts to ZMod M (the y with residue x), and their values of β are (x.val % r^k) + r^k·t for t = 0, …, r − 1, each once. Lift every element of w to its lift with t = 0 (β < r^k), except one single element (one unit of multiplicity at one point x₀ with w x₀ ≠ 0), which goes to its lift with t = 1. Then (1) holds because β < 2·r^k ≤ (r − 1)·r^k for r ≥ 3, and (2) holds with b = (x₀.val % r^k) + r^k: the only element with β in [r^k, 2r^k) is the one that was moved. And reduce w' = w by construction.

In Lean the Chinese remainder theorem is the delicate part. Things that may help: ZMod.chineseRemainder, Nat.chineseRemainder, ZMod.castHom, ZMod.natCast_self_eq_zero, ZMod.val_natCast; for the splitting of the character, 1/M = u/N' + v/r^(k+1) for integers u, v with u·r^(k+1) + v·N' = 1 (Bézout, Nat.Coprime), so that stdAddChar (ξ * y) on ZMod M is a product of a factor that depends on y.val % N' and a factor that depends on y.val % r^(k+1); for the count of roots, Polynomial.card_roots', Polynomial.eq_zero_of_natDegree_lt_card_of_eval_eq_zero (or its Finset forms) and IsPrimitiveRoot. You may prefer to avoid N' altogether where you can: a frequency ξ of ZMod M has order d not dividing N exactly when r^(k+1) divides its order; and the frequencies ξ·(1 + N'·j)-like families, or ξ + (M / r^(k+1))·j, run over the η with ω fixed. Choose whatever formulation of the key lemma is easiest to prove; only the fixed statements matter. If the general k is heavy, note that nothing in the fixed statements mentions k or N': any construction of w' with reduce w' = w and no new divisor will do.

sizes_eq. From the three statements above. (⊆) For w' with pattern P on ZMod M, reduce w' has the same size, and for d ∣ N, d ≠ 1: Φ_d ∣ maskW (reduce w') ↔ Φ_d ∣ maskW w' ↔ d ∈ P (d ∣ N gives d ∣ N * r). (⊇) For a nonempty w with pattern P on ZMod N, take the lift w': same size (sum_reduce); for d ∣ N * r, d ≠ 1: if d ∣ N use cyclotomic_dvd_reduce_iff; if not, Φ_d ∤ maskW w' and d ∉ P because P holds divisors of N only.

The three theorems of Pnq/LiftMin.lean. Each is IsLeast of a set on ZMod (p ^ n * q * r); the corresponding theorem of Pnq/MinGroup.lean is IsLeast of a set on ZMod (p ^ n * q) with the same least value. Membership: take the w that the old theorem gives (it is nonempty: in the first and third theorems because some Φ does not divide its mask, and the mask of the empty multiset is 0; in the second because 0 < s), lift it, and check the conditions with cyclotomic_dvd_reduce_iff (levelsEW w = Es unfolds to: for ℓ ∈ Finset.Icc 1 n, Φ_{p^ℓ} ∣ maskW w ↔ ℓ ∈ Es; note p ^ ℓ ∣ p ^ n * q and p ^ ℓ * q ∣ p ^ n * q for ℓ ≤ n). Lower bound: for w' in the new set, reduce w' is in the old set and has the same size. Here N = p ^ n * q; check which NeZero instance Lean finds for it, and that ZMod (p ^ n * q * r) is ZMod (N * r) on the nose.

Practical advice

That way a gap, if one remains, is small and named.
