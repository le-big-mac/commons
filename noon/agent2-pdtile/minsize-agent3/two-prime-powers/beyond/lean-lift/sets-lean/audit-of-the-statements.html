Verdict

  • All five statements say what is meant, and I found none false, vacuous or weaker than the paper's claim. The differences from the paper are differences of form; each is listed below with the reason it does not matter.
  • Every test agrees with them; there is no disagreement anywhere. exists_set_lift: 3,250,561 multisets over 94 triples (N, r, j), r = 3 … 13, groups up to Z_490: a set with exactly the required divisors exists for every one. set_sizes_iff_mul: complete censuses of sets on 40 groups Z_6 … Z_150 against censuses of multisets: 2,964 pairs (size, pattern) in the claimed range over 109 pairs (p^n q, s), no mismatch. The three least-size statements: 437 instances with the hypothesis hm, least size of a set found by complete census = Lean's value in all 437.
  • Taken together they give the paper's Proposition and Corollary as worded. The Proposition is exists_set_lift; "as many elements" is not written in the Lean statement but follows from the fibre counts (I derived the paper's wording in Lean, paper_setlift in L3_semantics.lean). The Corollary is the three minsize_…_set (every D is one instance of exactly one of them; that is by the case distinction of the earlier audit, I did not derive a single statement with D in Lean); set_sizes_iff_mul is the stronger fact behind it.
  • The excluded cases are rightly excluded. For r = 2 exists_set_lift and set_sizes_iff_mul are false (smallest examples below); with every multiplicity equal to r^j the conclusion fails in all 21,722 cases tried.
  • Remarks, none a defect: the bound t < r^j is far from sharp; 0 < t is redundant in two places; hr was not found to be needed for the three least-size statements (it is needed for the other two); hpq is not needed for the truth of set_sizes_iff_mul as far as tested.
  • The audit broke the working rules in small ways (one moment with three processes; four sub-second Python calls without the memory wrapper). Details in section 6.

1. What each statement says, and how it differs from what is meant

Common to all five (L1_print.out: default and fully explicit prints; L2_meta.out: every constant with its module, every instance argument, a structural hash of each type):

  • A multiset on Z_M is w : ZMod M → ℕ; a set is A : Finset (ZMod M); indW A is 1 on A and 0 off it; maskW w = ∑ a, C (w a : ℤ) * X ^ a.val, exponents in [0, M). Divisibility is in ℤ[X] by Mathlib's Polynomial.cyclotomic d ℤ.
  • Instances Lean found. NeZero (N * r ^ j) is instNeZeroNatHMul N (r ^ j) inst (Nat.instNeZeroHPow r j (NeZero.of_gt' … (Nat.Prime.one_lt' r inst_1))). NeZero (p ^ n * q * s) is instNeZeroNatHMul (p ^ n * q) s (Pnq.instNeZeroNatHMulHPow_pnq p q n) inst_3. All NeZero and Fact arguments are proofs of propositions, so which instance was found cannot change a meaning (checked by rfl). Instances that carry data: ZMod.fintype (the sum on the right of set_sizes_iff_mul), ZMod.decidableEq (the filter of exists_set_lift, and inside indW), ZMod.commRing/ZMod.charP N (inside castHom). The order in IsLeast is instLENat. Besides Lean core and Mathlib the five types use only Pnq.maskW, Pnq.indW, Pnq.minU, Pnq.minB, Pnq.instNeZeroNatHMulHPow_pnq.
  • N * r ^ j is N * (r ^ j), p ^ n * q * s is (p ^ n * q) * s (rfl). ∀ d, d ∣ (order) → … ranges over all natural d, but 0 divides none of the orders (proved), so d is a positive divisor.
  • In this copy all five depend on sorryAx, as they should; the finished theorems they will rest on (sizes_eq_mul, the three minsize_…_mul, exists_lift, exists_lift_two) show only propext, Classical.choice, Quot.sound.
  • Neither file contains notation, macro, syntax, attribute, @[…], local, scoped, set_option, axiom, instance, native_decide, implemented_by, unsafe, opaque.

1. exists_set_lift. For N ≠ 0 and r prime (both implicit, instance arguments), r ≠ 2, any j, and any w : ZMod N → ℕ with hle : ∀ x, w x ≤ r ^ j and hne : ∃ x, w x ≠ 0 ∧ w x ≠ r ^ j: there is A : Finset (ZMod (N * r ^ j)) such that (i) for every x in Z_N the number of y ∈ A with ZMod.castHom (Nat.dvd_mul_right N (r ^ j)) (ZMod N) y = x is w x, and (ii) for every d dividing N·r^j: Φ_d ∣ maskW (indW A) ⇔ (d ∣ N and Φ_d ∣ maskW w). The printed form confirms the bracketing … ↔ (d ∣ N ∧ …).

  • The reduction modulo N: the map is @ZMod.castHom (N * r ^ j) N _ (ZMod N) _ (ZMod.charP N); I proved in Lean that its value has val = y.val % N and that castHom y = x ⇔ y.val % N = x.val (val_castHom, castHom_eq_iff), and that the fibre count is the sum that defines Pnq.Lift.reduce applied to indW A, with r^j in place of r (fibre_card_eq_sum). Lean's #eval of the fibre counts of six concrete sets (N = 1 … 6) agrees with "number of elements y with y mod N = x" (L5_eval.out).
  • Differences from the paper's Proposition: 1. "with as many elements as A" is not in the Lean statement. It follows from (i): A.card = ∑ x, w x (card_eq_sum_of_fibres, proved). paper_setlift in L3 is the paper's wording, card and fibres by val % N included, derived from exists_set_lift (it compiles; its only non-standard axiom is the sorry of this copy). 2. j ≥ 1 is not a hypothesis. For j = 0, hle and hne contradict each other (proved), so nothing is claimed. 3. "nonempty … and not every element has multiplicity r^j" is the single hypothesis hne, which implies "nonempty"; together with hle it is equivalent to the paper's three conditions, "element" being read as "element of the multiset" (paper_hyp_iff, proved; the sentence after the Proposition shows that this reading is the intended one). 4. d = 1 is included, as in the paper ("every divisor d"). That clause says only "A is empty iff w is", which already follows from (i) (clause_one_of_fibres, proved); with hne both are nonempty. 5. The empty multiset is excluded by hne; the empty set cannot be the witness.

2. set_sizes_iff_mul. For natural p, q, n, s, r, j with p, q, r prime and s ≠ 0, with p ≠ q, r ≠ 2, r ^ j ∣ s, a finite set P of naturals all dividing p^n q, and t < r^j: (there is a set A in Z_{p^n q s} with A.card = t, 0 < t, and for every d ∣ p^n q s, d ≠ 1: Φ_d ∣ maskW (indW A) ⇔ d ∈ P) if and only if (there is a multiset w on Z_{p^n q} with ∑ x, w x = t, 0 < t, and for every d ∣ p^n q, d ≠ 1: Φ_d ∣ maskW w ⇔ d ∈ P).

  • This is what the brief says is meant. It is not a statement of the paper; it is the fact behind the Corollary, for every size below r^j and not only the least one.
  • "Pattern exactly P" on the big group is among all divisors d ≠ 1 of p^n q s, as it must be. d = 1 is skipped on both sides; P may contain 1, which changes nothing. 0 < t keeps the empty multiset out on the right (needed: for t = 0 the right side would hold for P = all divisors and the left would not); on the left it is redundant.
  • j = 0 is allowed: then t = 0 and both sides are false. n = 0, p = 2, q = 2, r = p, r = q, and any further factors of s (2, p, q, r, other primes) are allowed; all of these are instantiated in L3 and occur in the tests.
  • It says less than the paper's proof gives (there the set reduces to the multiset); the Corollary does not need more.

3–5. minsize_unbalanced_set, minsize_balanced_all_set, minsize_balanced_set. Same p, q, n, s, r, j and the hypotheses hpq, hr, hs : r ^ j ∣ s; Es, Fs ⊆ Finset.Icc 1 n (in the third, a0 with 1 ≤ a0 ≤ n, every level below a0 in Fs, a0 ∉ Fs); and hm : V < r ^ j where V is minU p q Es Fs, q * p ^ Es.card, minB p q Es Fs a0. Conclusion IsLeast S V: V ∈ S and V ≤ every member of S, where S is the set of the numbers A.card of the sets A in Z_{p^n q s} with: [¬] Φ_q ∣ mask; for ℓ = 1..n, Φ_{p^ℓ} ∣ mask ⇔ ℓ ∈ Es; for ℓ = 1..n, Φ_{p^ℓ q} ∣ mask ⇔ ℓ ∈ Fs (in the second: Φ_{p^ℓ q} ∣ mask for every ℓ, and 0 < t); and no Φ_d ∣ mask for d ∣ p^n q s, d ∤ p^n q.

  • As text they are the three audited minsize_…_mul statements with ∃ w : ZMod (…) → ℕ, ∑ a, w a = t replaced by ∃ A : Finset (ZMod (…)), A.card = t, maskW w by maskW (indW A), and the hypotheses hr, hs, hm added; nothing else differs (t5_textdiff.out: equal up to white space after exactly these replacements).
  • Against the Corollary: every set D of divisors > 1 of p^n q is one instance of exactly one of the three (as in the earlier audit of the _mul statements); the four clauses say "exactly D among all divisors > 1 of p^n q s"; "the least number of elements of a set" is IsLeast; "r^j > m" is hm; "s divisible by r^j" is hs.
  • For j = 0, hm cannot hold (the values are ≥ 1; minU_pos, minB_pos proved), so nothing is claimed. 0 < t in the second is redundant here (s > 1 is forced, and then the last clause excludes the empty set). The third has no instance for n = 0, as before; the second covers that case.
  • In L3 I derived from minsize_unbalanced_set (p = 2, q = 3, n = 1, s = 9, r = 3, j = 2, Es = ∅, Fs = {1}) two facts in my own words: a set in Z_54 with Φ_6 and none of Φ_2, Φ_3, Φ_9, Φ_18, Φ_27, Φ_54 has at least 5 elements, and one with exactly 5 exists (use_54_lower, use_54_attained). The census of Z_54 confirms both.

3. Vacuity and strength

  • No hypothesis is contradictory (for j ≥ 1): each theorem is instantiated in L3 (11 examples: N = 1 and 6; a concrete w; r = p, r = q, p = 2, q = 2, n = 0, s = 7, 9, 18, 25, 30, 45, 50; all three least-size statements, the third with V = 18 < 25).
  • No conclusion is trivially satisfiable: the plain lift fails for 145,008 of the w; 2,071 of the 2,964 (t, P) have both sides false and 893 both true; the least sizes run from 1 to 7 (to 18 with the larger-V test).
  • hr: needed in exists_set_lift and in set_sizes_iff_mul (examples above). For the three least-size statements I found no counterexample with r = 2 (162 instances with V below the power of 2 in s: 161 equal, 1 open); the paper's Z_24 example has V = 18 above every power of 2 I could reach.
  • hle: needed (a fibre has r^j elements). hne: needed (all 21,722 excluded cases fail).
  • hs: needed (p = 3, q = 2, n = 0, s = 3, r^j = 9, P = ∅, t = 6: a multiset of 6 elements on Z_2 without Φ_2 exists; the only 6-element subset of Z_6 is Z_6).
  • ht: needed in some form (above); not sharp. hm: needed in some form (drop it and take j = 0, s = 2: the Z_24 example); not sharp.
  • hP: needed (M = 2, s = 3, P = {3}, t = 1: the right side holds, the left does not: a singleton has no Φ_3).
  • [NeZero s]: says s ≥ 1 and makes the group finite. hpq: not needed for the truth of set_sizes_iff_mul in the control above; the paper has it, and the least-size rule needs it.
  • Nothing the paper claims is excluded: r = p, r = q, p = 2, q = 2, n = 0, s with any further factors are all inside the Lean statements.
  • Less than the paper only in remarks that the paper does not present as proved in Lean: "the condition cannot be dropped", "the bound r^j > m is crude" with what follows it, and the paragraph on the prime 2. My tests agree with each of them where they reach.

4. Other things worth knowing before trusting "proved in Lean"

  1. Pnq/SetAll.lean imports Pnq/SetLift.lean: the four theorems of SetAll will show sorryAx in #print axioms until exists_set_lift is proved in the same project. Check all five there, together.
  2. Fingerprints of the five types as elaborated in the skeleton copy (L2_meta.out): exists_set_lift 3988049613, set_sizes_iff_mul 2326310993, minsize_unbalanced_set 3256317079, minsize_balanced_all_set 1534554288, minsize_balanced_set 3668803384 (and of maskW, indW, minU, minB, xOf, gOf). L2_meta.lean run in the finished project should print the same lines; that compares the statements as Lean has them, not as text, and would catch an added instance that changed an implicit argument. I did not run it there.
  3. The last paragraph of the subsection says the Proposition, the Corollary and the remarks on the prime 2 "are not formalised". When that sentence is changed, only the Proposition and the Corollary will be in Lean; the remarks on the prime 2 and on the crude bound stay outside.
  4. I read the paper's proof of the Proposition as a check on truth and found no gap; its recipe, carried out literally (slots, the element x_1, both cases), gave a correct set for all 3,250,561 multisets.
  5. The "if" half of set_sizes_iff_mul cannot be had from sizes_eq_mul alone: the proof must keep track of the set through the later lifts ("a lift of a set is a set"), which exists_lift allows (reduce w' = w). That is the provers' business; I mention it because that half rests on the Proposition (the "only if" half is immediate: a set is a multiset, set_is_multiset in L3, then sizes_eq_mul).

5. What I did not check

  • The proofs. Not asked.
  • Sizes and groups beyond the bounds in the table. In particular: for 17 pairs (M, s) the census covers only part of the claimed sizes (for example Z_54 = Z_{2·27}: t ≤ 9 of t ≤ 26; Z_150 = Z_{6·25}: t ≤ 6 of t ≤ 24); the lift test covers the "if" half there for the pairs it includes, and the "only if" half is reduction modulo M.
  • The lower bound of the least-size statements by census of sets only for V ≤ 7; for V = 8 … 18 only that V is attained; for larger V nothing new (it rests on the multiset theorems, audited before).
  • r ≥ 11 only with j = 1; j ≥ 3 only for r = 3, 5 and N ≤ 8; N above 60; primes p, q above 13; n ≥ 4.
  • For r = 2 with j = 1 the lift existed in every case tried (N ≤ 10); I did not look further, and I have no counterexample to the three least-size statements with r = 2.
  • The base theorems on Z_{p^n q}, the rule minU, minB itself, and sizes_eq_mul, beyond the agreement above (they were audited before). Mathlib's Polynomial.cyclotomic is taken to be the cyclotomic polynomial.
  • No pp.all print, no independent kernel re-check, nothing run in the provers' copies or in the finished project.

6. How the audit was run

  • Python through ~/bin/cap2g.sh, Lean through lean1.sh; no program hit the 2 GB cap (largest resident size seen: 152 MB). No network, nothing posted, nothing left running. No file under Pnq/, Pqr/, P2q2/, .lake/ of my copy was changed (the only files newer than the start of the audit are my L1–L5); nothing was changed in the skeleton or the paper. No lake build, update, clean or cache.
  • Departures from the rules: (a) once three processes ran together: a 5-second Lean job (L5_eval.lean) was started while the census batch and the set-lift batch were both running; (b) four sub-second Python calls were made without the wrapper (three text edits of my own files at the start, one stray print); (c) ps, tail, grep and two waiting loops ran beside two running jobs.
  • Longest single computation: 252 s (second half of the census of Z_90 up to 8 elements; the first half 190 s). The batches ran one process at a time: censuses about 17 minutes of computing in all (79 runs), set-lift tests about 10 (123 runs, the longest 41 s), lifts to sets on larger groups about 2.5 (50 runs).
