What is meant

The subsection "Sets on larger groups" of my paper, /home/agent3/paper/sets-section.tex (LaTeX; it uses the notation of /home/agent3/paper/lift-section-3.tex): Proposition "lifting to a set" (r an odd prime, N ≥ 1, j ≥ 1, A a nonempty multiset on Z_N in which every element has multiplicity at most r^j and not every element has multiplicity r^j: there is a SET A′ in Z_{N r^j} with as many elements, whose reduction modulo N is A, such that for every divisor d of N r^j: Φ_d | A′(X) if and only if d | N and Φ_d | A(X)), and Corollary "sets" (p ≠ q primes, M = p^n q, D a set of divisors d > 1 of M, m the least size of a multiset on Z_M with pattern exactly D; if s is divisible by r^j, r an odd prime, with r^j > m, then the least number of elements of a set in Z_{Ms} whose mask is divisible by Φ_d, among the divisors d > 1 of Ms, exactly for d ∈ D, is m). set_sizes_iff_mul is the statement behind the corollary: for every size t < r^j, a set of t elements with pattern exactly P exists on Z_{p^n q s} if and only if a multiset of t elements with pattern exactly P exists on Z_{p^n q}.

What I ask

  1. Read each statement as Lean has it. In your own copy of the project, /home/agent3/lean/sets-audit-copy/ (which builds, with sorry), print the five with implicit arguments shown and say in plain words exactly what each says: every hypothesis and quantifier, the types, the instances Lean found (NeZero (N * r ^ j), NeZero (p ^ n * q * s)), what "the reduction modulo N is w" is in Lean (the count of the elements of the set over each x, through ZMod.castHom), how d = 1, j = 0, the empty multiset and the empty set are treated. Then compare with the paper's statements and list every difference, however small.
  2. Is each statement true? Test outside Lean, by brute force with exact integer arithmetic: - exists_set_lift: for small N, r = 3, 5, 7 and j = 1, 2, every multiset w that satisfies hle and hne (small supports): search the sets A on Z_{N r^j} with the fibre counts w for one with exactly the divisors required (both directions of the "if and only if", for every d | N r^j). Also the excluded cases (every element of multiplicity r^j; r = 2), to see that the statement would fail there. - set_sizes_iff_mul: by complete enumeration of sets on small groups Z_{p^n q s} (for instance orders 18, 30, 36, 54, 60, 45, 90) against a census of multisets on Z_{p^n q}, for every pattern P and every t < r^j, for the admissible (r, j); and what happens for t ≥ r^j or for r = 2 (the statement does not claim those). - the three minsize_…_set: evaluate Lean's values (minU, minB, q * p ^ Es.card; see the earlier audits for how) and compare with the least size of a SET found by search on Z_{p^n q s}, in the cases a search can finish.
  3. Vacuity and strength. Could a hypothesis be contradictory or a conclusion trivially satisfiable? Are hr, hle, hne, hs, ht, hm, hP, [NeZero s] all needed? Is anything excluded that the paper claims (r equal to p or q; p or q equal to 2; s with further factors; n = 0)? Do the Lean statements give the paper's proposition and corollary as worded, or less (for instance: "as many elements"; "whose reduction modulo N is A"; the corollary's "least number of elements of a set")?
  4. Anything else you would want to know before trusting a "proved in Lean" about these.
