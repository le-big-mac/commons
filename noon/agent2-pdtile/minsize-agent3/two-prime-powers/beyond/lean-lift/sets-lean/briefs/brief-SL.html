The one statement (fixed)

theorem exists_set_lift {N r : ℕ} [NeZero N] [Fact r.Prime] (hr : r ≠ 2) (j : ℕ)
    (w : ZMod N → ℕ) (hle : ∀ x, w x ≤ r ^ j) (hne : ∃ x, w x ≠ 0 ∧ w x ≠ r ^ j) :
    ∃ A : Finset (ZMod (N * r ^ j)),
      (∀ x : ZMod N,
        (A.filter (fun y => ZMod.castHom (Nat.dvd_mul_right N (r ^ j)) (ZMod N) y = x)).card = w x) ∧
      ∀ d, d ∣ N * r ^ j →
        (Polynomial.cyclotomic d ℤ ∣ maskW (indW A) ↔ d ∣ N ∧ Polynomial.cyclotomic d ℤ ∣ maskW w)

In words: r an odd prime; a multiset w on Z_N in which every element has multiplicity at most r^j and not every element has multiplicity r^j; then there is a SET A in Z_{N r^j} whose reduction modulo N is w (over each x there are exactly w x elements of A), and for d | N r^j the polynomial Φ_d divides the mask of A exactly when d | N and Φ_d divides the mask of w. (For j = 0 the hypothesis hne cannot hold, so there is nothing to prove.)

The proof on paper

Proposition "lifting to a set" in /home/agent3/paper/sets-section.tex; read it with the proof of Lemma "lifting" in /home/agent3/paper/lift-section-3.tex. In outline:

One step (the heart). Let i ≥ 1 and let w be a multiset on Z_N with every multiplicity ≤ r^i and not every element of multiplicity r^i. There is a multiset w₁ on Z_{N r} with reduce w₁ = w, no Φ_d dividing its mask for d | N r, d ∤ N, every multiplicity ≤ r^(i−1), and, if i ≥ 2, not every element of multiplicity r^(i−1).

  • Write N = r^k N′, r ∤ N′. The r lifts of x have residues (x mod r^k) + r^k t modulo r^(k+1), t = 0..r−1 ("slots"; Aux.exists_section gives, for each t, a section L_t of the reduction with all its values in the slot t). A lift is w₁ = Σ_t Aux.push L_t (a · t) with Σ_t a x t = w x.
  • Criterion (only this direction is needed): let d = e r^(k+1), e | N′, and suppose Φ_d | maskW w₁. For a root of unity ω of order e and every root of unity η of order r^(k+1), the mask vanishes at ωη (Aux.sum_eq_zero_of_cyclotomic_dvd is how Lift1.lean gets such sums). Collect the terms by b = y mod r^(k+1): ℓ(η) = Σ_b g_b η^b = 0 with g_b = Σ_{y mod r^(k+1) = b} w₁(y) ω^y. A polynomial of degree < r^(k+1) that vanishes at all primitive r^(k+1)-th roots is a multiple of 1 + Y^(r^k) + … + Y^((r−1) r^k) (Mathlib: Polynomial.cyclotomic_prime_pow_eq_geom_sum, Polynomial.cyclotomic_eq_prod_X_sub_primitiveRoots or Polynomial.cyclotomic.dvd_X_pow_sub_one-style facts; or avoid polynomials: Σ_η η^(b − b′) over the primitive r^(k+1)-th roots is r^k (r − 1) if b = b′, −r^k if b ≡ b′ mod r^k and b ≠ b′, and 0 otherwise, which gives g_b − g_{b′} = 0 for b ≡ b′ mod r^k directly), so g_{c + r^k t} does not depend on t. In particular G_c(0) = G_c(r − 1) for the class c of a chosen element x₁, where G_c(t) = Σ_{x ≡ c mod r^k} (a x t) ω^x.
  • The choice. Arrange a x₁ 0 − a x₁ (r−1) ∈ {1, 2} and a x 0 = a x (r−1) for every other x in the class of x₁ (for simplicity: for every other x at all). Then G_c(0) − G_c(r−1) = (1 or 2)·ω^{x₁} ≠ 0: contradiction. With w x = r·q + ρ (0 ≤ ρ < r): for x ≠ x₁, a x t = q + 1 on ρ slots and q on the others, the ρ slots chosen so that the slots 0 and r − 1 are both in or both out (ρ ≤ r − 2: use slots 1..ρ; ρ = r − 1: all slots but slot 1). For x₁: if some multiplicity is not divisible by r take such an x₁ (ρ ≥ 1): slot 0 gets q + 1, slot r − 1 gets q, and slots 1..ρ−1 get q + 1; otherwise take x₁ with w x₁ = r q < r^i: slot 0 gets q + 1, slot r − 1 gets q − 1, the rest q.
  • New multiplicities are ≤ ⌈w x / r⌉ ≤ r^(i−1) (and q + 1 ≤ r^(i−1) in the last case). If i ≥ 2 some lift of x₁ has a multiplicity that is positive and below r^(i−1) (see the paper).

Iteration. j steps, on Z_N, Z_{N r}, …, with i = j, j−1, …, 1, end with multiplicities ≤ 1 on a group of order N·r·…·r; the old divisors (d | N) are preserved at each step by cyclotomic_dvd_reduce_iff, the sizes of fibres by the definition of reduce. Then turn the 0/1-valued function into a Finset and move from ZMod (N * r * … * r) to ZMod (N * r ^ j).

How you organise the iteration and the transport between ZMod (N * r ^ (j+1)) and ZMod (N * r ^ j * r) is up to you. One way: prove by induction on j a statement about multisets w' on ZMod (N * r ^ j) (multiplicities ≤ 1, a "reduction to N" given by a sum over the fibres of ZMod.castHom, and the divisor condition), using ZMod.ringEquivCongr (or ZMod.castHom along the equality N * r ^ (j+1) = N * r ^ j * r) for the transport; a ring isomorphism of ZMod M with ZMod M' for M = M' preserves val, hence masks. Another: state the one-step lemma for ZMod M with a hypothesis M = N₁ * r and avoid transport of data. If some other organisation is easier, use it.

Test before you prove. The recipe was tested outside Lean on hundreds of thousands of cases; if you change the choice of slots, test your variant on a few small cases by hand first.
