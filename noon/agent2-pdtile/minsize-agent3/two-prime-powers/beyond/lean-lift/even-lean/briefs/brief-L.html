The proof on paper

Part L of /home/agent3/lean/even-briefs/plan.md. Apply T with - V := the functions {η : F3 // IsPrimitiveRoot η d} → F3 (an additive commutative group by Pi.addCommGroup; any equivalent choice, such as F3 → F3 with values cut off outside the primitive roots, will do), - pos := e, val k := fun η => (η : F3) ^ e k. Then, for every ε: - levelBad pos val ε 0 ↔ Bad3 e ε d: the sum ∑ k, sg (ε k) • val k is the function η ↦ val3 e ε η (a ℤ-multiple sg (ε k) • f of a function is pointwise (sg (ε k) : F3) * f η: zsmul_eq_mul, Pi.smul_apply, Finset.sum_apply), and it is 0 iff val3 e ε η = 0 for every primitive d-th root η, which is Bad3 e ε d. - Bad3 e ε (2^(j+1) * d) → levelBad pos val ε (j+1): for r < 2^j and every primitive d-th root η, S0′ with p = 2, i = j + 1, c = r, t = 0, t′ = 1 gives classSum3 e ε η (2^(j+1)) (r % 2^j + 0 * 2^j) = classSum3 e ε η (2^(j+1)) (r % 2^j + 1 * 2^j), and r % 2^j = r; csum pos val ε M s evaluated at η is classSum3 e ε η M s. - For j = 0, Bad3 e ε (2^0 * d) is Bad3 e ε d, level 0. So {ε | ∃ j ≤ K, Bad3 e ε (2^j * d)} ⊆ {ε | ∃ j ≤ K, levelBad pos val ε j} and {ε | levelBad pos val ε 0} = bad3Set e d (as filters of Finset.univ; mind the Classical decidability instances on both sides: Finset.filter_congr_decidable or convert), and T finishes it: Finset.card_le_card then card_exists_levelBad_le.
