The statement (fixed; it is in your file with sorry)

Pnq.card_exists_levelBad_le (T): V an additive commutative group, pos : ι → ℕ, val : ι → V (ANY values, 0 allowed; nothing is assumed of V). csum pos val ε M r = ∑ k, if pos k % M = r then sg (ε k) • val k else 0; levelBad pos val ε 0 says ∑ k, sg (ε k) • val k = 0; levelBad pos val ε (j+1) says that for every r < 2^j, csum pos val ε (2^(j+1)) r = csum pos val ε (2^(j+1)) (r + 2^j). Then for every K the number of signings ε : ι → Bool for which some level j ≤ K is bad is at most twice the number for which level 0 is bad.

The proof on paper

Part T of /home/agent3/lean/even-briefs/plan.md; it is §2 of /home/agent3/lean/lift-check/even/third/theorem-twice.md (steps (a) to (d); four short steps, refereed). For Lean:

  • F d := {ε | ∀ r, r < 2^d → csum pos val ε (2^d) r = 0} (every class modulo 2^d has sum 0), as a Finset filter.
  • (a) F (d+1) ⊆ F d: csum … (2^d) r = csum … (2^(d+1)) r + csum … (2^(d+1)) (r + 2^d) for r < 2^d (a number that is r modulo 2^d is r or r + 2^d modulo 2^(d+1)); and F 0 is "level 0 bad" (csum … 1 0 is the whole sum).
  • (b) τ j : (ι → Bool) → (ι → Bool) negates ε k for the k with 2^j ≤ pos k % 2^(j+1). It is an involution. For r < 2^j: csum pos val (τ j ε) (2^j) r = csum pos val ε (2^(j+1)) r − csum pos val ε (2^(j+1)) (r + 2^j) (sg of the negated Boolean is −sg). So levelBad pos val ε (j+1) ↔ τ j ε ∈ F j, and the two sets have the same number of elements (Finset.card_bij or Finset.card_nbij' with τ j both ways, or map the filter through the equivalence).
  • (c) F (j+1) ⊆ {level j+1 bad} (both halves 0, so equal) and F (j+1) ⊆ F 0 = {level 0 bad}.
  • (d) By induction on K prove the stronger #{ε | ∃ j ≤ K, levelBad … j} + #(F K) ≤ 2 * #{ε | levelBad … 0}. K = 0: both terms are #{level 0 bad}. Step: {∃ j ≤ K+1} ⊆ {∃ j ≤ K} ∪ ({level K+1 bad} \ {level 0 bad}), and #({level K+1 bad} \ {level 0 bad}) ≤ #{level K+1 bad} − #(F (K+1)) = #(F K) − #(F (K+1)) by (b) and (c) (in ℕ: #(bad (K+1) \ bad 0) + #(F (K+1)) ≤ #(F K)).
