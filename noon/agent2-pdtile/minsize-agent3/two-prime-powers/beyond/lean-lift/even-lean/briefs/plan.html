New, for the reduction modulo 3. Let F be the algebraic closure of ZMod 3 (AlgebraicClosure (ZMod 3)). - val3 e ε ζ : F := Σ_k sg(ε k)·ζ^(e k), the signed mask evaluated at ζ ∈ F. - Bad3 e ε d := for EVERY ζ ∈ F that is a primitive d-th root of unity, val3 e ε ζ = 0. /-- an exceptional pair: two marks whose difference has even additive order -/
def ExceptionalPair {n : ℕ} (w : ZMod n → ℕ) : Prop :=
  ∃ a b : ZMod n, w = Pi.single a 1 + Pi.single b 1 ∧ Even (addOrderOf (a - b))

theorem exists_signs_all (n : ℕ) [NeZero n] (w : ZMod n → ℕ) (hw : ∃ x, w x ≠ 0)
    (hpair : ¬ ExceptionalPair w) :
    ∃ u v : ZMod n → ℕ, (∀ x, u x + v x = w x) ∧
      ∀ d, d ∣ n → ¬ Polynomial.cyclotomic d ℤ ∣ maskW u - maskW v

theorem not_exists_signs_of_exceptionalPair (n : ℕ) [NeZero n] (w : ZMod n → ℕ) (hpair : ExceptionalPair w) :
    ¬ ∃ u v : ZMod n → ℕ, (∀ x, u x + v x = w x) ∧
      ∀ d, d ∣ n → ¬ Polynomial.cyclotomic d ℤ ∣ maskW u - maskW v

(For a = b the order is 1, so two equal marks are not an exceptional pair. Pi.single a 1 + Pi.single b 1 needs decidable equality on ZMod n, which it has.) Route for the first. Total 1: one monomial.
