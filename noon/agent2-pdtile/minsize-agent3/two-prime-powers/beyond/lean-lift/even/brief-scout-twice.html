The inequality ("Theorem T′")

Elements y, each with a position u_y in Z_(2^k) and a value v_y in an abelian group V; independent uniform signs ε_y = ±1; for a set C of elements, σ(C) = Σ_(y ∈ C) ε_y·v_y. A class at depth d is the set of all elements whose position lies in one residue class modulo 2^d. Level 0 is bad if σ of everything is 0. Level j (1 ≤ j ≤ k) is bad if every class at depth j − 1 has equal sums σ in its two halves modulo 2^j. Let F_d be the event that every class at depth d has σ = 0. Then - P(level j is bad) = P(F_(j−1)) (flip the signs of the upper halves at level j), and - P(some level 0, …, k is bad) ≤ 2·P(level 0 is bad) − P(F_k).

Other clothes for the same thing: - For a random element S = Σ ε_y v_y X^(u_y) of the group ring V[Z_(2^k)] with prescribed support and values, the probability that some isotypic component of S vanishes (S ≡ 0 modulo X^(2^(j−1)) + 1 for some j, or S(1) = 0) is at most twice the probability that S(1) = 0. - For a polynomial with coefficients ±1 on a prescribed multiset of exponents: the probability that it vanishes at some root of unity of 2-power order (times a fixed root of unity of odd order) is at most twice the probability that it vanishes at 1 (times that root). - For a random ±1 circulant matrix of order 2^k with a prescribed zero pattern: P(singular) ≤ 2·P(row sum = 0). - In spirit: a reflection argument, like Lévy's maximal inequality for sums of independent symmetric random variables, along the tower of subgroups of Z_(2^k).

The whole result ("Conjecture E", now with a proof on paper)

For every n ≥ 1 and every nonempty multiset B of residues modulo n there are signs such that Σ_(b ∈ B) ± X^b is divisible by no cyclotomic polynomial Φ_d, d | n (equivalently: nonzero at every n-th root of unity; a ±1-signed circulant 0/1 pattern that is nonsingular; a function with values ±1 on a prescribed support in Z_n whose Fourier transform has no zero), EXCEPT exactly when B = {a, b} with n / gcd(n, a − b) even. The proof reduces modulo 3 (Φ_(3^i·d) ≡ Φ_d^(φ(3^i)) modulo 3), so that it suffices to find signs for which the signed sum is nonzero modulo 3 in every "block" Z[ζ_d]/3, d | n with 3 ∤ d; then counts: at most twice (the inequality above) the sum over the odd parts e of the shares of signings that vanish modulo 3 at e.
