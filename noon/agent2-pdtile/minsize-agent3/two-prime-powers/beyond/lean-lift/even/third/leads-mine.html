Leads of mine for a third attempt at Conjecture E (27 November 2026; unchecked unless a program is named; not posted)

Setting as in even-result-2.md: N = 2^k·n″, gcd(n″, 6) = 1; "3-bad at d" means S(ζ_d) ∈ 3Z[ζ_d]; E3: every multiset on Z_N that is not an exceptional pair has a signing 3-bad at no d | N. ρ_2(B) = share of signings 3-bad at no 2^j. p_r = P(sum of r signs ≡ 0 mod 3) = 1/3 + (2/3)(−1/2)^r; p_(r+1) = (1 − p_r)/2.

  1. Conjecture ρ: ρ_2(B) ≥ p_(m−1) for every multiset of m ≥ 3 elements on Z_(2^k). Computed (rho_min.py, rho_min-Z8.out, rho_min-Z16.out; all signings, every multiset containing 0): the least value is exactly p_(m−1) for m = 3..10 on Z_8 and m = 3..7 on Z_16, attained at a large part of all multisets (2,165 of 6,435 for m = 9 on Z_8). A proof in the "unsplit" case (by hand, mine): let x be an element of multiplicity one, alone modulo 2^(d_x); D_1, …, D_(d_x) the sibling classes along the path to x, s_d = σ(D_d) mod 3, ε_x = +1, u_j = 1 + s_(d_x) + … + s_(j+1). Bad at level 0: u_0 ≡ 0. Bad at level j ≥ 1: s_j ≡ u_j and every class at depth j − 1 inside D_1 ∪ … ∪ D_(j−1) is balanced; levels j > d_x are never bad. If every D_d is one unsplit class at the levels ≤ d_x, "balanced" is s_d ≡ 0, and then {u_0 ≡ 1, some level bad} = {the first nonzero s_j is ≡ −1 and u_j ≡ −1}, {u_0 ≡ −1, no level bad} = {the first nonzero s_j is ≡ −1 and u_j ≡ 0}; flipping all signs in D_(j+1) ∪ … ∪ D_(d_x) exchanges u_j ≡ −1 with u_j ≡ 0 … (check: u_j = 1 + s_(>j); s_(>j) ≡ 1 ↔ s_(>j) ≡ −1). So ρ_2 = P(u_0 ≡ 1) = p_(m−1) EXACTLY in that case. When the D_d split, the worked example {x} ∪ D_2 ∪ D_1 with D_1 split at level 2 gives MORE good signings. General case: not proved. When x splits off at the root (d_x = first live level): ρ_2 = p_(m−1) exactly, trivially (good iff σ(B∖x) ≡ 0).
  2. Which levels cost anything for e″ > 1. E_j(e″) := {3-bad at 2^j·e″} = ∩ over the classes c at depth j − 1 of {T_c 3-bad at e″}, T_c = σ(c0) − σ(c1) on Z_(n″); the classes are independent. (a) If some class at depth j − 1 is a single element, level j is never bad at any e″. (b) If no class at depth j − 1 has a full group for a prime of e″, then E_j(e″) ⊂ E_j(1) (step-down in every class), already counted in 1 − ρ_2. (c) P(T_c 3-bad at e″) ≤ 1/2 for every nonempty class. So: bad share ≤ (1 − ρ_2) + Σ over the levels j = 0 and the live j with no singleton class at depth j − 1 of Σ_(e″>1) P(E_j(e″) ∖ E_j(1)), and a level with s classes should cost at most about W(no 3)·2^(−(s−1)) (the pivot set of Lemma L3 (b) in one class, a factor 1/2 for every class without a pivot; NOT proved: the pivots may meet every class). Consequence if (c′) holds: a singleton that separates at the first live level: cost ≤ 2·W(no 3) < 0.2383 < p_(m−1) for m ≥ 4; at the second: ≤ 2.5·W < 0.298 < 5/16 ≤ p_(m−1) for m ≥ 5. Worst case of the crude count: 3·W = 0.357 > 1/3.
  3. Mixing characteristic 0 and peeling. For each e_2 > 1 prime to 3, the events {bad at 2^j·3^i·e_2: all i, j} lie in ∪j E_j(e_2) (Lemma M), and also cost at most Σ_i 2^(1−D(3^i e_2)) (Lemma N, nested in j). So bad share ≤ (1 − ρ_2) + Σ_(e_2) min(…, …). With Lemma A (which does not use that m is odd): bad share ≤ (1 − ρ_2) + 1.13282·2·W(no 3) + R_fib = (1 − ρ_2) + 0.2699 + R_fib. For even m ≥ 10, with Conjecture ρ (p_9 = 0.332): enough if R_fib < 0.062. For the fibrewise pairs use the peeled side of the minimum.
  4. One witness class per level is enough: a signing is 3-good if σ(root) is 3-good on Z_(n″) and for each live level j some class c at depth j − 1 has T_c 3-good on Z_(n″) (all e″ at once; Proposition H says more than half of the signings of a class of ≥ 3 elements do it). Theorem G is the case of one level. For a chain C_0 ⊋ C_1 ⊋ … to a shallowest singleton the conditions are "w(C_i) ± u(D_i) both 3-good"; a single-element sibling D_i above the bottom makes them contradictory at e″ = 1, so witnesses off the chain are needed there.
  5. NOT true: "3-good" is not "unit of F_3[Z_N]" (it is: nonzero in every block Z[ζ_d]/3, which is weaker).

More on Conjecture ρ (by hand, mine, later the same hour)

  • It holds as stated for EVERY nonempty multiset if p_0 = 1, p_1 = 0: one element: 1 = p_0; the exceptional pair: ρ_2 = 0 = p_1. So an induction over the 2-tree need not exclude anything.
  • Reformulation. p_(a+b−1) = p_a + p_b − 3·p_a·p_b = P(exactly one of two independent sums of a and of b signs is ≡ 0) − p_a·p_b. Let the root split into classes c′, c″ of a and b elements, with sums σ′, σ″ and J′, J″ the sets of deeper levels at which every class inside c′ (inside c″) is balanced. A signing is good iff exactly one of σ′, σ″ is ≡ 0 and J′ ∩ J″ = ∅. So Conjecture ρ for B is: P(exactly one of σ′, σ″ ≡ 0, and J′ ∩ J″ ≠ ∅) ≤ P(σ′ ≡ 0)·P(σ″ ≡ 0).
  • Rules for J of a class c at depth d that splits at level j_0 into κ′, κ″: for d < j < j_0, j ∈ J_c iff σ_c ≡ 0; j_0 ∈ J_c iff σ(κ′) ≡ σ(κ″); for j > j_0, j ∈ J_c iff j ∈ J_κ′ ∩ J_κ″. An atom (t equal elements): J = everything if σ ≡ 0, nothing otherwise.
  • A natural injection that FAILS: for σ′ ≡ 0, σ″ ≢ 0, j ∈ J′ ∩ J″, negate inside c″ the upper half of every class at depth j − 1; then σ″ becomes ≡ 0 (each class had σ(κ0) ≡ σ(κ1)). Each such map is a bijection onto its image in {σ′ ≡ σ″ ≡ 0}, but two of them collide: B = {0, 8, 2, 10, 1, 9} on Z_16 (c′ = {1, 9}, c″ = {0, 8} ∪ {2, 10}), ω = (ε_1, ε_9; ε_0, ε_8; ε_2, ε_10) = (+, −; −, −; +, +) is the image of (+, −; −, −; −, −) at level 2 and of (+, +; −, −; +, +) at level 4. (For this B: the left side is 1/8, the right 3/16, ρ_2 = 3/8.)
  • In the unsplit-path case with a singleton x the conjecture is an equality (lead 1); with the path's first sibling split once, the inequality needed is a statement about the rest alone: P(u_1 ≢ 0, no bad level below j_0, some bad level from j_0 on) ≥ P(u_1 ≡ 0, bad at level j_0).

Later (16:10): Lemma ρ is proved (see lemma-rho.md; with a referee), and more on the count

  • Lemma ρ: ρ_2(B) ≥ p_(m−1) for every nonempty multiset, by induction on m with three exact recursions (an atom of multiplicity ≥ 2; a set with a single-element class at the deepest split level; a set that is a doubling). Tested on Z_8 (m ≤ 8), Z_16 (m ≤ 7), Z_32 (m ≤ 5).
  • Rows or columns. For each e_2 > 1 prime to 3 the events {bad at 2^j·3^i·e_2} form a grid in (i, j). A row (fixed i) costs 2^(1−D_(3^i e_2)) by Lemma N (first result); a column (fixed j) costs P(3-bad at 2^j·e_2) by Lemma M. Either all rows or all columns must be paid. Rows: 2^(1−D_(e_2))·(1.13282 + the fibrewise levels, each up to as much as e_2 itself) by Lemma A. Columns: for a pivot set P of e_2 (Lemma L3 (b)), P(3-bad at 2^j·e_2) ≤ 2^(−|P|)·2^(−f_j), f_j the number of classes at depth j − 1 that contain no pivot (the classes are independent, each nonempty class is 3-bad at e_2 for at most half of its signings, and the pivots' signs are forced given all the others): PROVED by hand, two lines. A class of one element makes the level free.
  • Why the plain union over the levels j overcounts: the SAME event recurs at many levels. Example: five pairs, each pair congruent modulo 5, the pairs in the five classes modulo 5, split off one by one in the 2-tree: at every level at which no class holds all five pairs, "3-bad at 2^j·5" is the one event "every pair has opposite signs" (share 1/32). A proof must merge such levels (as the step-down merges the levels that are not live).
  • How far the truth is from the bounds: the worst-looking multiset I could build for the count (n = 240, eleven elements: five in distinct classes modulo 5 with equal residue modulo 16 and modulo 3, and three pairs congruent modulo 15 split off at three levels: 0, 48, 96, 144, 192, 145, 25, 50, 170, 196, 76) has 960 good signings of 1,024 (share.py).
  • For odd m the row count is 0.531258 + (rows of the e_2 > 1); if the fibrewise e_2 could be paid by columns at ≤ 3·2^(−μ) each, the total would be < 0.531258 + 3·W(no 3) = 0.8887 < 1; but a column also contains the levels at which no class has a full group, where "3-bad at 2^j·e_2" is not rare by itself (it is then inside "3-bad at 2^j", which costs nothing in characteristic 0 for odd m but is not excluded modulo 3).
