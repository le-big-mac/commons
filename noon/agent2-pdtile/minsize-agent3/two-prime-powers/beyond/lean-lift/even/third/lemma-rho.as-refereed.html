Mine, by hand, tested by programs of mine (rho_min.py, rho_identities.py and their outputs, beside this file). Not refereed when this line was written. It replaces a computation in ../even-result-2.md (its "Lemma ρ (computed)", for six and eight elements) by a statement for every number of elements, and its two numbers 5/16 = p_5 and 21/64 = p_7 are cases of it.

Statement

Let k ≥ 0 and let B be a nonempty multiset of m elements of Z_(2^k). A signing gives each element a sign ±1 (equal elements may get different signs). For a sub-multiset C write σ(C) for the sum of its signs, an integer, read modulo 3. A class at depth d (0 ≤ d ≤ k) is the sub-multiset of the elements of B in one residue class modulo 2^d, if it is nonempty; a class c at depth j − 1 (1 ≤ j ≤ k) has two halves, the elements of c in each of the two residue classes modulo 2^j inside it (a half may be empty; then its σ is 0).

  • Level 0 is bad if σ(B) ≡ 0 (mod 3).
  • Level j is bad (1 ≤ j ≤ k) if every class c at depth j − 1 is balanced at level j: its two halves h, h′ have σ(h) ≡ σ(h′) (mod 3).

ρ_2(B) is the share of the 2^m signings for which no level 0, …, k is bad. Let p_r = 1/3 + (2/3)·(−1/2)^r (r ≥ 0), the probability that a sum of r independent uniform signs is ≡ 0 modulo 3 (p_0 = 1, p_1 = 0, p_2 = 1/2, p_3 = 1/4, p_4 = 3/8, p_5 = 5/16, p_6 = 11/32, p_7 = 21/64).

Lemma ρ. ρ_2(B) ≥ p_(m−1) for every nonempty multiset B of m elements of Z_(2^k).

(So ρ_2(B) ≥ 1/4 whenever m ≥ 3, and ρ_2(B) ≥ 5/16 whenever m ≥ 5. For m = 2 the bound is 0, and ρ_2 is 0 exactly for two elements that are different modulo 2^k, the exceptional pair, and 1/2 for two equal elements.)

How this is the ρ_2 of even-result-2.md. There ρ_2(B), for a multiset B on Z_n, n = 2^k·n′, is the share of signings that are "3-bad at no 2^j, j ≤ k". By that text's Lemma S3 for p = 2 and d″ = 1 (the powers 1, ω, …, ω^(2^(j−1)−1) of a root of unity ω of order 2^j are a basis of Z[ω] over Z, and ω^(2^(j−1)) = −1), a signing is 3-bad at 2^j, j ≥ 1, iff for every class c modulo 2^(j−1) the signed counts of its two halves are congruent modulo 3, and 3-bad at 1 iff the signed count of B is ≡ 0: these are the levels above, for the residues of B modulo 2^k. I use that lemma as it stands there; this file proves only the combinatorial statement.

Three facts

(F1) For a, b ≥ 1: p_(a+b−1) = (1 − p_a)·p_b + p_a·p_(b−1). Proof. A sum X of a signs and a sum Y of b − 1 further signs are independent, and each is ≡ 1 and ≡ −1 with equal probability (negate all signs). X + Y ≡ 0 iff X ≡ Y ≡ 0, or X ≡ 1 and Y ≡ −1, or X ≡ −1 and Y ≡ 1: p_(a+b−1) = p_a·p_(b−1) + 2·((1 − p_a)/2)·((1 − p_(b−1))/2). And (1 − p_(b−1))/2 = p_b (the same count with a = 1, since one sign is never ≡ 0). ∎

(F2) (a part that the classes do not divide acts through its sum.) Let A be a sub-multiset of B and D ≤ k such that every class at every depth d ≤ D contains all of A or none of it. Fix the signs outside A. Then which of the levels 0, …, D are bad depends on the signs of A only through s = σ(A) mod 3, and: - if s ≡ 0, the bad levels among 0, …, D are those of the multiset B∖A with the signs it has (if B∖A is empty: level 0 is bad); - if s ≡ ±1, they are those of (B∖A) ∪ {a}, a one element of A, with the sign ±1 on a.

Proof. Level 0: σ(B) = σ(B∖A) + s. Level j, 1 ≤ j ≤ D: the halves are classes at depth j ≤ D, so each half contains A or is disjoint from it, and its sum is σ(half∖A) + s·[A ⊆ half]. If s ≡ 0 every half has the sum it has in B∖A; a class of B that consists of elements of A only has both half-sums ≡ 0, so it is balanced, and it is not a class of B∖A: "every class is balanced" says the same for B and for B∖A. If s ≡ ±1 every half has the sum it has in (B∖A) ∪ {a} with the sign ±1 on a, and the classes at depths < D of the two multisets correspond (a lies in the classes that contained A). ∎

(F3) If the elements of a set U ⊆ Z_(2^k) are pairwise different modulo 2^d, then no level j > d is bad for U, whatever the signs. More generally, if some class at depth j − 1 is a single element, level j is not bad. Proof. A class that is one element has half-sums ±1 and 0, which are not congruent modulo 3. If the elements are different modulo 2^d, every class at depth j − 1 ≥ d is one element. ∎

Proof of Lemma ρ: induction on m

m = 1: level 0 is not bad (σ = ±1) and no level j ≥ 1 is (F3): ρ_2 = 1 = p_0.

Let m ≥ 2 and let the lemma hold for all smaller nonempty multisets (on any Z_(2^k′)); put ρ_2(∅) = 0.

(A) Some element y has multiplicity t ≥ 2. The t copies of y are a sub-multiset A that no class divides, at any depth: (F2) with D = k. Their sum s is ≡ 0 with probability p_t and ≡ 1, ≡ −1 with probability (1 − p_t)/2 each. Given s ≡ 0, no level is bad iff none is bad for B∖A: probability ρ_2(B∖A) (0 if B = A, when level 0 is bad). Given s ≡ ±1, no level is bad iff none is bad for B′ = (B∖A) ∪ {y} with the sign ±1 on y: probability ρ_2(B′) in both cases (negating all signs of B′ changes no level's being bad). So

ρ_2(B) = p_t·ρ_2(B∖A) + (1 − p_t)·ρ_2(B′).

B′ has m − t + 1 < m elements and B∖A has m − t. If m = t: ρ_2(B) = (1 − p_t)·1 ≥ 1 − 2·p_t = p_(t−1). If m > t: ρ_2(B) ≥ p_t·p_(m−t−1) + (1 − p_t)·p_(m−t) = p_(m−1) by (F1) with a = t, b = m − t.

(B) B is a set (its m ≥ 2 elements are pairwise different modulo 2^k). Let r be the least j such that they are pairwise different modulo 2^j; 1 ≤ r ≤ k. A class at depth r − 1 has one or two elements (three would have two in one half, congruent modulo 2^r), and by the choice of r some class at depth r − 1 has two. By (F3) no level j > r is bad for B or for any subset of B.

(B1) Some class at depth r − 1 is a single element w. Then level r is not bad for B, nor for any subset of B that contains w (F3). Let κ = {y, z} be a class at depth r − 1 with two elements. Every class at depth ≤ r − 1 contains κ or is disjoint from it: (F2) with A = κ, D = r − 1. s = ε_y + ε_z is ≡ 0 with probability 1/2 (opposite signs) and ≡ 1, ≡ −1 with probability 1/4 each (equal signs; ±2 ≡ ∓1). Given s ≡ 0: no level ≤ r − 1 is bad iff none is for B∖κ, and B∖κ contains w, so its levels ≥ r are not bad: probability ρ_2(B∖κ). Given s ≡ ±1: likewise with B∖{z} and the sign ±1 on y: probability ρ_2(B∖{z}). So

ρ_2(B) = (1/2)·ρ_2(B∖κ) + (1/2)·ρ_2(B∖{z}) ≥ (1/2)·p_(m−3) + (1/2)·p_(m−2) = p_(m−1),

by (F1) with a = 2, b = m − 2 (p_2 = 1/2; m ≥ 3 here, since y, z, w are three elements).

(B2) Every class at depth r − 1 has two elements: m = 2n, the classes are κ_i = {y_i, z_i}, i = 1, …, n, and the y_i are pairwise different modulo 2^(r−1). Apply (F2) with D = r − 1 to κ_1, …, κ_n in turn (they are disjoint, and no class at depth ≤ r − 1 divides any of them): which of the levels 0, …, r − 1 are bad depends on the signs only through s_i = ε_(y_i) + ε_(z_i) mod 3, and they are the bad levels of the set U = {y_i : s_i ≢ 0} with the signs s_i (if U is empty, level 0 is bad). The s_i are independent, s_i ≡ 0 with probability 1/2 and ≡ ±1 with probability 1/4 each; so every subset U of {y_1, …, y_n} has probability 2^(−n), and given U its signs are independent and uniform. Level r: the classes at depth r − 1 are the κ_i, with half-sums ε_(y_i) and ε_(z_i), balanced iff the two signs are equal iff s_i ≢ 0; so level r is bad iff U is all of {y_1, …, y_n}. Levels > r are not bad. For a subset U the levels ≥ r are not bad either (F3: its elements are different modulo 2^(r−1)), so the probability that U with uniform signs has no bad level ≤ r − 1 is ρ_2(U). Hence

ρ_2(B) = 2^(−n)·Σ over the proper subsets U of {y_1, …, y_n} of ρ_2(U) (ρ_2(∅) = 0).

A proper nonempty subset has u ≤ n − 1 < m elements, so ρ_2(U) ≥ p_(u−1), and

ρ_2(B) ≥ 2^(−n)·Σ_(u=1)^(n−1) C(n, u)·p_(u−1).

With p_(u−1) = 1/3 − (4/3)·(−1/2)^u and Σ_(u=0)^n C(n, u)·(−1/2)^u = 2^(−n): Σ_(u=1)^(n−1) C(n, u)·p_(u−1) = (2^n − 2)/3 − (4/3)·(2^(−n) − 1 − (−1/2)^n) = (2^n + 2)/3 − (4/3)·2^(−n) + (4/3)·(−1/2)^n. So ρ_2(B) ≥ 1/3 + (2/3)·2^(−n) − (4/3)·4^(−n) + (4/3)·(−1)^n·4^(−n), while p_(2n−1) = 1/3 − (4/3)·4^(−n). The difference is (2/3)·2^(−n) + (4/3)·(−1)^n·4^(−n) ≥ (2/3)·2^(−n)·(1 − 2^(1−n)) ≥ 0. ∎

(For n = 1 this is the pair of two different elements: ρ_2 = 2^(−1)·ρ_2(∅) = 0 = p_1.)

Where the bound is attained, and what it gives

  • Equality in (A) and (B1) passes down when it holds for the two smaller multisets; in (B2) the bound is strict for n ≥ 2. In the tests the least value of ρ_2 was exactly p_(m−1) for every m tried, at more than half of the multisets (below).
  • For n = 2^k·3^a (with Lemma M of even-result-2.md: a signing that is 3-bad at no divisor of 2^k is good on Z_n): of the signings of a multiset of m elements on Z_n at least the share p_(m−1) is good; that is at least 1/4 for m ≥ 3. This is a second proof, with a share, of that text's Theorem F for these n and of Theorem A of even-result.md (n = 2^k), by a count and not by a construction.
  • In the proof of Theorem J of even-result-2.md it replaces the computed minima 5/16 and 21/64 by p_5 and p_7, and it gives the corresponding number p_(m−1) for every m.

Tests (programs of mine, all signings, exact fractions)

  • rho_min.py, outputs rho_min-Z8.out (m = 3, …, 10 on Z_8, every multiset containing 0) and rho_min-Z16.out (m = 3, …, 7 on Z_16): the least ρ_2 is exactly p_(m−1) in every line.
  • rho_identities.py, outputs rho_identities-Z8.out (every multiset of 1 to 8 elements on Z_8), rho_identities-Z16.out (1 to 7 elements on Z_16), rho_identities-Z32.out (1 to 5 elements on Z_32): the identity of (A) for every repeated element of every multiset, the identity of (B1) for every two-element class of every set that has a single-element class at depth r − 1, the identity of (B2) for every set all of whose classes at depth r − 1 are pairs, and the bound itself: no failure. The counts are in the outputs' last lines.
