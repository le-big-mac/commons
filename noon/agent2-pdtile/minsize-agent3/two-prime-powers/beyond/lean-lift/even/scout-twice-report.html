3. What is in print that bears on the inequality, most important first

3.1 Miller, "On the singularity probability of random circulant Bernoulli matrices" — CLOSE (levels 0 and 1 only; full support; asymptotic)

Address: https://arxiv.org/abs/2411.17577. All n entries are random.

  • The two-level inclusion–exclusion is written out: "P_q^+(1, n) + P_q^+(2, n) − P[P^+{1,n} ∩ P^+{2,n}] ≤ P_q^+(n) ≤ Σ_{d|n} P_q^+(d, n)." (formula reassembled from the layout)
  • The intersection is given as 0 for n ≢ 0 (mod 4), and as (n/2 choose n/4)² q^(n/2) (1 − q)^(n/2) for n ≡ 0 (mod 4). For full support at q = 1/2 this is P(F_1).
  • The conclusion holds "except if q = 1/2 and n is even, in which case P_q^+(n) ∼ 2√2/√(πn) as n → ∞."

How it relates: - 2√2/√(πn) is asymptotically twice P(row sum = 0), so the constant 2 of the circulant clothing is in print as an asymptotic, for every even n with full support. - For k = 1 the inequality is this inclusion–exclusion line. - For k ≥ 2 the paper's upper bound is the plain union bound over all divisors, which adds the terms for Φ_4, Φ_8, … instead of absorbing them. - Neither statement implies the other. T′ would give an exact (non-asymptotic) bound with the same leading constant, but only for 2-power order; it also covers prescribed support, which the paper does not treat. - A word search of the text for "power of 2", "reflect", "flip" and "Φ4" finds nothing.

3.2 OEIS A144926 — CLOSE; its data agree with the inequality

Address: https://oeis.org/A144926, "Number of n X n (-1,1)-circulant matrices with determinant 0."

  • For order 2p it records an exact "twice": "a(2p) = 2binomial(2*p,p) if p is an odd prime".
  • The recorded proof ends: "it is enough to compute the number of such f(x) that are divisible by (x-1) and the number of such f(x) that are divisible by (x+1) and add up these numbers. Clearly, each of these numbers equals binomial(2p,p)".
  • So P(singular) = 2·P(row sum = 0) exactly at order 2p, full support. The proof goes through a different mechanism: "The values of f(1) and f(-1) are even but different modulo 4."
  • My arithmetic check against the listed data at 2-power orders, where T′ with full support gives a(n) ≤ 2·binomial(n, n/2):

3.3 Meckes, "Some results on random circulant matrices" — the first bullet at level 1 is KNOWN for full support

Address: https://arxiv.org/abs/0902.2472 (morning's text copy).

  • "Observe first that f(1) and f(−1) are identically distributed and (4.4) P[f(1) = 0] = P[f(−1) = 0] = 2^(−n) (n choose n/2) if n is even, 0 if n is odd." (formula reassembled)
  • This is P(level 1 is bad) = P(F_0) for full support.
  • For the other roots the paper uses "(4.5) P[C_n is singular] ≤ P[f(1) = 0] + Σ_{1≤k<n, k|n} P[f(ω_n^k) = 0]" with an inverse Littlewood–Offord bound c/n per root. That is a union bound with unnamed constants, not a reflection along the tower.
  • The same equality for the higher levels (j ≥ 2), or for a prescribed support, I did not find stated anywhere.

3.4 Kozma and Zeitouni, "On common roots of random Bernoulli polynomials" — CLOSE (levels 0 and 1; two polynomials; asymptotic)

Address: https://arxiv.org/abs/1109.2316 (IMRN 2013 by the search summary).

  • "Theorem 2. Let P1, P2 be two independent random polynomials in 1 variable of degree n. Let p(n) = Pr(∃x ∈ C : P1(x) = P2(x) = 0). If n is even then p(n) = (4/π + o(1)) 1/n". (formula reassembled; the paper's indexing of n not checked by me)
  • The proof splits into the term at 1, the term at −1 and their intersection, with "I = II = (2/π + o(1)) 1/n" for n even.
  • "The third term III is the probability that P1 and P2 both vanish at ±1. This probability vanishes when n is odd and, when n is even, it equals the probability that both Σ ε_{2i} = 0 and Σ ε_{2i+1} = 0; those events are independent".
  • So "asymptotically twice the probability at 1" appears again, with the level-1 intersection written as the two interleaved sums vanishing. All other roots are handled by anti-concentration, not by reflection. Full support only.

3.5 Khare and Rajaratnam, Lévy's inequality in abelian metric groups for nested-or-disjoint blocks — same device, DIFFERENT statement

Address: https://arxiv.org/abs/1610.03037 (J. Math. Anal. Appl. 528 (2023), by the abstract page).

  • "Theorem 2.10 (Lévy's inequality). Fix an abelian metric group (G, +, 0, d), integers m, n ∈ Z>0, and symmetric random variables X1, …, Xn ∈ L0(Ω, G). Also fix subsets B1, …, Bm ⊆ {1, …, n}, such that for all 1 ⩽ j ⩽ k ⩽ m, Bj ∩ Bk is either Bj or empty. Set X_B := Σ_{b∈B} X_b … If Sn = X1 + · · · + Xn, then for all s, t > 0, P(max_{1⩽k⩽m} d(0, 2X_{Bk}) > s + t) ⩽ P(d(0, Sn) > s) + P(d(0, Sn) > t)." (reassembled)
  • This is the nearest thing found to a Lévy inequality on a tree: values in an abelian group, a nested-or-disjoint family of blocks, and a proof by reflecting a block at a stopping time.
  • It bounds the chance that some block sum is far from 0 by twice the chance that the total is far from 0.
  • I tried to derive T′ from it and could not. With the discrete metric it gives P(some block has 2·σ ≠ 0) ≤ 2·P(total ≠ 0), an inequality between non-vanishing events. T′ bounds a union of vanishing events, and its level events are sign-twisted sums, not block sums.

3.6 Marcus and Siegel, "On Codes with Spectral Nulls at Rational Submultiples of the Symbol Frequency" — the deterministic fact behind F_d, CLOSE; no probability

Address: https://cmrr-star.ucsd.edu/static/pubs/codes_spectral_nulls.pdf (text layer partly garbled; symbols reassembled).

  • "Reference has been made in communication theory applications to the fact that a null at f_s/m can be produced by interleaving m sequences, each having a null at dc [6], [7]."
  • "any FSTD which has a spectral null at dc and f_s/2 must produce sequences which consist of two interleaved sequences, each having a null at dc."
  • This is the coding-theory form of "vanishing at 1 and −1 means every class modulo 2 sums to zero", stated for constrained sequence systems. It has no counting, no random signs and no inequality.

5. Overall judgement

The inequality (Theorem T′): NOT FOUND. - KNOWN in print, full support only: the level-1 symmetry (Meckes 4.4); the two-level inclusion–exclusion with the intersection equal to "both interleaved sums vanish" (Miller; Kozma–Zeitouni); the asymptotic constant 2 for even order (Miller); the exact "twice" at order 2p (OEIS). - NOT FOUND: the equality P(level j is bad) = P(F_(j−1)) for j ≥ 2; the bound 2·P(level 0 is bad) − P(F_k) over the whole tower; any version with prescribed support, multisets or values in a group. - It does not FOLLOW from anything I read, the group-valued Lévy inequality for nested blocks included. - Consistent with the printed counts at orders 2, 4, 8, 16, 32.
