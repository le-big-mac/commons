The one statement (fixed)

theorem exists_signs (p q : ℕ) [Fact p.Prime] [Fact q.Prime] (hp : p ≠ 2) (hq : q ≠ 2) (hpq : p ≠ q) (a b : ℕ)
    (w : ZMod (p ^ a * q ^ b) → ℕ) (hw : ∃ x, w x ≠ 0) :
    ∃ u v : ZMod (p ^ a * q ^ b) → ℕ, (∀ x, u x + v x = w x) ∧
      ∀ d, d ∣ p ^ a * q ^ b → ¬ Polynomial.cyclotomic d ℤ ∣ maskW u - maskW v

In words: n = p^a q^b with odd primes p ≠ q; a nonempty multiset w on Z_n; each element gets a sign (u = the elements signed +, v = those signed −); the signed mask S = maskW u − maskW v is divisible by no Φ_d, d | n, d = 1 included. Write g(x) = u(x) − v(x) ∈ ℤ, so |g(x)| ≤ w(x), g(x) ≡ w(x) mod 2, and any such g comes from some u, v.

The proof on paper

It is Lemma "signs" in /home/agent3/paper/lift-section-2.tex (read it). In outline, with the route I would try in Lean:

Step 1, what has to be avoided. Let d = p^i q^j divide n (every divisor of n has this form, i ≤ a, j ≤ b) and suppose Φ_d | S in ℤ[X]. Map to (ZMod q)[X]. In characteristic q, Mathlib has Polynomial.cyclotomic_mul_prime_pow_eq: for q ∤ m and 0 < j, cyclotomic (q ^ j * m) R = cyclotomic m R ^ (q ^ j - q ^ (j - 1)). So in every case Φ_{p^i} divides S over ZMod q (for j = 0 directly; for j > 0 because Φ_{p^i q^j} is there the power Φ_{p^i}^(q^j − q^(j−1)), with exponent ≥ 1, so Φ_{p^i} divides it, and it divides S). - i = 0: X − 1 divides S over ZMod q, so S(1) = Σ_x g(x) ≡ 0 mod q. - i ≥ 1: multiply by X^(p^(i−1)) − 1. Mathlib: Polynomial.cyclotomic_prime_pow_mul_X_pow_sub_one: cyclotomic (p ^ (k + 1)) R * (X ^ p ^ k - 1) = X ^ p ^ (k + 1) - 1. So X^(p^i) − 1 divides (X^(p^(i−1)) − 1)·S over ZMod q. A polynomial f divisible by X^L − 1 has, for every residue c modulo L, the sum of its coefficients at exponents ≡ c (mod L) equal to 0 (it is 0 in the quotient by X^L − 1, where X^m ↦ X^(m mod L); or: induct on the quotient; or evaluate in the group algebra). Applied with L = p^i: for every class c modulo p^i, σ_i(c − p^(i−1)) ≡ σ_i(c) (mod q), where σ_i(c) = Σ_{x ≡ c mod p^i} g(x). Hence all the classes modulo p^i inside one class modulo p^(i−1) have the same σ_i modulo q.

So S is good as soon as (i) Σ_x g(x) ≢ 0 mod q, and (ii) for each i = 1, …, a there are two classes c, c′ modulo p^i with c ≡ c′ modulo p^(i−1) and σ_i(c) ≢ σ_i(c′) mod q. (You only need "some two classes in a common parent differ", so it is enough to derive from divisibility that ALL pairs in a common parent agree; by the shift relation above, c and c − t·p^(i−1) agree for every t.)

Step 2, the signs. Fix x* with w(x) ≠ 0 and let C_i be the set of x ≡ x modulo p^i (C_0 = everything, C_0 ⊇ C_1 ⊇ … ⊇ C_a). Build g on C_a first, then on C_(a−1), …, C_0, keeping this invariant for g defined on C_i (and 0 outside): T_i := Σ_{x ∈ C_i} g(x) ≢ 0 mod q, and (ii) holds at every level j with i < j ≤ a (its two witness classes lie inside C_(j−1) ⊆ C_i, so later choices outside C_i do not disturb them). - On C_a: all elements +, except that if their number is ≥ 2 one may take any g with parity right; simplest: the sum of all w on C_a is some ν ≥ 1; take T_a = 1 if ν is odd, 2 if ν is even (so one element's copies split suitably; any g on C_a with |g| ≤ w, g ≡ w mod 2 and total 1 or 2 will do, and 1, 2 ≢ 0 mod q as q ≥ 3). - From C_i to C_(i−1): the rest C_(i−1) ∖ C_i is the union of the p − 1 "sibling" classes modulo p^i. A sibling with an even number of elements (counted with multiplicity, 0 allowed) can be given total 0; one with an odd number can be given total +1 or −1, as we like. A greedy lemma does most of it: given a start value T ≢ 0 mod q and a finite set of siblings, the totals (0 for even ones, ±1 for odd ones) can be chosen so that T plus their sum is ≢ 0 mod q: add the siblings one at a time; for an odd one, T + 1 and T − 1 are not both ≡ 0 mod q since q ∤ 2. Witness for (ii) at level i: if some sibling is even, its total 0 differs from T_i ≢ 0, and the pair (that sibling, C_i) is the witness; run the greedy lemma over all siblings. If all p − 1 siblings are odd, take two of them (p − 1 ≥ 2 because p is odd), give them −1 and +1 (their sum is 0, so T is unchanged, and −1 ≢ +1 mod q because q ≠ 2), these two are the witness; run the greedy lemma over the other siblings.

How you represent partial signings, classes and siblings in Lean is up to you (functions ZMod n → ℤ with a support condition; classes via ZMod.castHom to ZMod (p ^ i), or via x.val % p ^ i; an induction on a − i). If a different organisation of the induction is easier (for instance from the root down, using the statement for the smaller group), use it.

Small cases to keep in mind: a = 0 (no level; only (i)); b = 0 (q does not divide n; it is then only an auxiliary odd prime; the argument is the same, with j = 0 always); n = 1.
