The five statements (fixed; read them in the file)

  • sizes_eq_odd {N} [NeZero N] (s) [NeZero s] (hs : Odd s) (P) (hP : ∀ d ∈ P, d ∣ N): the set of sizes of the nonempty multisets on ZMod (N * s) with pattern exactly P (among the divisors d ≠ 1 of N * s) equals the same set on ZMod N.
  • sizes_eq_mul p q n s … (hpq : p ≠ q) (P) (hP : ∀ d ∈ P, d ∣ p ^ n * q): the same on ZMod (p ^ n * q * s) against ZMod (p ^ n * q), for EVERY s with [NeZero s], p ≠ q primes (either may be 2).

The proof on paper

The Corollary in /home/agent3/paper/lift-section-2.tex. A route for Lean:

  1. A definition of your own, for instance sizes (M : ℕ) [NeZero M] (P : Finset ℕ) : Set ℕ := {t | ∃ w : ZMod M → ℕ, ∑ x, w x = t ∧ 0 < t ∧ ∀ d, d ∣ M → d ≠ 1 → (cyclotomic d ℤ ∣ maskW w ↔ d ∈ P)}, and a congruence lemma: M = M' → sizes M P = sizes M' P (by subst; NeZero is a Prop, so the two instances agree). With it N * 1, N * (s' * r) and N * s' * r can be exchanged freely.
  2. sizes_eq_odd by strong induction on s: s = 1 by congruence; otherwise take a prime r ∣ s (odd, since s is odd), s = s' * r, and sizes (N * s' * r) P = sizes (N * s') P by sizes_eq with N := N * s' (P consists of divisors of N, hence of N * s'), then the induction hypothesis for s'.
  3. sizes_eq_mul: write s = 2 ^ j * s' with s' odd. First sizes (p^n q · 2^j · s') = sizes (p^n q · 2^j) by sizes_eq_odd with N := p ^ n * q * 2 ^ j. Then induction on j with sizes_eq_two, which needs p ^ n * q * 2 ^ i = 2 ^ k * (p' ^ a * q' ^ b) for odd primes p' ≠ q': - p and q both odd: p' = p, q' = q, a = n, b = 1, k = i; - p = 2 (so q odd): k = n + i, q' = q, b = 1, and p' any odd prime other than q with a = 0 (3, or 5 if q = 3; Fact (Nat.Prime 3) is Nat.fact_prime_three, and Fact (Nat.Prime 5) can be made with ⟨by norm_num⟩ as a local haveI, which is not an instance declaration and is allowed); - q = 2 (so p odd): k = i + 1, p' = p, a = n, and q' any odd prime other than p with b = 0.
  4. The three least-size theorems from sizes_eq_mul and the three theorems of MinGroup.lean: the set in each is the set sizes (p ^ n * q * s) P for the pattern P = {p^ℓ : ℓ ∈ Es} ∪ {p^ℓ·q : ℓ ∈ Fs} (with q itself in P in the balanced cases), because the divisors d ≠ 1 of p ^ n * q are exactly p^ℓ (1 ≤ ℓ ≤ n), q, and p^ℓ·q (1 ≤ ℓ ≤ n), and 0 < t follows in each case as in LiftMin.lean (by ¬Φ_q ∣, by 0 < t, by a0 ∉ Fs). Alternatively, prove a general reduction ZMod (N * s) → ZMod N of your own and imitate LiftMin.lean directly. Whichever is shorter.
