0. Summary

Both statements say what §1 of union-twice.md means, in the weaker form the brief announces ("at most twice", without the subtracted terms), and my tests found both true. I found nothing false, vacuous or different in content.

U. For every finite type ι, every type V with AddCommGroup, every type κ (empty allowed), every pos : ι → ℕ, val : κ → ι → V, K : ℕ:

{ε : ι → Bool | ∃ c, ∃ j ≤ K, levelBad pos (val c) ε j} ≤ 2 · #{ε | ∃ c, levelBad pos (val c) ε 0}.

This is the note's Theorem U for k = K and positions pos mod 2^K, without "− P(G_k)" and without the equalities P(B_j) = P(G_(j−1)). One group V for all c loses nothing: the form with a group V_c for each c follows from the Lean statement in a few lines (product of the groups; U_family in U2_fit.lean, checked by Lean). Tests, every signing, exact arithmetic: 308,939 families (1,321,994 pairs family × K; 3,015,172 signings) in ℤ, ℤ/2, ℤ/3, ℤ/4, ℤ², ℤ/2 × ℤ/4 with 0 to 4 systems: no failure; the factor 2 is attained (239,385 times; with 1, 2, 3 and 4 systems). Four false variants fail in my test (a fifth fails exactly when there is no system), so the test can fail. Lean's own evaluation of both cardinalities on 60 small families equals my program's, line for line.

Corollary U. For every finite type ι, e : ι → ℕ, k : ℕ, n′ : ℕ with ¬ 2 ∣ n′:

{ε | ∃ d, d ∣ 2^k·n′ ∧ Φ_d ∣ Σ ± X^(e i)} ≤ 2 · #{ε | ∃ d, d ∣ n′ ∧ Φ_d ∣ Σ ± X^(e i)}.

This is the note's Corollary U without "− #G". It has no multiset on Z_n and no reduction modulo n′ in it; it is the same statement because BadAt e ε d depends only on the exponents modulo d (proved in Lean here, without sorry: badAt_mod, badAt_mod_of_dvd in U4_mod.lean; and 0 mismatches in 20,000 random families). Tests, every signing, exact polynomial division: 282,396 families with n′ odd (267,396 of them an exhaustive list of multisets), k = 0 to 4: no failure; the factor 2 is attained (102,056 times). With n′ even, which the hypothesis excludes: no failure either in 69,265 families, and that is no accident: the statement for every n′ (even, and 0) FOLLOWS from the Lean statement (whole_any in U2_fit.lean, checked by Lean). So the hypothesis costs nothing.

Worth knowing before "proved in Lean" is believed (§6): (1) what Lean will certify is the weak form: no P(G_k), no #G, no P(B_j) = P(G_(j−1)), and nothing of §3 of the note (shares, β(m)); (2) the words "multiset on Z_n" and "reduction modulo n′" are not in the Lean statement; the bridge is badAt_mod_of_dvd, which is in my scratch file and not in the library; (3) both statements carry the instances of classical logic, also inside Finset.univ; at a concrete ι (Fin m) exact does not match and convert does (seen); (4) my tests are small: at most 8 elements for U, at most 11 for Corollary U, n ≤ 216.

1. U as Lean has it (U1_print.out, with pp.all)

card_exists_exists_levelBad_le.{u_1, u_2, u_3} :
  ∀ {ι : Type u_1} [inst : Fintype ι] {V : Type u_2} [inst_1 : AddCommGroup V] {κ : Type u_3}
    (pos : ι → ℕ) (val : κ → ι → V) (K : ℕ),
  (filter (fun ε : ι → Bool => ∃ c : κ, ∃ j : ℕ, j ≤ K ∧ levelBad pos (val c) ε j) univ).card
    ≤ 2 * (filter (fun ε : ι → Bool => ∃ c : κ, levelBad pos (val c) ε 0) univ).card

Binder by binder:

  • ι : Type u_1, [Fintype ι]: the elements; any finite type, empty allowed; a family, so equal positions and equal values may repeat.
  • V : Type u_2, [AddCommGroup V]: ONE group for all systems; any group, no condition on 2-torsion; values any elements, 0 allowed.
  • κ : Type u_3: the indices of the systems; any type in a universe of its own, infinite allowed, empty allowed. Implicit: Lean finds it from val.
  • pos : ι → ℕ: one position for each element, THE SAME for every system (levelBad pos (val c)); natural numbers, not reduced modulo anything.
  • val : κ → ι → V: for each index c a value for each element.
  • K : ℕ: any natural number; not tied to the positions.
  • Left set: the signings ε for which there are an index c and a level j ≤ K with level j bad for the values of c. Both quantifiers are "there is"; c and j may differ from signing to signing. Right set: the signings for which there is an index c with level 0 bad for the values of c. The inequality is between natural numbers: left ≤ 2 · right.
  • levelBad pos val ε 0 is ∑ k, sg (ε k) • val k = 0 (sg true = 1, sg false = −1, a multiple by an integer in V); levelBad pos val ε (j+1) is: for every r < 2^j, csum pos val ε (2^(j+1)) r = csum pos val ε (2^(j+1)) (r + 2^j), csum … M r being the signed sum over the elements with pos k % M = r. (Printed in U1_print.out; these definitions were audited this evening and I re-read them; my program has them word for word.)
  • Instances inside the sets: each filter's DecidablePred is fun a => Classical.propDecidable (…) for the whole predicate (the whole ∃ c, ∃ j, … on the left, the whole ∃ c, … on the right). Finset.univ on ι → Bool is from Pi.instFintype with DecidableEq ι := fun a b => Classical.propDecidable (a = b), the given Fintype ι, and Bool.fintype. None of this changes the numbers (any two Fintype instances give the same univ, any two decidability instances the same filter); it matters only for use, see §6 (3).
  • Axioms now: propext, sorryAx, Classical.choice, Quot.sound (the sorry). card_exists_levelBad_le (T), on which it may lean, has no sorryAx.

Boundary cases (lemmas in U2_fit.lean, checked by Lean without the sorry statements unless said):

  • κ empty: no signing is in either set (no_system): 0 ≤ 0. As the note says for the empty E.
  • ι empty: one signing; every level is bad for every c (no_element): 1 ≤ 2 if κ is not empty, 0 ≤ 0 if it is. Lean's evaluation agrees (lines E2, E3 of U3_eval.out).
  • K = 0: the two sets are the same set; the statement reads x ≤ 2x.
  • K beyond the levels that matter: allowed and meaningful (classes modulo 2^(j) of natural numbers for every j); once 2^(j−1) exceeds every position, level j says "at each position the signed sum of the values there is 0", a real condition.
  • All values 0 (κ not empty): every signing is in both sets (all_zero): 2^m ≤ 2·2^m.
  • κ = Unit: the statement is T (T_of_U, derived from U in Lean).

2. U against the note (Theorem U of union-twice.md, §1; notation of theorem-twice.md, §1)

"Level j is bad" of the note = levelBad: level 0 is σ(B) = 0; level j ≥ 1 is "every class at depth j − 1 has halves with equal σ"; Lean lets r run over all r < 2^(j−1), including residues with no element, where both sums are 0, so the note's "if it is not empty" changes nothing. The class r modulo 2^(j−1) has the halves r and r + 2^(j−1) modulo 2^j.

Every difference I see:

  1. No subtracted term. Note: P(B_0 or … or B_k) ≤ 2·P(B_0) − P(G_k). Lean: only ≤ 2·(count for B_0). (Announced.)
  2. No equalities. The note's "P(B_j) = P(G_(j−1)) for 1 ≤ j ≤ k" is not in the Lean statement. The events G_d do not occur in it at all.
  3. Counts, not probabilities: the same after multiplying by 2^(number of elements).
  4. One group V, not a group V_e for each e. Nothing is lost in general: given groups V_c, take V = ∏ V_c and the values Pi.single c (v_c k); "level j is bad" is unchanged by an injective additive map (levelBad_map, proved without sorry), and the note's form comes out (U_family, derived from U; any universes). Nothing is lost for Corollary U either: there all values η_e^b lie in one ring (ℂ, say); the application card_exists_exists_levelBad_le e (fun (c : {d : ℕ // d ∣ 15}) (i : ι) => η c.1 ^ e i) k (η : ℕ → ℂ) type-checks. Conversely the Lean statement is the note's with all V_e equal. What it costs: whoever wants the note's form in Lean must add the few lines of U_family.
  5. Positions in ℕ and K free, against positions in Z_(2^k) and levels 0, …, k. The Lean statement for (pos, K) is the note's for k = K and u_y = pos_y mod 2^K (levels j ≤ K only see pos modulo 2^K). So it is the note's theorem for every k, no more and no less.
  6. E "any set" is κ any type (in any universe). "A finite family of elements" is a Fintype.
  7. Signs are Booleans, true = +.

None of these changes the content apart from 1 and 2, which make the Lean statement weaker than the note's. The positions being the same for every system IS in the Lean statement (one pos), and it is needed: with positions of its own for each system "at most twice" fails (§3, last test).

5. Corollary U as Lean has it, against the note, and tests

card_exists_badAt_le.{u_1} :
  ∀ {ι : Type u_1} [inst : Fintype ι] (e : ι → ℕ) (k : ℕ) {n' : ℕ} (hn' : ¬ 2 ∣ n'),
  (filter (fun ε : ι → Bool => ∃ d : ℕ, d ∣ 2 ^ k * n' ∧ BadAt e ε d) univ).card
    ≤ 2 * (filter (fun ε : ι → Bool => ∃ d : ℕ, d ∣ n' ∧ BadAt e ε d) univ).card
  • ι, [Fintype ι]: the elements, any finite type, empty allowed. e : ι → ℕ: an exponent for each; any natural numbers, not reduced modulo anything, repetitions allowed; THE SAME e on both sides.
  • k : ℕ explicit, any, 0 allowed. n′ : ℕ implicit (found from hn'), with hn' : ¬ 2 ∣ n′: n′ odd, hence n′ ≥ 1 (2 ∣ 0). The number n = 2^k·n′ has no name in the statement; 2 ^ k * n' is (2^k)·n′.
  • BadAt e ε d is Polynomial.cyclotomic d ℤ ∣ P e ε, P e ε = ∑ i, C (sg (ε i)) * X ^ e i in ℤ[X].
  • Left set: the signings for which there is a natural number d dividing 2^k·n′ with Φ_d dividing the signed mask. Right set: the same with d dividing n′. Inequality of natural numbers, left ≤ 2·right.
  • d = 0 cannot occur: 0 divides only 0, and 2^k·n′ ≠ 0, n′ ≠ 0 (divisor_ne_zero, proved). If it could (n′ = 0, which hn' excludes), Mathlib has Φ_0 = 1 and every signing would be bad at 0 (badAt_zero); both sets would be everything.
  • Instances: each filter has fun a => Classical.propDecidable (∃ d, …); Finset.univ as in U.
  • ι empty: P = 0, the one signing is bad at every d (badAt_empty): 1 ≤ 2. One element: no signing is bad anywhere (0 ≤ 0; in my test two_counts((7,), 3, 5) = (0, 0)).
  • k = 0: the two sets are the same; x ≤ 2x.
  • n′ = 1: the right set is "bad at 1", which is "the signs add up to 0" (badAt_one_iff, proved): the statement says that at most twice as many signings are bad at some power of 2 up to 2^k.
  • Axioms now: propext, sorryAx, Classical.choice, Quot.sound.

Against the note (Corollary U of §1). Every difference:

  1. No "− #G". (Announced.) The set G is not in the Lean statement.
  2. Exponents, not a multiset of Z_n; no reduction modulo n′. It is the same statement: BadAt e ε d depends only on the exponents modulo d (Φ_d divides X^d − 1), so for d ∣ n only on e modulo n, and for d ∣ n′ only on e modulo n′. Proved in Lean without sorry: badAt_mod and badAt_mod_of_dvd (U4_mod.lean, axioms propext, Classical.choice, Quot.sound). So for a multiset B of Z_n with representatives e, the left set is "bad on Z_n" for B and the right set, with the same e, is "bad on Z_(n′)" for the reduction B′; and every e arises so. In the tests the two numbers were also recomputed from the exponents reduced modulo n (left) and modulo n′ (right): 0 mismatches in 20,000 random families (15,000 with n′ odd, 5,000 with n′ even; about a quarter of them with exponents up to 9n).
  3. "n′ odd" is ¬ 2 ∣ n′; "n = 2^k·n′" is written out. Every n ≥ 1 is 2^k·n′ in one way, so every Z_n is covered.
  4. Divisors are "d : ℕ with d ∣ …": the positive divisors, as in the note.
  5. Counts of signings; the note's last sentence about shares is the same after dividing by 2^m (one index type on both sides).
  6. m ≥ 0 of the note: ι may be empty.
  7. The hypothesis "n′ odd" is not needed for truth, and costs nothing. For n′ = 2^a·n″ ≠ 0 the divisors of 2^k·n′ are those of 2^(k+a)·n″ and the divisors of n″ are among those of n′; for n′ = 0 both sets are equal. Lean checks this derivation from the statement: whole_any (U2_fit.lean), the same inequality for ALL k, n′.

For speed the remainder of the signed mask is taken as the signed sum of the remainders of its monomials X^(e i) (each by long division, exponents as given, not reduced); compared with one long division of the whole signed mask on 44,503 (family, signing, d) triples in each run. d runs over the divisors of 2^k·n′ on the left and of n′ on the right.

6. Worth knowing before "proved in Lean" is believed of them

  1. What a Lean proof of these two statements certifies is the weak form. Not the term P(G_k) of Theorem U, not #G of Corollary U, not P(B_j) = P(G_(j−1)); and nothing of §3 of the note (no bad signing on the odd part ⇒ none at all DOES follow at once from Corollary U; the shares of §3, 3 to 5, β(m), W_m do not). A sentence "Theorem U / Corollary U of the note is formalised" would overstate; "the inequality with the factor 2" is what is there.
  2. "Multiset on Z_n" and "reduction modulo n′" are a reading of the Lean statement, not in it. The reading is right (badAt_mod_of_dvd), but that lemma is in my scratch file U4_mod.lean, not in the library. If the public wording is to speak of the reduction and say "checked by Lean", the lemma (15 lines) should go into the library. Likewise the note's "a group V_e for each e" is U_family in U2_fit.lean (derived from U), not in the library.
  3. Instances. Both statements are under open Classical: the filters and also Finset.univ on ι → Bool carry classical instances (DecidableEq ι classical inside Pi.instFintype). At ι = Fin m a goal written with the usual instances is not matched by exact (I got "Type mismatch" at Finset.univ), and convert closes it. T (card_exists_levelBad_le) is the same. This is about convenience, not truth.
  4. The hypothesis hn' can be dropped (whole_any); harmless as it is.
  5. After the proofs: #print axioms of both should show no sorryAx, and PrintUnion.lean should print the same text as PrintUnion.skeleton.out; and the two files' statements should be compared with the frozen hashes.
  6. Reach of my tests: U up to 8 elements, 4 systems, six groups, K ≤ 7; Corollary U up to 11 elements, n ≤ 216, n′ ∈ {1, 3, 5, 7, 9, 15, 21, 25, 27}. Small cases only; they would have caught a wrong definition or a wrong quantifier (the false variants fail), not a failure that begins at large sizes. I read the note's proofs of Theorem U and Corollary U (§2) and see no gap, but I was asked to audit statements and did not referee them.
  7. I did not test the subtracted terms (P(G_k), #G), which are not in the Lean statements.
