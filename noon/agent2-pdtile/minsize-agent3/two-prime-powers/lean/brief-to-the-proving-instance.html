The mathematics

M = p^n * q^m, p ≠ q primes. D is an up-set of the divisors of M without 1; L is the set of divisors of M not in D (a down-set containing 1); the corners are the maximal elements of L under divisibility. For c ∣ M, "periodic under c" means g (x + c) = g x for all x : ZMod M.

Theorem. For w : ZMod M → ℕ: Φ_d ∣ maskW w for every d ∈ D if and only if w = ∑_{c corner} g_c with g_c : ZMod M → ℕ periodic under c.

The proof on paper that was written for this theorem is in /home/agent3/pq2/sealed-derivations.md, sections 1 to 4 (read it; it has been refereed). It does an induction that passes to the smaller group Z_{p^{a-1} q^m}. In Lean I would avoid changing the group. Here is a route that stays in ZMod M; I worked it out on paper for this brief and nobody else has checked it, so test each step before you build on it.

Notation. Â(ξ) is hatW. For c ∣ M write Δ_c f (x) = f (x + c) − f (x) for f : ZMod M → ℤ. For ξ of order d (that is, Pqr.ord ξ = d) the character a ↦ stdAddChar (ξ * a) takes the value 1 at a = c if and only if d ∣ c. Three facts carry everything:

  • (F1) Transform of a difference. The transform of Δ_c f at ξ is (χ_ξ(c)⁻¹ − 1) times that of f (or with χ_ξ(−c); fix the sign as it comes). So if f is periodic under c and Pqr.ord ξ ∤ c, then f̂(ξ) = 0.
  • (F2) Injectivity. If an integer-valued (or complex-valued) function on ZMod M has transform 0 at every ξ, it is 0. (Mathlib's ZMod.dft is a linear equivalence; or prove it from orthogonality.) Consequence: if f̂(ξ) = 0 for every ξ whose order does not divide c, then f is periodic under c (apply F2 to Δ_c f).
  • (F3) Splitting. Let A : ZMod M → ℕ and s t : ZMod M with Δ_s Δ_t A = 0 (as integers: A (x+s+t) + A x = A (x+s) + A (x+t) for all x). Put μ x = min over i : ZMod M of A (x + i * s). Then μ is periodic under s, μ ≤ A, and A − μ is periodic under t. (Because A (x + t + i*s) − A (x + i*s) does not depend on i, the minimum over i shifts by the same amount.) No choice of coset representatives is needed.

Induction that stays in the group. For 0 ≤ r ≤ n put M_r = p^r * q^m. Claim(r): if A : ZMod M → ℕ is periodic under M_r and Â(ξ) = 0 whenever Pqr.ord ξ ∈ D, then A is a finite sum of functions ZMod M → ℕ, each periodic under some element of L (it is convenient to prove this weaker-looking form, "some element of L", and to pass to corners only at the very end).

  • Let b be the least v ≤ m with p^r * q^v ∈ D, if there is one.
  • No such v (so M_r ∉ D, M_r ∈ L): A itself is periodic under M_r ∈ L. Done. (This is also how the case D = ∅, r = n comes out: M_n = M and every function is periodic under 0 = (M : ZMod M).)
  • b = 0, r ≥ 1: every p^r * q^v is in D. By F1 Â vanishes at every ξ whose order does not divide M_r; by hypothesis it vanishes at the orders p^r q^v; so it vanishes at every ξ whose order does not divide M_{r-1}, and by F2 A is periodic under M_{r-1}. Apply Claim(r−1). (b = 0, r = 0 cannot happen: 1 ∉ D.)
  • 1 ≤ b ≤ m, r ≥ 1: put s = M_{r-1} = p^{r-1} q^m and t = p^r q^{b-1}; t ∈ L by the choice of b. The transform of Δ_s Δ_t A at ξ of order d is (χ(s)⁻¹−1)(χ(t)⁻¹−1) Â(ξ): if d ∤ M_r then Â(ξ) = 0 by F1; if d ∣ M_r and the exponent of p in d is < r then d ∣ s; if it is r then d = p^r q^v and either v < b, so d ∣ t, or v ≥ b, so d ∈ D (up-set) and Â(ξ) = 0. So Δ_s Δ_t A = 0 by F2. F3 gives A = μ + (A − μ), μ periodic under M_{r-1}, A − μ periodic under t ∈ L. For Pqr.ord ξ = d ∈ D: the transform of A − μ vanishes at ξ when d ∤ t (F1), and when d ∣ t it need not, but then μ̂(ξ) = 0 for another reason when d ∤ M_{r-1} (F1 for μ), and the case d ∣ t, d ∣ M_{r-1} cannot happen: then d ∣ p^{r-1} q^{b-1}, so p^r q^{b-1} is a multiple of d ∈ D dividing M, hence in D, against the choice of b. So μ̂(ξ) = 0 whenever Pqr.ord ξ ∈ D, and Claim(r−1) applies to μ.
  • 1 ≤ b ≤ m, r = 0: Â vanishes at every ξ whose order does not divide q^{b-1} (orders not dividing q^m by F1, orders q^v with v ≥ b by hypothesis and the up-set property), so A is periodic under q^{b-1} ∈ L by F2.

Claim(n) applies to every A (every function is periodic under M_n = M, which is 0 in ZMod M).

From L to the corners. Every c ∈ L divides a corner (take the largest element of L that c divides), and a function periodic under c is periodic under every multiple of c. Group the summands by a chosen corner.

The converse is F1: a corner c is not in D, so d ∈ D does not divide c (else c ∈ D by the up-set property), so the transform of a function periodic under c vanishes at the frequencies of order d; add.

Lower bound. Write w = ∑ g_c. Fix a corner c. For another corner c' ≠ c, c ∤ c' (maximality), so ĝ_{c'} vanishes at the frequencies of order c (F1). If g_c were 0, ŵ would vanish at order c, that is Φ_c ∣ maskW w (c ∣ M), against the hypothesis. So g_c x ≥ 1 for some x, hence on the whole coset x + c·ZMod M, which has M / c elements. Sum over the corners.

Least size. Lower bound: a member w of the set has Φ_d ∣ maskW w for d ∈ D (elements of D divide M and are not 1), and for a corner c: if c ≠ 1, Φ_c ∤ maskW w because c ∉ D; if c = 1, Φ_1 = X − 1 does not divide maskW w because the value at 1 is ∑ w = s > 0. Attained: w = ∑_{c corner} (indicator of the multiples of c), that is w a = #{c corner : (c : ℕ) ∣ a.val}; its size is ∑ M / c, which is positive (there is always a corner, since 1 ∈ L); at ξ of order d its transform is ∑_{c corner, d ∣ c} M / c, a sum of positive numbers, which is 0 exactly when no corner is a multiple of d, that is, when d ∈ D (for d ∣ M: if d ∉ D then d ∈ L divides a corner; if d ∈ D and d ∣ c then c ∈ D).

Practical advice

  • Read Pnq/Weighted.lean lines 1 to 280 and Pqr/ZeroDefs.lean, Pqr/Bridge.lean first; reuse what is there. Pnq/SharpGroup.lean and Pqr/SCBounds.lean show how sums over cosets and Pqr.ord were handled before.
  • A good order of work: (1) state your own lemmas F1, F2, F3 and the claim with sorry, and prove the three fixed theorems from them; (2) then prove the lemmas. That way a gap, if one remains, is small and named.
  • Divisors of p^n * q^m are p^u * q^v (Nat.dvd_mul, Nat.dvd_prime_pow); you may prefer to avoid exponents where you can and argue with divisibility (d ∣ M_r, ¬ d ∣ M_{r-1}, Nat.Coprime), for instance: a divisor d of M_r that does not divide M_{r-1} is p^r * e with e ∣ q^m.
  • Keep casts under control: (c : ZMod M) for a divisor c of M; Pqr.ord ξ ∣ c ↔ (ξ * c = 0) is the kind of lemma to prove once and reuse.
  • Compile often; a single file compiles in a minute or two.
