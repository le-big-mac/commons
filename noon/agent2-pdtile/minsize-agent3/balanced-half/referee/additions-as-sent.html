(A) New end of section 7 (follows Proposition 11 and the paragraph on host levels)

Proposition 11 is one condition, but still a list of three positions. The following is the condition without a list: the picture of the note ("a balanced nonempty class in a position where it can serve as the extra fibre") made exact.

Fibre classes. A class Z is a fibre class of a multiset if every class contained in Z, Z itself included, is balanced. (Then the part of the multiset inside Z consists of whole fibres, and conversely.)

Lemma 12 (rearranging fibre classes). Let A be a multiset and 𝒵 a set of pairwise disjoint fibre classes of A. Let A′ be a multiset that agrees with A outside the union of 𝒵 and for which every Z ∈ 𝒵 is again a fibre class, with the same total as in A. Then

  • (i) every class that is not properly contained in a member of 𝒵 has the same vector in A and in A′;
  • (ii) A′ is balanced iff A is, and for every level a ≥ 1: a ∈ F(A′) iff a ∈ F(A);
  • (iii) a level a is in E(A′) iff every class of depth a − 1 that is not contained in a member of 𝒵 has children of equal totals in A, and every class of depth a − 1 that is contained in a member of 𝒵 has children of equal totals in A′.

Proof. Two classes are nested or disjoint. (i) Let N be a class not properly contained in a member of 𝒵. Each Z ∈ 𝒵 is then disjoint from N or contained in N. The vector of N is the vector of its part outside the union of 𝒵, which is the same for A and A′, plus the vectors of the Z ⊆ N; and each such Z has a constant vector with the same total in A and A′, hence the same vector. (ii), (iii) The root is not properly contained in a class, so its vector is unchanged. Let N have depth a − 1. If N is not contained in a member of 𝒵, no child of N is properly contained in a member Z (such a Z would have depth ≤ a − 1 and contain the child, hence contain N). So by (i) the children of N have the same vectors in A and A′: equal shapes, or equal totals, in one iff in the other. If N is contained in a member of 𝒵, its children are balanced both in A and in A′, so they have equal shapes in both. ∎

Proposition 13. Let (E, F) be a pattern with 0 ∈ F, F ≠ {0, …, n} and k′ ≥ 1, and let E⁺ = E ∪ G′ (the levels of F∖E beyond a₀ moved into E). Then x = 0 if and only if

(✦) some balanced multiset with exact pattern (E⁺, F) and exactly q·p^(e+k′) elements has a nonempty fibre class of depth < g₁.

(q p^(e+k′) is the least size for the pattern (E⁺, F), by Theorems B and C: that pattern has |E⁺| = e + k′ and no level of F∖E⁺ beyond a₀.) In words: x = 0 exactly when a least multiset for the pattern in which the levels of G′ are not yet distinguished can have a free fibre class above all of them; concentrating the fibres of that class then makes the totals unequal at the levels of G′ at no cost.

Proof. (✦) ⇒ x = 0. Let A⁺ be such a multiset and Z such a class, of depth d ≤ g₁ − 1; so G′ ⊆ (d, n]. Lemma 2 for Z with the set {a − d : a ∈ E⁺, a > d} ⊆ E(Z) shows that q·p^(|E ∩ (d, n]| + k′) divides |Z|; so m = |Z| / (q·p^|E ∩ (d, n]|) is a positive integer. Let D_Z be the set of strings that have the prefix of Z, free digits at the levels of E ∩ (d, n], and 0 at the other levels beyond d; let A agree with A⁺ outside Z and be m·Fib(D_Z) inside Z. Then Z is a fibre class of A with |Z| elements, |A| = |A⁺|, and by Lemma 12 (with 𝒵 = {Z}) A is balanced with F(A) = F. For E(A) use Lemma 12(iii), and for the classes inside Z the two properties of m·Fib(D_Z) that are read off as in Lemma 8: at a level a > d that is in E the children of a class inside Z contain equally many strings of D_Z; at a level a > d not in E all strings of D_Z in a class lie in its child N_0. a ≤ d: no class of depth a − 1 is contained in Z, so a ∈ E(A) iff a ∈ E(A⁺) = E⁺ iff a ∈ E (a ≤ d < g₁, so a ∉ G′). a > d, a ∈ E: classes of depth a − 1 not in Z have children of equal totals in A⁺ (a ∈ E⁺); those in Z, in A. So a ∈ E(A). a > d, a ∉ E: the class of depth a − 1 inside Z whose digits at the levels d + 1, …, a − 1 are 0 meets D_Z and has all its elements in N_0; so a ∉ E(A). So A has exact pattern (E, F) and q p^(e+k′) elements, and the lower bound of Theorem B gives q p^e (p^k′ + x) ≤ q p^(e+k′): x = 0.

x = 0 ⇒ (✦). Since k′ ≥ 1 and x = 0, the multiset A of Theorem C is built by case (III), (IV) or (V). Let h be its host level (b, a₀, b) and i₀ = 1 in cases (III), (V), i₀ = 2 in case (IV). Let 𝒵 be the set of nonempty classes of depth h whose digit of level h is ≥ i₀. By the proof of Theorem C each Z ∈ 𝒵 is Φ_i-only for its digit i: the part of A inside Z is p^k′·Fib of the strings that have the prefix of Z, free digits on E ∩ (h, n], and 0 elsewhere beyond h. So Z is a fibre class with q p^(k′ + |E ∩ (h, n]|) elements. Let A⁺ agree with A outside the union of 𝒵 and be, inside each Z ∈ 𝒵, Fib(D_Z⁺), D_Z⁺ the strings with the prefix of Z, free digits on (E ∪ G′) ∩ (h, n] and 0 elsewhere beyond h. Because h < g₁, G′ ⊆ (h, n], and G′ ∩ E = ∅; so Z has the same total q p^(|E ∩ (h,n]| + k′) in A⁺. By Lemma 12, A⁺ is balanced, F(A⁺) = F, and |A⁺| = |A| = q p^(e+k′). E(A⁺), by Lemma 12(iii): a ≤ h: no class of depth a − 1 is contained in a member of 𝒵; so a ∈ E(A⁺) iff a ∈ E(A) = E iff a ∈ E⁺ (a < g₁). a > h, a ∈ E: all classes of depth a − 1 have children of equal totals in A (a ∈ E(A)); inside a member of 𝒵 the digit of level a is free in D_Z⁺. So a ∈ E(A⁺). a > h, a ∈ G′: a class of depth a − 1 not contained in a member of 𝒵 is S-only, or it is Φ_i-only and empty (a nonempty Φ_i-only class lies in the nonempty Φ_i-only class of depth h above it, a member of 𝒵). If empty, its children have equal totals. If S-only: a ∈ F ∩ (a₀, n] = T₂∖H for the shape part of each of the three cases, so its children have equal vectors by (S4). Inside a member of 𝒵 the digit of level a is free in D_Z⁺. So a ∈ E(A⁺). a > h, a ∉ E⁺: the class Y of depth h with digit i₀ at level h and 0 elsewhere is a member of 𝒵 (it is not empty: it contains the fibres over the string with digit i₀ at level h and 0 elsewhere, a string of D(E∖{h}; h↦i₀)). The class of depth a − 1 inside Y with digits 0 at the levels h + 1, …, a − 1 meets D_Y⁺ and has all its elements in N_0. So a ∉ E(A⁺). So A⁺ has exact pattern (E⁺, F), q p^(e+k′) elements, and the nonempty fibre class Y of depth h < g₁. ∎

The size condition in (✦) cannot be dropped, and the pattern (E⁺, F) cannot be replaced by (E, F) with "some multiset": for p = 2, q = 3, E = {2}, F = {0, 3} (x = 1, least size 18) the multiset of 36 elements with classes of depth 2 equal to (6,0,0), (2,2,2), (0,6,6), (4,4,4) (in the order of the prefixes 00, 01, 10, 11), each (6,0,0) or (0,6,6) split into two equal halves and each (2,2,2), (4,4,4) put in one child, has exact pattern (E, F) and a nonempty fibre class of depth 2 < g₁ = 3.

Appendix. The tree conditions and the cyclotomic divisors

This is standard (it is section 1 of the note, which cites the paper's lemma and de Bruijn's theorem for it). It is proved here only so that Theorems A and B hold for the pattern as the note defines it. Let A(X) = Σ_(0 ≤ x < M) A(x) X^x be the mask polynomial; an element x ∈ Z_M is the pair (u, w) = (x mod pⁿ, x mod q).

Claim. For 1 ≤ a ≤ n: Φ_{p^a} | A(X) iff a ∈ E, and Φ_{p^a q} | A(X) iff a ∈ F(root). And Φ_q | A(X) iff the root is balanced.

For a function B: Z_N → Z and r ∈ Z_N write (∇r B)(y) = B(y) − B(y − r) and B(X) = Σ(0 ≤ y < N) B(y) X^y.

Lemma T. Let N ≥ 2 and let r_1, …, r_m be proper divisors of N such that every proper divisor of N divides one of them. Then Φ_N(X) divides B(X) iff ∇(r_1) ⋯ ∇(r_m) B = 0.

Proof. Let C(X) = (X^(r_1) − 1) ⋯ (X^(r_m) − 1)·B(X). Multiplying by X^r shifts the coefficients cyclically by r modulo X^N − 1, so (X^r − 1)·B(X) ≡ −Σ_y (∇r B)(y) X^y and C(X) ≡ (−1)^m Σ_y (∇(r_1) ⋯ ∇(r_m) B)(y) X^y mod (X^N − 1), and the right side has degree < N. Hence ∇(r_1) ⋯ ∇_(r_m) B = 0 iff X^N − 1 divides C(X) iff C(ζ) = 0 for each of the N distinct roots ζ of X^N − 1. If ζ has order d < N, then d divides some r_i, ζ^(r_i) = 1 and C(ζ) = 0. If ζ has order N, no ζ^(r_i) is 1, and C(ζ) = 0 iff B(ζ) = 0. So the condition is: B(ζ) = 0 for every primitive N-th root of unity ζ; and that is Φ_N | B(X), since Φ_N is the monic polynomial with exactly these roots, all simple (divisibility in Q[X], which for a monic divisor with integer coefficients is divisibility in Z[X]). ∎

Proof of the Claim. For N | M let B_N(y) = Σ_(x ≡ y mod N) A(x). Then A(X) ≡ B_N(X) mod (X^N − 1), and Φ_N divides X^N − 1; so Φ_N | A(X) iff Φ_N | B_N(X).

N = p^a (1 ≤ a ≤ n), m = 1, r_1 = p^(a−1): every proper divisor of p^a divides p^(a−1). B_N(y) is the total of the class of depth a consisting of the x with u ≡ y mod p^a. ∇(r_1) B_N = 0 says that B_N is constant on each coset of p^(a−1)Z(p^a), that is: for every class of depth a − 1 (a residue mod p^(a−1)) the p classes of depth a inside it have equal totals. That is a ∈ E.

N = q, m = 1, r_1 = 1. B_q(w) is the entry at layer w of the vector of the root, and ∇_1 B_q = 0 says the root is balanced.

N = p^a q (1 ≤ a ≤ n), m = 2, r_1 = N/p, r_2 = N/q = p^a: a proper divisor of N lacks a factor p or the factor q, so it divides r_1 or r_2. Identify Z_N with Z_(p^a) × Z_q by y ↦ (c, w) = (y mod p^a, y mod q); then B_N(c, w) is the entry at layer w of the vector of the class of depth a with u ≡ c mod p^a. Subtracting r_1 from y changes (c, w) to (c − σ, w) with σ = p^(a−1) q mod p^a, an element of order p in Z_(p^a) (p ∤ q), so that c, c − σ, c − 2σ, … run through the p residues mod p^a in the class of c mod p^(a−1). Subtracting r_2 changes (c, w) to (c, w − θ) with θ = p^a mod q ≠ 0, a generator of Z_q. So ∇(r_2) ∇(r_1) B_N = 0 says: for every c the vector V_c = g(class c) − g(class c − σ) satisfies V_c(w) = V_c(w − θ) for all w, that is, V_c is constant: the classes c and c − σ of depth a have equal shapes. For the p children of a class of depth a − 1, "each has the shape of the next one" is the same as "all have equal shapes". That is a ∈ F(root). ∎
