0. What is proved here

Let p ≠ q be primes, n ≥ 1, M = pⁿq, and A a nonempty multiset on Z_M with exact pattern (E, F) (definitions in section 1), e = |E|. Assume 0 ∈ F (A is balanced).

  • Theorem A. If F = {0, 1, …, n}, the least possible |A| is q·p^e.
  • Theorem B. If F ≠ {0, 1, …, n}, let a₀ be the smallest level in 1..n not in F, k′ the number of levels a > a₀ that are in F and not in E, and x ∈ {0, 1} as in the rule (x = 0 iff one of the clauses (1) to (4) holds). Then the least possible |A| is q·p^e·(p^k′ + x).
  • Lower bound (section 5): every balanced A with exact pattern (E, F) has |A| ≥ q·p^e·(p^k′ + x).
  • Upper bound (section 6): for every pattern, every p ≠ q and every n an explicit multiset with exactly that pattern and exactly q·p^e·(p^k′ + x) elements.

So the conjecture is true as stated, for all primes p ≠ q and all n ≥ 1; no counterexample exists. The tool for the lower bound is a statement about the set of possible sizes of an unbalanced class (Lemmas 3, 4, 5), which is stronger than a bound on the least size and passes cleanly through the induction over the tree. As a by-product it gives a second, shorter proof of both lower bounds of the unbalanced half (Remark after Lemma 4). Section 7 restates the four clauses as one condition ("a host level").

1. Setting, notation, conventions

The group. Z_M = Z_{pⁿ} × Z_q. Write u ∈ Z_{pⁿ} in base p, u = Σ_{a=1..n} u_a p^(a−1) with digits u_a ∈ {0, …, p−1}; u_a is the digit of level a. An element is a pair (u, w), w ∈ Z_q its layer. A multiset A is a function Z_M → {0, 1, 2, …}; |A| is the sum of its values. Sums of multisets are sums of functions.

Classes. For 0 ≤ d ≤ n a class of depth d is the set of all (u, w) whose digits u_1, …, u_d have prescribed values (its prefix); equivalently a residue class of u mod p^d. The class of depth 0 is the whole group (the root). A class N of depth d < n has p children: the classes of depth d+1 inside it, one for each value of u_(d+1); N_j denotes the child with u_(d+1) = j. A class of depth d has n − d levels below it; its own level l (1 ≤ l ≤ n − d) is the level d + l of the group. (The task statement says "node" for class.)

Vectors. For a class N, g(N) ∈ N^q is the vector whose entry at w is the number of elements of A in N in layer w (with multiplicity). |N| = |g(N)| is the sum of the entries, the total of N. For any integer vector x, |x| denotes the sum of its entries. 1 = (1, …, 1). N is empty if g(N) = 0; balanced if g(N) is a constant vector (a multiple of 1; an empty class is balanced); unbalanced otherwise (an unbalanced class is not empty). Two classes have equal shapes if their vectors differ by a multiple of 1. The vector of a class is the sum of the vectors of its children.

Patterns. For a class N of depth d and 1 ≤ l ≤ n − d:

  • l ∈ E(N) iff every class of depth d + l − 1 contained in N has p children of equal totals;
  • l ∈ F(N) iff every class of depth d + l − 1 contained in N has p children of equal shapes.

(E(N), F(N)) is the pattern of N (on its own levels). The pattern of A is (E, F) with E = E(root) and F = F(root) ∪ {0 if the root is balanced}. This is the definition of the task statement. For classes other than the root I never put 0 into F(N); I say "balanced" or "unbalanced" in words.

Reference patterns. A pair (E, F) of subsets of {1, …, j} is contained in the pattern of N (N with j levels below it) if E ⊆ E(N) and F ⊆ F(N). All lemmas below are stated for a pair contained in the pattern of a class, not for the exact pattern; this is what makes the inductions work. For such a pair the shifted pair is

E⁻ = {l − 1 : l ∈ E, l ≥ 2}, F⁻ = {l − 1 : l ∈ F, l ≥ 2}.

(0) If (E, F) is contained in the pattern of N, then (E⁻, F⁻) is contained in the pattern of every child of N. Indeed for l ≥ 2 the classes of depth (d+1) + (l−1) − 1 = d + l − 1 inside a child of N are among the classes of depth d + l − 1 inside N. Also |E⁻ ∪ F⁻| = |E ∪ F| − 1 if 1 ∈ E ∪ F, and = |E ∪ F| otherwise.

Three sets of integers. For an integer u ≥ 0 put

S_u = {p^u·t + q·m : t ≥ 1, m ≥ 0}, S_u⁺ = {p^u·t + q·m : t ≥ 1, m ≥ 1}, Q_u = {q·p^u·t : t ≥ 1}

(t, m integers). The arithmetic used later, each line checked by writing out the definition:

  • (A1) for u ≥ 1: p·S_(u−1) ⊆ S_u, p·S_(u−1)⁺ ⊆ S_u⁺, p·Q_(u−1) ⊆ Q_u. [p(p^(u−1) t + q m) = p^u t + q(pm).]
  • (A2) S_u + S_u ⊆ S_u; S_u + qZ_(≥0) ⊆ S_u; S_u⁺ + S_u ⊆ S_u⁺; S_u⁺ + qZ_(≥0) ⊆ S_u⁺; S_u + qZ_(≥1) ⊆ S_u⁺.
  • (A3) Q_u + S_u ⊆ S_u⁺ and Q_u + qZ_(≥1) ⊆ S_u⁺. [q p^u t′ + p^u t + q m = p^u t + q(p^u t′ + m) with t ≥ 1 and p^u t′ + m ≥ 1. And for m ≥ 1: q p^u t′ + q m = p^u·q + q(p^u (t′ − 1) + m), with q ≥ 1 in the place of t and p^u(t′ − 1) + m ≥ 1.]
  • (A4) if x ∈ S_u and q | x, then x ∈ Q_u ∪ S_u⁺ and x ≥ q p^u. [x = p^u t + q m with t ≥ 1; q divides p^u t; q is a prime other than p, so q | t and t ≥ q. If m = 0 then x = q p^u (t/q) ∈ Q_u; if m ≥ 1 then x ∈ S_u⁺ by definition. In both cases x ≥ p^u t ≥ q p^u.]
  • (A5) if x ∈ S_u⁺ and q | x, then x ≥ q p^u + q. [As in (A4): t ≥ q, and m ≥ 1.]

2. Two elementary lemmas

Lemma 1 (children of equal shapes). Let N be a class whose p children have equal shapes, and let v be the vector of a child of least total. Then

  • (a) the children have vectors v + d_i·1 (i = 1..p) with integers d_i ≥ 0; g(N) = p·v + (Σ d_i)·1 and |N| = p·|v| + q·Σ d_i; the children have equal totals iff Σ d_i = 0;
  • (b) N is balanced iff v is constant iff every child is balanced. In particular, if N is unbalanced then every child is unbalanced (hence nonempty), and if N is balanced every child is balanced.
  • (c) If A is balanced and the levels 1, …, a₀ − 1 are all in F, then every class of depth ≤ a₀ − 1 is balanced.

Proof. (a) Equal shape with v means g(child i) − v = d_i·1 with d_i an integer; its total is q d_i ≥ 0 because v has least total. Summing over the children gives g(N) and |N|; the totals are |v| + q d_i, all equal iff all d_i = 0 (one of them is 0). (b) g(N) = p v + (Σ d_i) 1 is constant iff p v is constant iff v is constant iff v + d_i 1 is constant (for each i). (c) Induction on the depth: the root is balanced; a class of depth d ≤ a₀ − 1, d ≥ 1, is a child of a class of depth d − 1, which is balanced by induction and whose children have equal shapes because level d ∈ F; apply (b). ∎

Lemma 2 (divisibility). Let N be a class and E a set contained in E(N). Then p^|E| divides |N|. If N is balanced, q·p^|E| divides |N|.

Proof. Induction on the number j of levels below N; for j = 0, E = ∅. For j ≥ 1: E⁻ ⊆ E(child) for each child by (0), so p^|E⁻| divides each child's total. If 1 ∉ E then |E⁻| = |E| and |N| is a sum of multiples of p^|E|. If 1 ∈ E the children have equal totals s, p^(|E|−1) | s and |N| = p s. If N is balanced, q | |N| as well, and q, p are coprime. ∎

3. The sizes of unbalanced classes

Lemma 3. Let N be an unbalanced class, (E, F) a pair contained in its pattern, u = |E ∪ F|. Then |N| ∈ S_u.

Proof. Induction on the number j of levels below N. If j = 0 then u = 0 and S_0 = Z_(≥1) ∋ |N|. Let j ≥ 1 and let u⁻ = |E⁻ ∪ F⁻|; by (0) the induction hypothesis applies to every unbalanced child with the pair (E⁻, F⁻).

  • 1 ∈ F. Then u⁻ = u − 1. The children have equal shapes; by Lemma 1 the child v of least total is unbalanced and |N| = p|v| + q Σ d_i with Σ d_i ≥ 0. By induction |v| ∈ S_(u−1), so |N| ∈ p·S_(u−1) + qZ_(≥0) ⊆ S_u by (A1), (A2).
  • 1 ∈ E, 1 ∉ F. Then u⁻ = u − 1. The children have one total s and |N| = p s. Some child is unbalanced (a sum of constant vectors is constant). By induction s ∈ S_(u−1), so |N| ∈ S_u by (A1).
  • 1 ∉ E, 1 ∉ F. Then u⁻ = u. Some child is unbalanced, and its total is in S_u by induction. Every other child is unbalanced with total in S_u, or balanced with total in qZ_(≥0). By (A2) the sum is in S_u. ∎

In particular |N| ≥ p^|E ∪ F| (this is Claim U of the note).

Witnesses. Let N be a class of depth d with j levels below it and 1 ≤ g ≤ j. N has a witness at level g if some class Γ of depth d + g − 1 contained in N has children of unequal totals (so g ∉ E(N)). Such a Γ is not empty. If g ≥ 2, Γ lies in exactly one child N_c of N, N_c is not empty, and N_c has a witness at its own level g − 1.

Lemma 4. Let N be an unbalanced class, (E, F) a pair contained in its pattern, u = |E ∪ F|, and suppose N has a witness at some level g ∈ F. Then |N| ∈ S_u⁺ ∪ Q_u.

Proof. Induction on the number j of levels below N; for j = 0 there is no g and nothing to prove. Let j ≥ 1, u⁻ = |E⁻ ∪ F⁻|, Γ the witness class.

  • 1 ∈ F. Then u⁻ = u − 1; by Lemma 1 every child is unbalanced and |N| = p|v| + q Σ d_i, v the child of least total, |v| ∈ S_(u−1) by Lemma 3. If Σ d_i ≥ 1: |N| ∈ p S_(u−1) + qZ_(≥1) ⊆ S_u⁺ by (A1), (A2). If Σ d_i = 0: the children of N have equal totals, so Γ ≠ N, so g ≥ 2; Γ lies in a child N_c, which is unbalanced and has a witness at its level g − 1 ∈ F⁻. By induction |N_c| ∈ S_(u−1)⁺ ∪ Q_(u−1), and |N| = p|N_c| ∈ S_u⁺ ∪ Q_u by (A1).
  • 1 ∈ E, 1 ∉ F. Then u⁻ = u − 1, g ≠ 1 (because g ∈ F), the children have one total s, |N| = p s, and Γ lies in a nonempty child N_c, which has a witness at its level g − 1 ∈ F⁻. If N_c is unbalanced, s = |N_c| ∈ S_(u−1)⁺ ∪ Q_(u−1) by induction. If N_c is balanced, q | s. Some child of N is unbalanced, so s ∈ S_(u−1) by Lemma 3, and then s ∈ Q_(u−1) ∪ S_(u−1)⁺ by (A4). In both cases |N| = p s ∈ S_u⁺ ∪ Q_u by (A1).
  • 1 ∉ E, 1 ∉ F. Then u⁻ = u, g ≥ 2, and Γ lies in a nonempty child N_c with a witness at its level g − 1 ∈ F⁻. Let R be the sum of the totals of the other children. Each other child is unbalanced with total in S_u (Lemma 3) or balanced with total in qZ_(≥0). If N_c is unbalanced and |N_c| ∈ S_u⁺: |N| ∈ S_u⁺ by (A2). If N_c is unbalanced and |N_c| ∈ Q_u: if R = 0 then |N| ∈ Q_u; if some other child is unbalanced then R ∈ S_u by (A2) and |N| ∈ Q_u + S_u ⊆ S_u⁺ by (A3); otherwise R ∈ qZ_(≥1) and |N| ∈ Q_u + qZ_(≥1) ⊆ S_u⁺ by (A3). If N_c is balanced: |N_c| ∈ qZ_(≥1); N is unbalanced, so some other child is unbalanced, with total in S_u; so |N| ∈ S_u + qZ_(≥1) + (S_u or qZ_(≥0) terms) ⊆ S_u⁺ by (A2). ∎

Remark (the unbalanced half again). Lemmas 2, 3, 4 give the lower bounds of section 2 of the note without its four-case argument. Let A be unbalanced with exact pattern (E, F), e = |E|, k = |F∖E| ≥ 1, u = e + k. A level g ∈ F∖E is a witness level, so |A| ∈ S_u⁺ ∪ Q_u. If |A| = p^u t + q m with t, m ≥ 1, then p^e divides |A| and p^u t, hence q m, hence m; so m ≥ p^e and |A| ≥ p^u + q p^e = p^e(p^k + q). If |A| ∈ Q_u then |A| ≥ q p^(e+k) ≥ p^e(p^k + q), because q p^k − p^k − q = (q − 1)(p^k − 1) − 1 ≥ 0. (This remark is not used below.)

Lemma 5. Let N be an unbalanced class, (E, F) a pair contained in its pattern, u = |E ∪ F|. Suppose N has a witness at a level g ∈ F, and no level l < g lies in E∖F. Then |N| ∈ S_u⁺.

Proof. Induction on j; nothing to prove for j = 0. Let j ≥ 1 and Γ the witness class. If g ≥ 2, the child N_c containing Γ has a witness at its level g − 1 ∈ F⁻, and no level l′ < g − 1 lies in E⁻∖F⁻ (else l′ + 1 < g would lie in E∖F); so if N_c is unbalanced the induction hypothesis applies to it with the pair (E⁻, F⁻).

  • 1 ∈ F. As in Lemma 4: |N| = p|v| + q Σ d_i with |v| ∈ S_(u−1). If Σ d_i ≥ 1, |N| ∈ S_u⁺. If Σ d_i = 0 then g ≥ 2, N_c is unbalanced (Lemma 1), |N_c| ∈ S_(u−1)⁺ by induction, and |N| = p|N_c| ∈ S_u⁺ by (A1).
  • 1 ∈ E, 1 ∉ F. This case does not occur: g ∈ F gives g ≠ 1, so g ≥ 2, and level 1 < g would lie in E∖F.
  • 1 ∉ E, 1 ∉ F. Then u⁻ = u and g ≥ 2. If N_c is unbalanced, |N_c| ∈ S_u⁺ by induction, the other children have totals in S_u or in qZ_(≥0), and |N| ∈ S_u⁺ by (A2). If N_c is balanced, |N_c| ∈ qZ_(≥1) and some other child is unbalanced with total in S_u, so |N| ∈ S_u⁺ by (A2). ∎

Lemma 5 is false without its hypothesis: for p = 2, q = 3 the class with children (6,0,0) = (3,0,0) + (3,0,0) and (2,2,2) = (2,2,2) + (0,0,0) has vector (8,2,2), E = {1}, F = {2}, u = 2, and 12 elements; 12 = q p^u is in Q_2 and not in S_2⁺. The balanced child (2,2,2) is the "free fibre" of the note's picture.

4. Balanced classes whose children have unequal shapes

Lemma 6. Let N be a balanced class whose p children do not all have equal shapes, (E, F) a pair contained in the pattern of N, u = |E ∪ F|. Then |N| ≥ q·p^u.

Proof. Some child is unbalanced (balanced children all have equal shapes). N is balanced, so q | |N|. If 1 ∈ E: the children have one total s, p s = |N|, so q | s. Here 1 ∉ F (the children have unequal shapes), so |E⁻ ∪ F⁻| = u − 1 and s ∈ S_(u−1) by Lemma 3 applied to an unbalanced child; by (A4) s ≥ q p^(u−1), and |N| = p s ≥ q p^u. If 1 ∉ E: |E⁻ ∪ F⁻| = u (again 1 ∉ F). The totals of the unbalanced children are in S_u, those of the balanced ones in qZ_(≥0); by (A2) |N| ∈ S_u, and q | |N|; by (A4) |N| ≥ q p^u. ∎

Proposition 7. Let A be balanced with exact pattern (E, F), F ≠ {0, …, n}, and a₀, k′ as in Theorem B. Then |A| ≥ q·p^(e + k′).

Proof. Level a₀ ∉ F: some class P of depth a₀ − 1 has children of unequal shapes. By Lemma 1(c), P is balanced. The pair E_P = {a − a₀ + 1 : a ∈ E, a ≥ a₀}, F_P = {a − a₀ + 1 : a ∈ F, a > a₀} is contained in the pattern of P (a level a ≥ a₀ of the group is the own level a − a₀ + 1 of P, and "every class of depth a − 1" includes those inside P). E_P and F_P∖E_P are disjoint, F_P ∩ E_P ⊆ E_P, so |E_P ∪ F_P| = |E ∩ [a₀, n]| + k′. By Lemma 6, |P| ≥ q p^(|E ∩ [a₀, n]| + k′). Let P = P_(a₀−1) ⊂ P_(a₀−2) ⊂ … ⊂ P_0 = root be the classes containing P, P_d of depth d. For 1 ≤ d ≤ a₀ − 1: |P_(d−1)| ≥ |P_d|, and if d ∈ E then P_(d−1) has p children of equal totals, one of them P_d, so |P_(d−1)| = p|P_d|. Hence |A| ≥ p^(|E ∩ [1, a₀−1]|)·|P| ≥ q p^(e + k′). ∎

5. The theorems: lower bounds

Theorem A (lower bound). If A is balanced with exact pattern (E, F), then |A| ≥ q p^e. (Lemma 2 for the root.)

The rule, for reference. F ≠ {0, …, n}; a₀ = the least level in 1..n not in F; G′ = (F∖E) ∩ (a₀, n], k′ = |G′|; if k′ ≥ 1, g₁ = min G′. x = 0 if at least one of

  • (1) k′ = 0;
  • (2) some level in 1..a₀ − 1 is in E;
  • (3) a₀ ∈ E and p ≥ 3;
  • (4) a₀ ∈ E, p = 2, and some level b with a₀ < b < g₁ is in E and not in F

holds, and x = 1 otherwise.

Theorem B (lower bound). Let A be balanced with exact pattern (E, F), F ≠ {0, …, n}. Then |A| ≥ q·p^e·(p^k′ + x).

Proof. If x = 0 this is Proposition 7. Let x = 1. Then none of (1) to (4) holds:

  • k′ ≥ 1, so g₁ exists;
  • E ∩ [1, a₀ − 1] = ∅;
  • either (α) a₀ ∉ E, or (β) a₀ ∈ E, p = 2, and no level b with a₀ < b < g₁ lies in E∖F.

As in Proposition 7 let P be a class of depth a₀ − 1 with children of unequal shapes; P is balanced, and the pair (E_P, F_P) defined there is contained in the pattern of every class of depth a₀ − 1. Now |E_P| = e (no level of E is above a₀) and |E_P ∪ F_P| = e + k′.

Step 1: another nonempty class of depth a₀ − 1. Suppose a class P′ ≠ P of depth a₀ − 1 is not empty. P′ is balanced (Lemma 1(c)) and E_P ⊆ E(P′), so q p^e divides |P′| (Lemma 2) and |P′| ≥ q p^e. By Lemma 6, |P| ≥ q p^(e+k′). So |A| ≥ |P| + |P′| ≥ q p^e (p^k′ + 1).

Step 2: P is the only nonempty class of depth a₀ − 1. Then |A| = |P|. Since g₁ ∈ F∖E, some class Γ of depth g₁ − 1 has children of unequal totals; Γ is not empty, so Γ ⊆ P; and g₁ − 1 ≥ a₀, so Γ lies in a child N_c of P. The children of P have depth a₀; by (0) the pair

E⁻ = {a − a₀ : a ∈ E, a > a₀}, F⁻ = {a − a₀ : a ∈ F, a > a₀}

is contained in the pattern of each of them. Put u⁻ = |E⁻ ∪ F⁻| = |E ∩ (a₀, n]| + k′. The class N_c has a witness at its own level g := g₁ − a₀, and g ∈ F⁻.

Case (α): a₀ ∉ E. Then |E⁻| = e and u⁻ = e + k′. At least one child of P is unbalanced (the children do not all have equal shapes).

  • If some child N_b of P is balanced and not empty: q p^e divides |N_b| (Lemma 2 with E⁻), so |N_b| ≥ q p^e. Let Σ be the sum of the totals of the unbalanced children; Σ ∈ S_(u⁻) by Lemma 3 and (A2); the balanced children and P have totals divisible by q, so q | Σ; by (A4) Σ ≥ q p^(u⁻). Hence |A| ≥ Σ + |N_b| ≥ q p^(e+k′) + q p^e.
  • Otherwise every nonempty child of P is unbalanced. In particular N_c is unbalanced, and by Lemma 4 |N_c| ∈ S_(u⁻)⁺ ∪ Q_(u⁻). Since g(P) is constant and g(N_c) is not, the other children do not sum to a constant vector, so some other child is unbalanced; let R ≥ 1 be the sum of the totals of the children other than N_c; R ∈ S_(u⁻) by Lemma 3 and (A2). If |N_c| ∈ Q_(u⁻): |P| = |N_c| + R ≥ q p^(u⁻) + 1. If |N_c| ∈ S_(u⁻)⁺: |P| ∈ S_(u⁻)⁺ by (A2), and q | |P|, so |P| ≥ q p^(u⁻) + q by (A5). Either way |P| > q p^(e+k′). By Lemma 2, q p^e divides |P| (P is balanced, |E_P| = e); it also divides q p^(e+k′). So |P| − q p^(e+k′) is a positive multiple of q p^e, and |A| = |P| ≥ q p^e(p^k′ + 1).

Case (β): a₀ ∈ E, p = 2, no level of E∖F strictly between a₀ and g₁. Then |E⁻| = e − 1 and u⁻ = e − 1 + k′. P has two children N_1, N_2 with one total s (level a₀ ∈ E), |P| = 2s, and q | |P| with q odd (q ≠ p = 2), so q | s. g(N_1) + g(N_2) is constant; if one of the two were constant so would the other be, and they would have equal shapes; so both are unbalanced. N_c is one of them, it has a witness at its level g ∈ F⁻, and no level l < g lies in E⁻∖F⁻ (then a₀ + l would be a level of E∖F with a₀ < a₀ + l < g₁). By Lemma 5, s = |N_c| ∈ S_(u⁻)⁺; with q | s, (A5) gives s ≥ q p^(u⁻) + q > q p^(u⁻). By Lemma 2 p^(e−1) | s, so q p^(e−1) | s, and q p^(e−1) | q p^(u⁻); hence s ≥ q p^(u⁻) + q p^(e−1), and |A| = p s ≥ q p^(e+k′) + q p^e. ∎

Where the clauses enter. Clause (2) is the reason Step 1 needs E ∩ [1, a₀−1] = ∅ (otherwise |P′| is forced only by an E-level above a₀, which gives a factor p and no summand). Clause (3): in case (β) with p ≥ 3 the child N_c that contains the witness may be balanced, and then nothing forces s above q p^(u⁻). Clause (4): Lemma 5 needs "no level of E∖F above g"; with such a level, the second case of Lemma 4 (a balanced child at a level of E∖F) allows the size q p^u.

6. The constructions: upper bounds, with exactness

6.1 Strings and fibres

For a set T of levels, D(T) = {u ∈ Z_{pⁿ} : u_a = 0 for every a ∉ T}. For a level b ∉ T and a digit c, D(T; b↦c) = {u : u_b = c, u_a = 0 for every a ∉ T ∪ {b}}. Both have p^|T| elements. For a set D of strings and m ≥ 1, m·Fib(D) is the multiset with m copies of (u, w) for every u ∈ D and every w ∈ Z_q.

Lemma 8 (fibres). Let Φ = m·Fib(D), D = D(T) or D(T; b↦c), and N a class of depth d.

  • (i) g_Φ(N) = m·#(D ∩ N)·1, a constant vector.
  • (ii) N meets D iff the prefix of N has u_a = 0 at every level a ≤ d outside T ∪ {b}, and u_b = c if b ≤ d. Then #(D ∩ N) = p^|T ∩ (d, n]|.
  • (iii) If a = d + 1 ∈ T, the p children of N contain equally many strings of D.
  • (iv) If a = d + 1 ∉ T, all strings of D in N lie in one child: N_0 if a ≠ b, N_c if a = b.

Proof. A string of D lies in N iff its first d digits are the prefix of N; the strings of D are exactly those with free digits on T and the prescribed digits elsewhere. All four statements are read off from this. ∎

6.2 The shape part

Fix a level a₀, sets T₁ ⊆ [1, a₀−1], T₂ ⊆ [a₀+1, n], H ⊆ T₂, and a mode, one of U, Q, W (for "unequal totals", "equal totals on all p children", "equal totals on two children"). Put

  • D* = {u : u_a = 0 for every a ∉ T₁ ∪ {a₀} ∪ T₂} (the digit of level a₀ is free);
  • τ(u) = 1 if H ≠ ∅ and u_a ≠ 0 for every a ∈ H, and τ(u) = 0 otherwise (τ depends only on digits of levels > a₀);
  • I = {0, 1} in modes U and W, I = {0, …, p−1} in mode Q;
  • for x ∈ Z^q: (Δx)(w) = x(w) − x(w − 1), indices mod q; so Δe_t = e_t − e_(t+1), e_t the unit vector of layer t;
  • linear maps Λ_i : Z^q → Z^q, i ∈ I. Mode U: Λ_0 x = x, Λ_1 x = |x|·1 − x. Modes Q and W: Λ_0 x = |x|·1 + Δx, Λ_1 x = |x|·1 − Δx; mode Q also Λ_i x = |x|·1 for 2 ≤ i ≤ p − 1.
  • r_i = |Λ_i e_t|: r_0 = 1, r_1 = q − 1 in mode U; r_i = q in modes Q, W. So |Λ_i x| = r_i |x| (note |Δx| = 0).

The vectors Λ_i e_t (t ∈ {0, 1}) have entries ≥ 0: e_t; 1 − e_t; 1 + e_t − e_(t+1) (one element in every layer, a second one in layer t, none in layer t+1; for q = 2 this is 2e_t); 1 − e_t + e_(t+1); 1.

The shape part S = S(a₀, T₁, T₂, H, mode) is the multiset that has, for every u ∈ D* with u_(a₀) ∈ I and every layer w, (Λ_(u_(a₀)) e_(τ(u)))(w) copies of (u, w). For a class N and i ∈ I let

β^i(N) = #{u ∈ D* ∩ N : u_(a₀) = i, τ(u) = 0}·e_0 + #{u ∈ D* ∩ N : u_(a₀) = i, τ(u) = 1}·e_1.

Then, by linearity, g_S(N) = Σ_(i ∈ I) Λ_i β^i(N). Let β₀ = Σ e_(τ), the sum over all choices of digits (u_(a₀+1), …, u_n) that are 0 outside T₂ (τ is a function of these digits); |β₀| = p^|T₂|.

Two facts about the maps:

  • (Δ) Δx is constant iff x is constant. [If Δx = c·1, summing over the layers gives 0 = q c, so c = 0 and x(w) = x(w−1) for all w. The converse is clear.]
  • (Λ) For i ∈ {0, 1}, in every mode, and integer vectors x, y: Λ_i x − Λ_i y is constant iff x − y is constant. [Λ_i x − Λ_i y = Λ_i(x − y) is a multiple of 1 plus or minus (x − y) in mode U, plus or minus Δ(x − y) in modes Q, W; use (Δ).] In particular Λ_i x is constant iff x is constant.

Lemma 9 (counting strings by τ). Let N be a class of depth d ≥ a₀ whose prefix is 0 at every level outside T₁ ∪ {a₀} ∪ T₂ ("N meets D*"), i its digit of level a₀, and β(N) = β^i(N). Let a = d + 1 ≤ n.

  • (i) |β(N)| = p^|T₂ ∩ (d, n]| ≥ 1, and β(N) is not constant. If d = a₀ then β(N) = β₀.
  • (ii) If a ∈ T₂∖H: β(N_j) is the same for all j.
  • (iii) If a ∈ H: |β(N_j)| = p^|T₂ ∩ (a, n]| for all j.
  • (iv) If a ∉ T₂: β(N_0) = β(N), and N_j does not meet D* for j ≠ 0.
  • (v) If a ∈ H and the prefix of N is 1 at the levels of H ∩ (a₀, a) and 0 at all other levels except a₀ (call this class N*(a, i)): β(N_0) − β(N_1) = t(e_0 − e_1) with an integer t ≥ 1, and this vector is not constant.

Proof. The strings of D* in N are the completions of the prefix by digits that are free on T₂ ∩ (d, n] and 0 elsewhere. (i) Their number is p^|T₂ ∩ (d,n]|. β(N) is supported on layers 0 and 1. If q ≥ 3 its entry at layer 2 is 0 and its total is ≥ 1, so it is not constant. If q = 2 and it were constant its total would be even; but the total is a power of p and p ≠ q = 2 is odd. For d = a₀ the completions are all digit choices beyond a₀. (ii) Changing the digit of level a from j to j′ is a bijection between the strings of D* in N_j and in N_j′ that does not change τ (a ∉ H). (iii) Each N_j meets D* (a ∈ T₂); apply (i). (iv) Strings of D* have u_a = 0. (v) N(a, i) meets D because H ⊆ T₂. Every string in N_0 has u_a = 0 with a ∈ H, so τ = 0 and β(N_0) = p^h e_0, h = |T₂ ∩ (a, n]|. In N_1 the string that continues with 1 at the levels of H beyond a and 0 elsewhere has all its H-digits nonzero, so τ = 1 for it, and β(N_1) = (p^h − t) e_0 + t e_1 with t ≥ 1. The difference t(e_0 − e_1) has entries t and 0 at layers 0 and 2 if q ≥ 3, and entries t and −t if q = 2; not constant. ∎

Lemma 10 (the pattern of the shape part). Let S = S(a₀, T₁, T₂, H, mode), and μ = 1, p, 2 in modes U, Q, W.

  • (S1) A class N of depth d < a₀ that meets D* (prefix 0 outside T₁) has g_S(N) = μ·p^(|T₁ ∩ (d, a₀)| + |T₂|)·1; a class of depth < a₀ that does not meet D* is empty. So every class of depth < a₀ is balanced, and |S| = μ·q·p^(|T₁| + |T₂|).
  • (S2) Level a < a₀, N a class of depth a − 1. If a ∈ T₁, all children of N have the same vector g_S. If a ∉ T₁, only N_0 can be nonempty.
  • (S3) Level a₀, N a class of depth a₀ − 1 that meets D*: g_S(N_i) = Λ_i β₀ for i ∈ I and g_S(N_i) = 0 for i ∉ I; the totals are r_i p^|T₂| for i ∈ I; N_0 and N_1 do not have equal shapes.
  • (S4) Level a > a₀, N a class of depth a − 1 that meets D* and has its digit i of level a₀ in I: g_S(N_j) = Λ_i β(N_j) for the children that meet D. If a ∈ T₂∖H, all children have the same vector. If a ∈ H, all children have the total r_i p^|T₂ ∩ (a, n]|; and for N = N(a, 0) the children N_0, N_1 do not have equal shapes. If a ∉ T₂, g_S(N_0) = g_S(N) and the other children are empty; and if i ∈ {0, 1}, g_S(N) is not constant. A class of depth ≥ a₀ that does not meet D*, or whose digit of level a₀ is not in I, is empty.
  • (S5) If Φ is any sum of multisets of the form m·Fib(D), then A = S + Φ is balanced and F(A) = {0} ∪ [1, a₀ − 1] ∪ (T₂∖H).

Proof. (S1) For N of depth d < a₀ meeting D, the strings of D in N with u_(a₀) = i are the prefix, any digits on T₁ ∩ (d, a₀), the digit i, and a completion beyond a₀; τ depends only on the completion. So β^i(N) = p^|T₁ ∩ (d, a₀)|·β₀ for every i, and g_S(N) = p^|T₁ ∩ (d,a₀)|·Σ_(i∈I) Λ_i β₀. Now Σ_(i∈I) Λ_i x equals x + |x|1 − x = |x|·1 in mode U, (|x|1 + Δx) + (|x|1 − Δx) + (p−2)|x|1 = p|x|·1 in mode Q, and 2|x|·1 in mode W; and |β₀| = p^|T₂|. For the root, d = 0, the total is μ q p^(|T₁|+|T₂|). (S2) By (S1), if a ∈ T₁ the children of N all meet D* or none does, and those that do have the same vector (the formula depends only on the depth). If a ∉ T₁ only N_0 can meet D. (S3) The strings of D in N_i are the prefix, the digit i, and a completion; so β^i(N_i) = β₀ and g_S(N_i) = Λ_i β₀ for i ∈ I; no string of S has u_(a₀) ∉ I. Totals: |Λ_i β₀| = r_i p^|T₂|. g_S(N_0) − g_S(N_1) = Λ_0 β₀ − Λ_1 β₀ is 2β₀ − |β₀|·1 in mode U and 2Δβ₀ in modes Q, W. If 2β₀ − |β₀|1 is constant so is β₀. If 2Δβ₀ = c·1 then summing gives q c = 0, so Δβ₀ = 0 and β₀ is constant by (Δ). But β₀ is not constant (Lemma 9(i)). (S4) g_S(N_j) = Λ_i β(N_j) by the definition of S. The three cases are Lemma 9(ii); Lemma 9(iii) with |Λ_i x| = r_i|x|; Lemma 9(v) with (Λ) for i = 0: g_S(N_0) − g_S(N_1) = Λ_0(β(N_0) − β(N_1)) is not constant; Lemma 9(iv); and Lemma 9(i) with (Λ): Λ_i β(N) is constant iff β(N) is. The last sentence: S has no string outside D* and none with u_(a₀) ∉ I. (S5) By Lemma 8(i), g_A(N) − g_S(N) is a constant vector for every class N. So a class is balanced in A iff g_S(N) is constant, and two classes have equal shapes in A iff their g_S differ by a constant vector. The root is balanced by (S1). For a < a₀: every class of depth a ≤ a₀ − 1 has constant g_S by (S1), so the children of every class of depth a − 1 have equal shapes: a ∈ F(A). Level a₀: the class of depth a₀ − 1 with prefix 0 meets D, and its children N_0, N_1 have unequal shapes by (S3): a₀ ∉ F(A). For a > a₀ and a ∈ T₂∖H: a class of depth a − 1 either meets D with its digit of level a₀ in I, and then its children have equal g_S by (S4), or all its children have g_S = 0: a ∈ F(A). For a ∈ H: N(a, 0) by (S4): a ∉ F(A). For a > a₀, a ∉ T₂: let Z be the class of depth a − 1 whose prefix is 0 everywhere (its digit of level a₀ is 0 ∈ I, and it meets D); g_S(Z_0) = g_S(Z) is not constant and g_S(Z_1) = 0 by (S4): a ∉ F(A). ∎

6.3 The five multisets

Throughout, (E, F) is a pattern with 0 ∈ F. If F = {0, …, n}:

Theorem A (upper bound). A = Fib(D(E)) has exact pattern (E, {0, …, n}) and q p^e elements.

Proof. Every class is balanced (Lemma 8(i)), so the root is balanced and the children of every class have equal shapes: F(A) = {0, …, n}. For a ∈ E the children of every class of depth a − 1 have equal totals (Lemma 8(iii)). For a ∉ E the class of depth a − 1 with prefix 0 meets D(E) and all its elements are in the child N_0 (Lemma 8(iv)): unequal totals. |A| = q p^e. ∎

Now let F ≠ {0, …, n}, with a₀, G′ = (F∖E) ∩ (a₀, n], k′ = |G′|, and g₁ = min G′ if k′ ≥ 1. Write "above" = [1, a₀−1], "below" = [a₀+1, n], and

T₂⁰ = (E ∪ F) ∩ below, H⁰ = (E∖F) ∩ below, mode⁰ = Q if a₀ ∈ E, U if a₀ ∉ E.

Note T₂⁰∖H⁰ = F ∩ below, |T₂⁰| = |E ∩ below| + k′, and [1, a₀−1] ⊆ F. The multiset A is defined by the first of the following five cases that applies.

  • (I) k′ = 0. A = S(a₀, E ∩ above, T₂⁰, H⁰, mode⁰).
  • (III) k′ ≥ 1 and E ∩ above ≠ ∅. Let b = min E (so b < a₀, and b ∈ F). A = S(a₀, (E ∩ above)∖{b}, T₂⁰, H⁰, mode⁰) + Σ_(i=1..p−1) p^k′·Fib(D(E∖{b}; b↦i)).
  • (IV) k′ ≥ 1, a₀ ∈ E, p ≥ 3. A = S(a₀, E ∩ above, T₂⁰, H⁰, W) + Σ_(i=2..p−1) p^k′·Fib(D(E∖{a₀}; a₀↦i)).
  • (V) k′ ≥ 1, a₀ ∈ E, and some level of E∖F lies strictly between a₀ and g₁. Let b be the least such level. A = S(a₀, E ∩ above, T₂⁰∖{b}, H⁰∖{b}, Q) + Σ_(i=1..p−1) p^k′·Fib(D(E∖{b}; b↦i)).
  • (II) otherwise (k′ ≥ 1 and none of the above). A = S(a₀, E ∩ above, T₂⁰, H⁰, mode⁰) + Fib(D(E)).

In (III), (IV), (V) the level that is treated specially (b, a₀, b) is the host level; the shape part is built as if that level were not in E, and the fibre multisets fill the other children at that level with whole fibres, p^k′ on each string, so that the totals at the host level come out equal. (For (IV) and (V) the definition does not need E ∩ above = ∅ or p = 2; the order of the cases only fixes which construction is used.)

Theorem C (upper bound of Theorem B). In each case A has exact pattern (E, F), and |A| = q·p^e·(p^k′ + x) with x = 0 in cases (I), (III), (IV), (V) and x = 1 in case (II). Case (II) applies exactly when none of the clauses (1) to (4) holds.

Proof. The last sentence: (I) is clause (1); (III) is "k′ ≥ 1 and clause (2)"; (IV) is "k′ ≥ 1 and clause (3)"; (V) with p = 2 is "k′ ≥ 1 and clause (4)", and (V) with p ≥ 3 is never reached (then (IV) applies first). So (II) is reached iff none of the clauses holds.

F(A) = F and A balanced, in all cases. A = S + Φ with Φ a sum of fibre multisets, and in each case the parameters of S satisfy T₂∖H = F ∩ below: in (I) to (IV) T₂∖H = T₂⁰∖H⁰; in (V) b ∈ H⁰, so (T₂⁰∖{b})∖(H⁰∖{b}) = T₂⁰∖H⁰. By (S5), A is balanced and F(A) = {0} ∪ [1, a₀−1] ∪ (F ∩ below) = F.

E(A) = E. For each level a I show: if a ∈ E, the children of every class of depth a − 1 have equal totals; if a ∉ E, some class of depth a − 1 has two children of unequal totals. I use repeatedly:

  • (✱) if all elements of A in a nonempty class Z lie in one child of Z, the children of Z have unequal totals;
  • the total of a class in A is its total in S plus its totals in the fibre multisets.

Write Z(a) for the class of depth a − 1 whose prefix is 0 everywhere.

Case (I). A = S, T₁ = E ∩ above, T₂ = T₂⁰ = E ∩ below (k′ = 0 means F ∩ below ⊆ E), mode Q or U. Size: |S| = μ q p^(|T₁|+|T₂|) with μ = p if a₀ ∈ E, μ = 1 if not; so |A| = q p^e. a < a₀: if a ∈ E then a ∈ T₁: equal vectors (S2). If a ∉ E: Z(a) meets D* so is nonempty (S1), and only its child N_0 is nonempty (S2); (✱). a = a₀: if a₀ ∈ E (mode Q, I all digits): a class of depth a₀ − 1 that meets D* has children of totals r_i p^|T₂| = q p^|T₂| each (S3); one that does not is empty. If a₀ ∉ E (mode U): the children of Z(a₀) have totals p^|T₂|, (q − 1)p^|T₂|, and 0 for the p − 2 others (S3). If q ≥ 3 the first two differ. If q = 2 then p ≥ 3, there is a third child, and 0 ≠ p^|T₂|. a > a₀: if a ∈ E then a ∈ T₂: a class of depth a − 1 that meets D* with digit of level a₀ in I has children of equal totals (S4: equal vectors if a ∉ H, equal totals if a ∈ H); any other class of depth a − 1 is empty (S4). If a ∉ E then a ∉ T₂: Z(a) meets D*, has digit 0 at a₀, is nonempty and has only N_0 nonempty (S4); (✱).

Case (II). A = S + Fib(D(E)), T₁ = E ∩ above, T₂ = T₂⁰, H = H⁰, mode Q or U; k′ ≥ 1. Size: μ q p^(|E ∩ above| + |E ∩ below| + k′) + q p^e = q p^(e+k′) + q p^e. a < a₀: if a ∈ E: (S2) equal vectors, and Lemma 8(iii). If a ∉ E: Z(a) is nonempty; its S-part is in N_0 (S2) and its fibres are in N_0 (Lemma 8(iv)); (✱). a = a₀ ∈ E (mode Q): for every class of depth a₀ − 1 the S-totals of the children are equal (all q p^|T₂| or all 0, (S3)) and the fibre totals are equal (Lemma 8(iii)). a = a₀ ∉ E (mode U): in Z(a₀) all fibres lie in N_0 (Lemma 8(iv)), p^|E ∩ below| of them (Lemma 8(ii)). With c = |E ∩ below|, the totals of the children are p^(c+k′) + q p^c for N_0, (q − 1)p^(c+k′) for N_1, and 0 for the others. If p ≥ 3 there is a child of total 0 and N_0 is not empty. If p = 2: p^k′ + q is odd (q is odd, k′ ≥ 1) and (q − 1)p^k′ is even, so the totals of N_0 and N_1 differ. a > a₀, a ∈ E: then a ∈ T₂; S-totals of the children of any class of depth a − 1 are equal (S4) and so are the fibre totals (Lemma 8(iii)). a > a₀, a ∈ F∖E: a ∈ T₂∖H, so the children of Z(a) have equal S-vectors (S4); Z(a) meets D(E), and its fibres all lie in N_0 (Lemma 8(iv)); so N_0 has q p^|E ∩ (a,n]| ≥ q more elements than N_1. a > a₀, a ∉ E ∪ F: a ∉ T₂; Z(a) is nonempty, its S-part lies in N_0 (S4) and so do its fibres; (✱).

Case (III). b = min E < a₀; T₁ = (E ∩ above)∖{b}, T₂ = T₂⁰, H = H⁰, mode Q or U; Φ_i = p^k′·Fib(D(E∖{b}; b↦i)), i = 1..p−1. Strings of S have u_b = 0 (b ∉ T₁); strings of Φ_i have u_b = i ≠ 0. So a class of depth ≥ b is S-only (u_b = 0: it contains no fibre of any Φ_i) or Φ_i-only (u_b = i: it contains nothing of S and nothing of Φ_i′, i′ ≠ i). Size: |S| = μ q p^(|E ∩ above| − 1 + |E ∩ below| + k′) = q p^(e−1+k′); each Φ_i has p^k′ q p^(e−1) elements; total q p^(e−1+k′)·p. a < b: a ∉ E (b is the least level of E). Z(a) is nonempty; a ∉ T₁ and a ∉ (E∖{b}) ∪ {b}, so S and every Φ_i lie in N_0 (S2, Lemma 8(iv)); (✱). a = b ∈ E: let N be a class of depth b − 1. S meets N iff the prefix of N is 0 outside T₁, that is (all levels < b are outside E) iff the prefix is 0; the same condition for each Φ_i (Lemma 8(ii)). If the prefix is not 0, N is empty. If it is 0 (N = Z(b)): the S-part lies in N_0 and is all of S, q p^(e−1+k′) elements; Φ_i lies in N_i, q p^(k′+e−1) elements. Equal totals. b < a < a₀: a class of depth a − 1 is S-only or Φ_i-only. If a ∈ E: a ∈ T₁, S-only classes have children of equal vectors (S2); a ∈ E∖{b}, Φ_i-only classes have children of equal totals (Lemma 8(iii)). If a ∉ E: Z(a) is S-only, nonempty (S1), and only N_0 is nonempty (S2); (✱). a = a₀: if a₀ ∈ E: S-only classes by (S3) as in case (I), Φ_i-only classes by Lemma 8(iii). If a₀ ∉ E: Z(a₀) is S-only and its children have totals p^|T₂|, (q−1)p^|T₂|, 0, …; unequal as in case (I). a > a₀, a ∈ E: S-only classes by (S4) (a ∈ T₂), Φ_i-only classes by Lemma 8(iii). a > a₀, a ∈ F∖E: the class Y of depth a − 1 with prefix u_b = 1 and 0 elsewhere is Φ_1-only and meets D(E∖{b}; b↦1); all its elements lie in N_0 (Lemma 8(iv), a ∉ E); (✱). a > a₀, a ∉ E ∪ F: a ∉ T₂; Z(a) is S-only, nonempty, with only N_0 nonempty (S4); (✱).

Case (IV). p ≥ 3, a₀ ∈ E; T₁ = E ∩ above, T₂ = T₂⁰, H = H⁰, mode W (I = {0, 1}); Φ_i = p^k′·Fib(D(E∖{a₀}; a₀↦i)), i = 2..p−1. A class of depth ≥ a₀ is S-only (digit 0 or 1 at level a₀) or Φ_i-only (digit i ≥ 2). Size: |S| = 2 q p^(|E ∩ above| + |E ∩ below| + k′) = 2 q p^(e−1+k′); each Φ_i has q p^(k′+e−1); total q p^(e−1+k′)(2 + p − 2). a < a₀: if a ∈ E: (S2) and Lemma 8(iii). If a ∉ E: Z(a) nonempty, S and all Φ_i in N_0; (✱). a = a₀ ∈ E: let N be a class of depth a₀ − 1. S meets N iff its prefix is 0 outside E ∩ above; the same condition for Φ_i (Lemma 8(ii)). If it fails N is empty. If it holds: N_0 and N_1 have the S-totals r_i p^|T₂| = q p^(|E ∩ below| + k′) (S3) and no fibres; N_i, i ≥ 2, has no S-part and p^k′·q·p^|E ∩ below| elements of Φ_i (Lemma 8(ii)). Equal totals. a > a₀, a ∈ E: S-only classes by (S4), Φ_i-only by Lemma 8(iii). a > a₀, a ∈ F∖E: the class Y of depth a − 1 with digit 2 at level a₀ and 0 elsewhere is Φ_2-only, nonempty, with all its elements in N_0; (✱). a > a₀, a ∉ E ∪ F: Z(a) is S-only, nonempty, only N_0 nonempty (S4); (✱).

Case (V). a₀ ∈ E; b ∈ E∖F with a₀ < b < g₁; T₁ = E ∩ above, T₂ = T₂⁰∖{b}, H = H⁰∖{b}, mode Q (I = all digits); Φ_i = p^k′·Fib(D(E∖{b}; b↦i)), i = 1..p−1. Because b < g₁, no level strictly between a₀ and g₁ is in F∖E, so

(†) every level a with a₀ < a < b that is in F is in E; T₂ ∩ (a₀, b) = E ∩ (a₀, b); T₂ ∩ (b, n] = (E ∪ F) ∩ (b, n], of size |E ∩ (b, n]| + k′.

Strings of S have u_b = 0 (b ∉ T₂); so a class of depth ≥ b is S-only (u_b = 0) or Φ_i-only (u_b = i). Size: |S| = p q p^(|E ∩ above| + |E ∩ below| − 1 + k′) = q p^(e−1+k′) (a₀ ∈ E, so |E ∩ above| + |E ∩ below| = e − 1); each Φ_i has q p^(k′+e−1); total q p^(e+k′). a < a₀: if a ∈ E: (S2), Lemma 8(iii). If a ∉ E: Z(a), all in N_0; (✱). a = a₀ ∈ E: S-totals of the children of any class of depth a₀ − 1 are equal (mode Q, (S3)); a₀ ∈ E∖{b}, Lemma 8(iii). a₀ < a < b: if a ∈ E then a ∈ T₂ by (†): (S4) and Lemma 8(iii). If a ∉ E then a ∉ F by (†), so a ∉ T₂: Z(a) is nonempty, its S-part is in N_0 (S4), its fibres are in N_0 (Lemma 8(iv), a ∉ E, a ≠ b); (✱). a = b ∈ E: let N be a class of depth b − 1. 7. The four clauses as one condition

Let k′ ≥ 1. Call a level b a host level of the pattern if b ∈ E, b < g₁, and one of

  • b < a₀;
  • b = a₀ and p ≥ 3;
  • b > a₀, b ∉ F, and a₀ ∈ E.

Proposition 11. x = 0 iff k′ = 0 or the pattern has a host level.

Proof. Let k′ ≥ 1. Clause (2) gives a host level b < a₀ (a₀ < g₁). Clause (3) gives the host level a₀. Clause (4) gives a host level of the third kind. Conversely a host level b < a₀ is clause (2); b = a₀ with p ≥ 3 is clause (3); a host level of the third kind gives clause (3) if p ≥ 3 (a₀ ∈ E) and clause (4) if p = 2. ∎

What a host level is, in terms of the proofs: a level of E, above every level of F∖E that lies beyond a₀, at which one of the p equal-total children of a class can be a nonempty class made of whole fibres without being needed for the shapes. Above a₀ every child is balanced and only one has to contain the class P with unequal shapes; at a₀ two children must be unbalanced, so a free one needs p ≥ 3; below a₀ the children of an unbalanced class are all unbalanced at a level of F (Lemma 1), so the level must be outside F, and the equal totals then force q to divide the totals of the unbalanced siblings, which is possible at the least size only when a₀ ∈ E. The constructions (III), (IV), (V) are one construction: build the shape part as if the host level were not in E, and fill the other children at the host level with whole fibres, p^k′ on each string. The lower bound says nothing else works. This is one condition, but it is still a list of three positions; I did not find a formulation free of cases, and a purely semantic one ("some multiset with the pattern has a nonempty all-fibre class above g₁") is false without a size condition: for p = 2, q = 3, E = {2}, F = {0, 3} (x = 1, least size 18) the multiset of 36 elements with classes of depth 2 equal to (6,0,0), (2,2,2), (0,6,6), (4,4,4) (in the order of the prefixes 00, 01, 10, 11), each (6,0,0) or (0,6,6) split into two equal halves and each (2,2,2), (4,4,4) put in one child, has that pattern and such a class.

8. What is not proved

  • Sets. Nothing here is about sets (weights 0 or 1). The constructions use weights up to p^k′ (and 2).
  • Lean. Nothing here is formalised. The lemmas are short inductions on the tree and should go into the existing tree model, but that was not attempted.
  • The construction of the unbalanced half (section 2 of the note) is not re-proved here; only its lower bounds are (Remark after Lemma 4).
  • No GAP is marked in the text: I know of no step that is not justified. That is the author's view of his own proof; it has been read by one other fresh instance (see section 9), not by a person.
  • The semantic version of section 7 is not a theorem (and is false as first stated there).
