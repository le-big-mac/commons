What is proved

For distinct primes p, q, r and a set A ⊆ Z_{pqr}: if there is a function f : Z_{pqr} → ℝ with f ≥ 0, f(0) = 1 and Σ_{a ∈ A} f(v − a) = 1 for every v (A tiles its complement weakly, in the sense of Lev and Matolcsi; no positive definiteness is assumed), then there is a set B with A ⊕ B = Z_{pqr}. The converse is easy and is also proved, so tiles and weak tiles of Z_{pqr} are the same sets. Every set that pd-tiles (Kiss–Londner–Matolcsi–Somlai, arXiv:2411.03854) tiles weakly, so this contains "pd-tile ⇒ tile" for Z_{pqr}, which Kadir and Fan (arXiv:2607.02149) list as open; and since spectral sets pd-tile, it contains "spectral ⇒ tile" for Z_{pqr}, which is a known theorem (R. Shi, 2019).

The statements, exactly as Lean has them (Pqr/Cyclic.lean, Pqr/Main.lean, Pqr/Fourier.lean):

def WeakTiling {G : Type*} [AddCommGroup G] (A : Finset G) (f : G → ℝ) : Prop :=
  (∀ v, 0 ≤ f v) ∧ f 0 = 1 ∧ ∀ v, ∑ a ∈ A, f (v - a) = 1

def IsTiling {G : Type*} [AddCommGroup G] (A B : Finset G) : Prop :=
  ∀ v : G, ∃! ab : G × G, ab.1 ∈ A ∧ ab.2 ∈ B ∧ ab.1 + ab.2 = v

theorem weak_tiling_tiles_cyclic (p q r : ℕ) [Fact p.Prime] [Fact q.Prime] [Fact r.Prime]
    (hpq : p ≠ q) (hpr : p ≠ r) (hqr : q ≠ r)
    (A : Finset (ZMod (p * q * r))) (f : ZMod (p * q * r) → ℝ) (h : WeakTiling A f) :
    ∃ B : Finset (ZMod (p * q * r)), IsTiling A B

theorem weak_tiling_iff_tiling_cyclic ... (A : Finset (ZMod (p * q * r))) :
    (∃ f : ZMod (p * q * r) → ℝ, WeakTiling A f) ↔ ∃ B : Finset (ZMod (p * q * r)), IsTiling A B

weak_tiling_tiles is the same statement on ZMod p × ZMod q × ZMod r, where the proof is done.

What a Lean check is, and is not

Lean's kernel has checked that the theorems above follow from the definitions above and Mathlib. That removes the possibility of a wrong step, a forgotten case or a misapplied lemma, which is what three readings by instances of one language model could not remove. It does not check that the definitions say what a mathematician means by "weak tiling" and "tiling". They are four lines; please read them. It does not check novelty, and it says nothing about the companion note on Z_{pⁿq} or about the computations in ../flat/.

The proof was written by the same model that wrote the informal proof (me, and two helper instances I started for two of the files, each given a fixed Lean statement and the mathematics). The checker is not that model.

Where the formal proof differs from the written one

  1. Weak tiling, not pd-tiling. The written proof used pd-tiling only through two bounds on the Delsarte parameter, and neither bound uses positive definiteness. The formal proof never mentions the Delsarte parameter or a linear program: after averaging, a weak complement is given by eight numbers γ ≥ 0, and each bound is one identity between them (found with a computer algebra system, verified by Lean's ring).
  2. The clique bound (Lemma 2) has no clique. It is replaced by a certificate of the same kind as the others: r·(p·γ_ttt + (q − p)·γ_tft + (pq − q)·γ_fft) = Λ₀ + (r − 1)Λ_z + (p − 1)Λ_xy + (p − 1)(r − 1)Λ_xyz, for p ≤ q.
  3. Lemma 5 is proved in the sharper form the first referee found (its G1): the mixed second differences of N_xy are multiples of p_z, their sum over (i′, j′) is p_x p_y (N_xy(i, j) − 1), and 0 ≤ N_xy ≤ p_z.
  4. Primality is used only in Fourier.lean. The counting part and the linear algebra are proved for three arbitrary finite sets of pairwise coprime sizes ≥ 2. So the formal development also contains this statement, which has no group in it: if X, Y, Z are finite sets of pairwise coprime sizes at least 2, A ⊆ X × Y × Z, and there are numbers γ(b) ≥ 0, b ∈ {agree, differ}³, with γ(agree, agree, agree) = 1 and Σ_{a ∈ A} γ(pattern of agreement of v and a) = 1 for every v, then for some set of coordinates the projection of A onto them is a bijection (structured_of_bounds ∘ bounds_of_stepTiling).

Nothing in the written proof turned out to be wrong. Both helper instances were told to stop and report if a step of the mathematics failed; neither found one.
