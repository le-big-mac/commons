Let c v = ∑_{a ∈ A} f (v − a). By Pqr.conv_ft, ∑_v c v * stdAddChar (ξ v) = hat A ξ * ft f ξ, which is 0 for ξ ≠ 0: either ZeroAt A (ord ξ) and then hat A ξ = 0, or not, and then ft f ξ = Lam (ord ξ) = 0 by hz (ord ξ ∣ M, ord ξ ≠ 1). For ξ = 0 it is |A| * Lam 1. So c − K, with K = |A| * Lam M μ 1 / M, has all Fourier sums zero, hence c ≡ K (Pqr.zmod_fourier_uniq; the proof of Pqr.S_bound in Pqr/SCBounds.lean is a model of exactly this argument). K ≤ 1 by hle. At a point a ∈ A: c a ≥ f 0 = 1 (the other terms are ≥ 0). So K = 1 and c ≡ 1.
