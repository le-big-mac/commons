It imports P2q2/Sub.lean (the embedding iota M N r : ZMod N → ZMod M, piece M N r A c, and four theorems: weakTiling_piece_of_support, weakTiling_piece_of_subset, tiling_of_pieces, tiling_of_piece_subset) and P2q2/Common.lean (exists_common_complement_pnq). Note the shape of the moduli. Pnq works in ZMod (P ^ n * Q). For "p" take M = p^2q^2, r = p, N = q^2p (hM : p^2*q^2 = p*(q^2*p) by ring), and apply the Pnq/Common theorems with (P, Q, n) = (q, p, 2). For "q" take r = q, N = p^2*q, (P, Q, n) = (p, q, 2). No casts between types are needed if you instantiate N this way.

  1. tiling_of_support_p (Lemma 3). By weakTiling_piece_of_support, every piece M N p A c (c : ZMod M) is a weak tile of ZMod (q^2*p) with the common weak complement fun y => f (iota M N p y). exists_common_complement_pnq (index type ZMod M) gives a common tiling complement B'; tiling_of_pieces concludes. tiling_of_support_q: the same with r = q.
  2. tiling_of_units_charged (Lemma 2). First, for a, a' ∈ A distinct, f (a − a') = 0: from the weak tiling identity at v = a, 1 = ∑_{a'' ∈ A} f (a − a'') ≥ f 0 + f (a − a') = 1 + f (a − a'). So by hunit, for any a, a' ∈ A: p ∣ (a − a').val or q ∣ (a − a').val (also true when a = a'). A is nonempty (Pqr.nonempty_of_weakTiling); fix a₀ ∈ A. Claim: (∀ a ∈ A, p ∣ (a − a₀).val) ∨ (∀ a ∈ A, q ∣ (a − a₀).val). If not, there are a, b ∈ A with p ∤ (a − a₀).val and q ∤ (b − a₀).val; then q ∣ (a − a₀).val and p ∣ (b − a₀).val; and a − b = (a − a₀) − (b − a₀) is divisible neither by p nor by q (divisibility of .val by a divisor of M is compatible with subtraction in ZMod M — prove that helper), contradicting the first step. In the first case use weakTiling_piece_of_subset (r = p, c = a₀), then Pnq.weak_tiling_tiles_pnq q p 2 on ZMod (q^2*p) to get a tiling complement of the piece, then tiling_of_piece_subset. In the second case the same with r = q and Pnq.weak_tiling_tiles_pnq p q 2.
