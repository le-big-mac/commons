Task: P2q2/LemmaY.lean — a counting lemma in ZMod (p² q²)

Read common.md in this directory first. Your file: /home/agent2/lean/pqr/P2q2/LemmaY.lean (one theorem with sorry): for distinct primes p, q and A ⊆ ZMod (p²q²) with |A| = p q, if p and p²q² are zeros of A then p q² is a zero of A.

Tools. Pqr.cnt A d v = number of a ∈ A with d ∣ (a − v).val (Pqr/Counting.lean). Pqr/Bridge.lean turns zeros into identities between counts: zeroAt_prime_pow (ZeroAt A (p^(ℓ+1)) ↔ ∀ v, p * cnt A (p^(ℓ+1)) v = cnt A (p^ℓ) v), zeroAt_prime_pow_mul (orders p^(ℓ+1) * q), and the general zeroAt_iff_cnt / zeroAt_iff_cnt_aux from which those two are derived. You need the analogous statements for the orders p²q² and p q²; with M = p²q², for a, b ≥ 1: ZeroAt A (p^a q^b) ↔ ∀ v, p*q*cnt A (p^a q^b) v + cnt A (p^(a-1) q^(b-1)) v = q*cnt A (p^(a-1) q^b) v + p*cnt A (p^a q^(b-1)) v. Read how zeroAt_prime_pow_mul is obtained from zeroAt_iff_cnt (via indicator_prime_pow_mul) and do the same for two prime powers (state it for exponents a+1, b+1; you only need (a,b) = (2,2) and (1,2), with p^a q^b ∣ p²q²). Also Pqr.cnt_one : cnt A 1 v = A.card, and cnt A (p²q²) v = if v ∈ A then 1 else 0.

Mathematics (a route that uses only counts; any correct route is fine). Write, for v : ZMod M, N v = cnt A (p q) v, ρ v = cnt A (p² q) v, κ v = cnt A (p q²) v, x v = [v ∈ A]. - (i) p zero and |A| = pq: cnt A p v = q for all v. - (ii) p²q² zero: p q x v + N v = q κ v + p ρ v for all v. - Counts only depend on classes: if d ∣ (v − v').val and e ∣ d then cnt A e v = cnt A e v'. Bounds: ρ v ≤ q, κ v ≤ p (the class of v modulo p²q has q elements, modulo pq² has p elements), N v ≤ cnt A p v = q. - Claim: for every a ∈ A, ρ a = q (the whole class of a modulo p²q, "the row of a", lies in A). Suppose a ∈ A and ρ a < q. The row of a has q elements, so some v in it is not in A; ρ v = ρ a, N v = N a. (ii) at v: N = q κ v + p ρ. (ii) at a: p q + N = q κ a + p ρ. Subtract: κ a = p + κ v, so κ a = p, κ v = 0, and N a = p ρ a: p divides N a. So: every a ∈ A with ρ a < q has p ∣ N a. Now fix a₀ ∈ A with ρ a₀ < q and look at the q elements of A congruent to a₀ modulo p (by (i)). They are distributed over the classes modulo pq inside that class modulo p. If one of them, a′, had ρ a′ = q, then N a′ ≥ q, so its class modulo pq contains all q of them, in particular a₀, and N a₀ = N a′ = ρ a′ = q … then p ∣ N a₀ = q, impossible. So all of them have ρ < q, each of their classes modulo pq has size divisible by p, and the sizes add up to q: p ∣ q, impossible. Hence the Claim. - So A is invariant under adding multiples of p²q (a + p²q·j ∈ A for a ∈ A). Consequences, for all v: cnt A q v = q * cnt A (q²) v and cnt A (p q) v = q * cnt A (p q²) v (adding p²q·j permutes transitively the q classes modulo q² inside a class modulo q, and the q classes modulo pq² inside a class modulo pq, because p is invertible modulo q). Therefore p q κ v + cnt A q v = p q κ v + q cnt A (q²) v = p * cnt A (p q) v + q * cnt A (q²) v, which is the count identity for the order p q² (a = 1, b = 2: pqcnt(p q²) + cnt(q) = qcnt(q²) + pcnt(p q)). If the Claim's argument is awkward to formalise, an alternative is: (ii) says the 0/1 array of A in each class modulo pq is additive, and Pqr.add2_zero_one in Pqr/Comb.lean says such an array is a union of full rows or full columns.
