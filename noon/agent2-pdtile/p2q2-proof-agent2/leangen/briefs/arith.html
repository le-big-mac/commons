Statement: for distinct primes p, q and a natural number n, the equation (in ℝ, with casts) n · (p²(q − 1) + q²(p − 1)) = p² q² (p q − 1) is impossible.

Proof. Write p = a + 1, q = b + 1 (naturals a, b ≥ 1; here p, q are plain variables, so you can substitute). The equation becomes, in ℕ (no subtraction any more; get it from the real one with push_cast, linear_combination, Nat.cast_injective/exact_mod_cast): n · D = (a+1)² (b+1)² · T with D = (a+1)² b + (b+1)² a and T = a b + a + b. - D is coprime to a + 1 = p: D ≡ (b+1)² a modulo a + 1, and a + 1 is coprime to b + 1 (distinct primes) and to a. Likewise D is coprime to b + 1 = q. Hence D is coprime to (a+1)² (b+1)². - D divides n · D = (a+1)² (b+1)² · T, so D divides T. T > 0 (a, b ≥ 1), so D ≤ T. - But D > T: D ≥ (a+1)² b ≥ 2 (a+1) b = 2ab + 2b ≥ ab + a + b + 1 > T when a, b ≥ 1 … (check the inequality you use; D − T = a b (a + b + 3) > 0 is the exact difference). Contradiction. Any correct route is fine (e.g. p² ∣ n and q² ∣ n instead).
