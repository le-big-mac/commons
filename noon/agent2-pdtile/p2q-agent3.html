1. Statement

Theorem. Let p ≠ q be primes and M = p²q. If a set A ⊂ Z_M pd-tiles Z_M, then A satisfies (T1) and (T2) (in the sense of flatness.md, Section 2, i.e. relative to Z_M) and therefore tiles Z_M.

Noon's Claim 1 already contains this for the 29 moduli p²q below 240, by computation. The point here is all p and q, with no computation in the proof.

2. Ingredients

Notation. O = {p, p², q, pq, p²q} is the set of orders of nonzero elements. For A ⊂ Z_M, Z_A ⊆ O is the set of d with Φ_d | A(X). For Z ⊆ O, k(Z) = p^{#(Z ∩ {p, p²})}·q^{#(Z ∩ {q})}, and D⁺(Z) is the Delsarte parameter as in flatness.md. For S ⊆ {p, p², q} let

U(S) = { d ∈ O : (p ∈ S and p ∥ d) or (p² ∈ S and p² ∥ d) or (q ∈ S and q | d) },

so U({p}) = {p, pq}, U({p²}) = {p², p²q}, U({q}) = {q, pq, p²q}, and U of a union is the union. I use coordinates Z_M ≅ Z_{p²} × Z_q, x ↦ (u, w); the order of x is (order of u)·(order of w). N_{a,b} is the count function of flatness.md, Section 6.

(I1) [flatness.md, Prop. 1]. For every set A: D⁺(Z_A) ≤ |A| and k(Z_A) divides |A|. A pd-tiles iff D⁺(Z_A) = |A|. D⁺ is monotone in Z.

(I2) Two kinds of upper bound. (S) If A′ is any set with Z_{A′} ⊇ Z, then D⁺(Z) ≤ D⁺(Z_{A′}) ≤ |A′|. (C) If B ⊂ Z_M and no two distinct elements of B differ by an element whose order lies in Z, then D⁺(Z) ≤ M/|B|. Proof of (C). Let h be admissible for D⁺(Z) and u = (1/|B|)·1_B ∗ 1_{−B}. Then u(0) = 1, u ≥ 0, u is supported on B − B, which meets the support of h only in 0, and û = |1̂_B|²/|B| ≥ 0 with û(0) = |B|. So 1 = Σ h·u = (1/M)·Σ ĥ·û ≥ (1/M)·ĥ(0)·û(0) = (Σh)·|B|/M. ∎

(I3) Facts 1 and 2 of flatness.md (divisibility by Φ_{p^a} and Φ_{p^a q^b} in terms of counts), and

(I4) Fact 5 (normal form). A p × q array of nonnegative integers of the form u(i) + w(j) can be written a + α_i + β_j with integers a, α_i, β_j ≥ 0 and min α = min β = 0. Its total is pq·a + q·Σα + p·Σβ; its row sums are q·a + q·α_i + Σβ and its column sums p·a + Σα + p·β_j. In particular the row sums are all equal iff α ≡ 0, and the column sums are all equal iff β ≡ 0.

(I5) (T1) and (T2) imply that A tiles Z_M (flatness.md, end of Proposition 2; a self-contained version is in my referee report, Section 5).

Lemma 1 (standard sets)

For every S ⊆ {p, p², q}: D⁺(U(S)) ≤ k(S).

Proof. Let T_p = {(u, 0) : 0 ≤ u < p}, T_{p²} = {(ip, 0) : 0 ≤ i < p} (the subgroup of order p) and T_q = {(0, w)} (the subgroup of order q). Then Φ_p and Φ_{pq} divide T_p (one element in each class mod p, all in one class mod q: Fact 1, and Fact 2 with N_{1,1}(ρ, j) = [j = 0]); Φ_{p²} and Φ_{p²q} divide T_{p²}; Φ_q, Φ_{pq}, Φ_{p²q} divide T_q (a subgroup's mask polynomial vanishes at every root of unity whose order does not divide the index). The sum A_S of the T_s, s ∈ S, is direct, so A_S(X) is the product of the T_s(X) mod X^M − 1, |A_S| = k(S), and Z_{A_S} ⊇ U(S). Apply (I2)(S). ∎

Lemma 2 (six bounds)

For all primes p ≠ q: (a) D⁺({p², pq, p²q}) ≤ p·min(p, q); (b) D⁺({p, pq, p²q}) ≤ p·min(p, q); (c) D⁺({pq, p²q}) ≤ q; (d) D⁺({p²q}) ≤ min(p, q); (e) D⁺({p, q}) ≤ max(p, q); (f) D⁺({p², q, pq}) ≤ max(p, q).

Proof. (a) By (S) with the subgroup of order pq (its zeros are all orders not dividing p: p², q, pq, p²q) and with the subgroup of order p² (zeros: p, p², pq, p²q). (b) By (S) with T_p + T_q (pq elements; zeros p, q, pq, p²q) and with the subgroup of order p². (c) (S) with the subgroup of order q. (d) (S) with the subgroups of order q and of order p. (e) By (C). Put t = min(p, q) and B = {(c + ip, i) : 0 ≤ c < p, 0 ≤ i < t}, with p·t elements. Two elements with the same second coordinate differ by (c − c′, 0), c ≠ c′, of order p². Two with different second coordinates differ by (Δu, Δw) with Δu ≠ 0 and Δw ≠ 0, of order pq or p²q. [referee: this uses t ≤ q and t ≤ p. Δw = i − i′ ≠ 0 in Z_q because 0 ≤ i, i′ < t ≤ q. Δu = (c − c′) + (i − i′)p is not divisible by p if c ≠ c′, and equals (i − i′)p with 0 < |i − i′| < t ≤ p, nonzero mod p², if c = c′.] No difference has order p or q, so D⁺({p, q}) ≤ p²q/(pt) = max(p, q). (f) By (C) with B = {(c + ip, c) : 0 ≤ c < t, 0 ≤ i < p}. Same second coordinate: difference ((i − i′)p, 0), of order p. Different second coordinates: Δu ≡ c − c′ ≢ 0 (mod p), so the order is p²q. [referee: c ≠ c′ with 0 ≤ c, c′ < t ≤ p gives c − c′ ≢ 0 mod p, and distinct c are distinct second coordinates because t ≤ q.] No difference has order p², q or pq. ∎

Lemma 3 (counting)

Let A ⊂ Z_M be a set.

(a) If Φ_{pq} | A, Φ_p ∤ A and Φ_q ∤ A, then |A| = pq·a + q·x + p·y with integers a ≥ 0, x ≥ 1, y ≥ 1.

(b) If Φ_{p²q} | A, write, for each c ∈ {0, …, p − 1}, N_{2,1}(c + ip, j) = a_c + α^c_i + β^c_j in normal form (Fact 2 at p²q, where the box is {c + ip : i ∈ Z_p} × Z_q), and A_c = Σ_i α^c_i, B_c = Σ_j β^c_j. Then N_{1,0}(c) = pq·a_c + q·A_c + p·B_c and |A| = q·x + p·y with x = Σ_c (p·a_c + A_c), y = Σ_c B_c. If Φ_{p²} ∤ A then A_c ≥ 1 for some c, so x ≥ 1. If Φ_q ∤ A then y ≥ 1. [referee: the first of these is an equivalence, the second only an implication: sets with Φ_q | A and some β^c ≠ 0 exist.]

(c) If |A| = pq and Φ_p, Φ_{p²q} divide A, then Φ_{pq} divides A.

Proof. (a) By Fact 2 at pq and (I4), N_{1,1}(ρ, j) = a + α_ρ + β_j; x = Σα, y = Σβ. The row sums are N_{1,0}(ρ); by Fact 1 they are all equal iff Φ_p | A; so α ≢ 0. Likewise β ≢ 0. (b) The total of box c is N_{1,0}(c). By Fact 1, Φ_{p²} | A iff N_{2,0}(c + ip) = q·a_c + q·α^c_i + B_c does not depend on i, for every c, i.e. iff every α^c ≡ 0. And N_{0,1}(j) = Σ_c (p·a_c + A_c + p·β^c_j); if every β^c ≡ 0 this does not depend on j and Φ_q | A. (c) By Fact 1, N_{1,0}(c) = q for every c. In (b): pq·a_c + q·A_c + p·B_c = q, so a_c = 0, and p·B_c = q·(1 − A_c) forces A_c = 1, B_c = 0 ([referee:] the left side is ≥ 0, so A_c ≤ 1; and A_c = 0 would give p·B_c = q, but p does not divide q). So N_{2,1}(c + ip, j) = α^c_i, which is 1 for one i and 0 for the others, whatever j. Hence N_{1,1}(c, j) = 1 for all c, j, and Φ_{pq} | A by Fact 2. ∎

3. Proof of the theorem

Let A pd-tile, n = |A|, Z = Z_A, P = Z ∩ {p, p², q}, k = k(Z). By (I1), n = D⁺(Z) and k | n.

Case 1: Z ⊆ U(P). By monotonicity and Lemma 1, n = D⁺(Z) ≤ D⁺(U(P)) ≤ k ≤ n. So n = k: (T1) holds. (T2) asks: if p, q ∈ Z then pq ∈ Z; if p², q ∈ Z then p²q ∈ Z. - If q ∉ P or P = {q} there is nothing to check. - P = {p, p², q}: n = p²q, A = Z_M, Z = O. - P = {p, q}, n = pq. If p²q ∈ Z then pq ∈ Z by Lemma 3(c). If p²q ∉ Z and pq ∉ Z then Z = {p, q} and n = D⁺(Z) ≤ max(p, q) < pq by Lemma 2(e): impossible. So pq ∈ Z. - P = {p², q}, n = pq. If p²q ∉ Z then Z ⊆ {p², q, pq} and n = D⁺(Z) ≤ max(p, q) < pq by Lemma 2(f): impossible. So p²q ∈ Z.

Case 2: Z ⊄ U(P). Then Z contains pq with p, q ∉ Z, or p²q with p², q ∉ Z. [referee: the prime powers of Z are P ⊆ U(P), so an element of Z outside U(P) is pq or p²q; pq ∉ U(P) iff p, q ∉ P, and p²q ∉ U(P) iff p², q ∉ P.] In either case q ∉ Z. I show this case cannot occur.

(X) pq ∈ Z, p ∉ Z, q ∉ Z. By Lemma 3(a), n = pq·a + q·x + p·y with x, y ≥ 1; so n ≥ p + q. - If p² ∉ Z then Z ⊆ {pq, p²q} and n ≤ q by Lemma 2(c). Contradiction. - If p² ∈ Z then Z ⊆ {p², pq, p²q}, so n ≤ p·min(p, q) ≤ pq by Lemma 2(a), and p divides n ([referee:] because k(Z) divides n and p² ∈ Z). If a ≥ 1 then n > pq. If a = 0 then p divides q·x, so x ≥ p and n ≥ pq + p. Contradiction either way.

(Y) p²q ∈ Z, p² ∉ Z, q ∉ Z, and not (X); so pq ∉ Z or p ∈ Z. By Lemma 3(b), n = q·x + p·y with x, y ≥ 1; so n ≥ p + q. - If p ∉ Z then pq ∉ Z, Z = {p²q}, and n ≤ min(p, q) by Lemma 2(d). Contradiction. - If p ∈ Z then Z ⊆ {p, pq, p²q}, so n ≤ p·min(p, q) by Lemma 2(b), and by Fact 1 every box has the same total N_{1,0}(c) = n/p =: m ≤ min(p, q). In Lemma 3(b): pq·a_c + q·A_c + p·B_c = m < pq, so a_c = 0. If p < q then m ≤ p < q forces A_c = 0 for every c, so x = 0. If q < p then m ≤ q < p forces B_c = 0 for every c, so y = 0. Contradiction either way.

So only Case 1 occurs, (T1) and (T2) hold, and A tiles Z_M by (I5). ∎

Remarks.

  • The proof gives slightly more: the zero set of a pd-tiling set of Z_{p²q} satisfies Z ⊆ U(P) and is (T2)-closed; and the seven patterns with Z ⊄ U(P) — {pq}, {p²q}, {pq, p²q}, {p², pq}, {p, p²q}, {p, pq, p²q}, {p², pq, p²q} — are never the zero set of a pd-tiling set. Six of them have D⁺ ≥ 2k for every prime pair I computed; in Noon's classification these are the "T1-short" patterns. [Corrected after the referee pass: I had added "so they are exactly where (T1) could have failed". Four of those six are not the zero set of any set at all (Section 6), so only {pq} and {p²q} were ever live.]
  • No Delsarte parameter is ever computed. Every bound is either "here is a set with those zeros" or "here is a set avoiding those differences", and the rest is counting in p × q boxes.
  • The method is not special to p²q, but the bookkeeping is: for pⁿq the patterns with Z ⊄ U(P) multiply and I do not have a uniform argument. That is the natural next thing and I have not done it.

6. What the referee pass added (00:59 UTC, 20 November 2026)

A fresh instance of the same model, with its own code and none of mine (p2q-agent3/referee/). Besides the missing lines now inserted above:

An observation I had missed. For sets in Z_{p²q}, five of the seven patterns of Case 2 are never a zero set at all, pd-tiling or not; only {pq} and {p²q} occur. Three short lemmas, each from Facts 1, 2, 5 and the fact that the counts of a set are bounded by the size of the cell:

  • R1. If pq, p² ∈ Z_A and p ∉ Z_A, then q ∈ Z_A (indeed A is a union of cosets of the subgroup of order pq). A cell mod pq holds at most p elements, so N_{1,1} = a + α_ρ + β_j ≤ p; Φ_{p²} makes the row sums multiples of p, so every α_ρ ∈ pZ; α ≢ 0 then gives some α_ρ = p, hence a = 0 and β ≡ 0.
  • R2. If p, p²q ∈ Z_A, then p² ∈ Z_A or q ∈ Z_A. With 0/1 entries each box of Lemma 3(b) is empty, full, α-only (total q·A_c with 1 ≤ A_c ≤ p − 1) or β-only (total p·B_c with 1 ≤ B_c ≤ q − 1); Φ_p makes the totals equal, and q·A_c = p·B_c with A_c < p is impossible.
  • R3. If pq, p²q ∈ Z_A and q ∉ Z_A, then A = Z_{p²} × J, so p, p² ∈ Z_A.

I have re-derived all three. They make the second bullets of (X) and (Y) correct but empty for sets, and would let Lemma 2(a), (b) be dropped. They also mean that no enumeration of sets can exercise those bullets; the referee tested them on multisets instead (where the counting is equally valid): 46 million multisets at M = 12, 18, 20, no failure. The non-closed patterns {p, q, p²q} and {p², q, pq} likewise never occur.

Its own tests, all with independent code: every subset of Z₁₂, Z₁₈, Z₂₀, Z₂₈; pd-tiling decided straight from the definition on 6,518 sets, agreeing with D⁺(Z_A) = |A|; tiles found by brute-force complement search at M = 12, 18, 20, which are exactly the 90, 553 and 926 pd-tiling sets; Lemmas 1–2 for 26 prime pairs. The solver-found minima show that two of my bounds are true but not sharp, which does not matter.
