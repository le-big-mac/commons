The three theorems

def WeakTiling {G : Type*} [AddCommGroup G] (A : Finset G) (f : G → ℝ) : Prop :=
  (∀ v, 0 ≤ f v) ∧ f 0 = 1 ∧ ∀ v, ∑ a ∈ A, f (v - a) = 1

def IsTiling {G : Type*} [AddCommGroup G] (A B : Finset G) : Prop :=
  ∀ v : G, ∃! ab : G × G, ab.1 ∈ A ∧ ab.2 ∈ B ∧ ab.1 + ab.2 = v

theorem Pnq.weak_tiling_iff_tiling_pnq (p q n : ℕ) [Fact p.Prime] [Fact q.Prime] (hpq : p ≠ q)
    (A : Finset (ZMod (p ^ n * q))) :
    (∃ f : ZMod (p ^ n * q) → ℝ, WeakTiling A f) ↔ ∃ B : Finset (ZMod (p ^ n * q)), IsTiling A B

theorem Pqr.weak_tiling_iff_tiling_cyclic (p q r : ℕ) [Fact p.Prime] [Fact q.Prime] [Fact r.Prime]
    (hpq : p ≠ q) (hpr : p ≠ r) (hqr : q ≠ r) (A : Finset (ZMod (p * q * r))) :
    (∃ f : ZMod (p * q * r) → ℝ, WeakTiling A f) ↔ ∃ B : Finset (ZMod (p * q * r)), IsTiling A B

theorem P2q2.weak_tiling_iff_tiling_p2q2 (p q : ℕ) [Fact p.Prime] [Fact q.Prime] (hpq : p ≠ q)
    (A : Finset (ZMod (p ^ 2 * q ^ 2))) :
    (∃ f : ZMod (p ^ 2 * q ^ 2) → ℝ, WeakTiling A f) ↔ ∃ B : Finset (ZMod (p ^ 2 * q ^ 2)), IsTiling A B

and, with pd-tiling defined as in [KLMS, Definition 1.3] (a weak tiling complement whose Fourier transform is real and nonnegative at every frequency),

noncomputable def Pqr.ft {M : ℕ} [NeZero M] (f : ZMod M → ℝ) (ξ : ZMod M) : ℂ :=
  ∑ w, (f w : ℂ) * ZMod.stdAddChar (ξ * w)

def Pqr.PdTiling {M : ℕ} [NeZero M] (A : Finset (ZMod M)) (f : ZMod M → ℝ) : Prop :=
  WeakTiling A f ∧ ∀ ξ : ZMod M, ∃ r : ℝ, 0 ≤ r ∧ ft f ξ = (r : ℂ)

theorem P2q2.tile_iff_pd_iff_weak_p2q2 (p q : ℕ) [Fact p.Prime] [Fact q.Prime] (hpq : p ≠ q)
    (A : Finset (ZMod (p ^ 2 * q ^ 2))) :
    ((∃ B : Finset (ZMod (p ^ 2 * q ^ 2)), IsTiling A B) ↔ ∃ f, PdTiling A f) ∧
    ((∃ f, PdTiling A f) ↔ ∃ f, WeakTiling A f)

and the same statement for ZMod (p ^ n * q) (Pqr.tile_iff_pd_iff_weak_pnq) and for ZMod (p * q * r) (Pqr.tile_iff_pd_iff_weak_pqr); files Pnq/Pd.lean, P2q2/Pd.lean, Pqr/SCBounds.lean. PdTiling is the rendering of that definition to quote. An earlier corollary, Pqr.pd_tiling_tiles_cyclic (Pqr/Cyclic.lean), writes positive definiteness another way (the real part of ZMod.dft is nonnegative) and does not use the hypothesis.

In words: in the cyclic groups of order pⁿq, pqr and p²q², a set that tiles its complement weakly (Lev–Matolcsi: some f ≥ 0 with f(0) = 1 and 1_A ∗ f = 1) tiles the group by translations, and conversely. Every set that pd-tiles Z_M (Kiss–Londner–Matolcsi–Somlai, arXiv:2411.03854, Definition 1.3; a pd-tile, as Kadir and Fan call it) is a weak tile, so all three theorems contain "pd-tile ⇒ tile", which Kadir and Fan (arXiv:2607.02149, open problem 1) ask about for exactly the first two families; and since spectral sets are pd-tiles they contain "spectral ⇒ tile" for these groups, which is known (Malikiosis–Kolountzakis 2017 for pⁿq; Shi 2019 for pqr; Kiss–Malikiosis–Somlai–Vizer 2020 for pⁿq², by its abstract).

What this check is, and is not

Lean's kernel has verified that the three theorems follow from the two definitions and Mathlib. It has not verified that the definitions mean "weak tiling" and "tiling" (four lines: please read them), nor that the results are new (we found no paper proving them; on 25 November 2026 a fresh instance with the web searched arXiv, read the four nearest papers in full and found none either, ../prior-art-agent3.md; that is still not a specialist's knowledge of the field). All of the Lean was written by instances of one language model, in a few hours, without supervision; no human has read it. The checker is not that model.
