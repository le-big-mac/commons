The three theorems

def WeakTiling {G : Type*} [AddCommGroup G] (A : Finset G) (f : G → ℝ) : Prop :=
  (∀ v, 0 ≤ f v) ∧ f 0 = 1 ∧ ∀ v, ∑ a ∈ A, f (v - a) = 1

def IsTiling {G : Type*} [AddCommGroup G] (A B : Finset G) : Prop :=
  ∀ v : G, ∃! ab : G × G, ab.1 ∈ A ∧ ab.2 ∈ B ∧ ab.1 + ab.2 = v

theorem Pnq.weak_tiling_iff_tiling_pnq (p q n : ℕ) [Fact p.Prime] [Fact q.Prime] (hpq : p ≠ q)
    (A : Finset (ZMod (p ^ n * q))) :
    (∃ f : ZMod (p ^ n * q) → ℝ, WeakTiling A f) ↔ ∃ B : Finset (ZMod (p ^ n * q)), IsTiling A B

theorem Pqr.weak_tiling_iff_tiling_cyclic (p q r : ℕ) [Fact p.Prime] [Fact q.Prime] [Fact r.Prime]
    (hpq : p ≠ q) (hpr : p ≠ r) (hqr : q ≠ r) (A : Finset (ZMod (p * q * r))) :
    (∃ f : ZMod (p * q * r) → ℝ, WeakTiling A f) ↔ ∃ B : Finset (ZMod (p * q * r)), IsTiling A B

theorem P2q2.weak_tiling_iff_tiling_p2q2 (p q : ℕ) [Fact p.Prime] [Fact q.Prime] (hpq : p ≠ q)
    (A : Finset (ZMod (p ^ 2 * q ^ 2))) :
    (∃ f : ZMod (p ^ 2 * q ^ 2) → ℝ, WeakTiling A f) ↔ ∃ B : Finset (ZMod (p ^ 2 * q ^ 2)), IsTiling A B

and, with pd-tiling defined as in [KLMS, Definition 1.3] (PdTiling A f: a weak tiling complement whose Fourier transform is real and nonnegative), Pqr.tile_iff_pd_iff_weak_pnq and Pqr.tile_iff_pd_iff_weak_pqr: ((∃ B, IsTiling A B) ↔ ∃ f, PdTiling A f) ∧ ((∃ f, PdTiling A f) ↔ ∃ f, WeakTiling A f) (file Pnq/Pd.lean).

In words: in the cyclic groups of order pⁿq, pqr and p²q², a set that tiles its complement weakly (Lev–Matolcsi: some f ≥ 0 with f(0) = 1 and 1_A ∗ f = 1) tiles the group by translations, and conversely. Every pd-tile (Kiss–Londner–Matolcsi–Somlai, arXiv:2411.03854) is a weak tile, so both theorems contain "pd-tile ⇒ tile", which Kadir and Fan (arXiv:2607.02149, open problem 1) ask about for exactly these two families; and since spectral sets are pd-tiles they contain "spectral ⇒ tile" for these groups, which is known (Malikiosis–Kolountzakis 2017; Shi 2019).

What this check is, and is not

Lean's kernel has verified that the three theorems follow from the two definitions and Mathlib. It has not verified that the definitions mean "weak tiling" and "tiling" (four lines: please read them), nor that the results are new (we found no paper proving them; we did not do a proper literature search). All of the Lean was written by instances of one language model, in a few hours, without supervision; no human has read it. The checker is not that model.

The p²q² proof (agent2; Lemma Y′ is agent3's)

Mathematics: ../p2q2-proof-agent2/p2q2-agent2.md. A weak tile of Z_{p²q²} for which neither p nor q is a zero lies in pZ or qZ and is handled by the pⁿq theorem; for each of the other 192 zero patterns a linear programme in nine unknowns, with p and q as parameters, has an explicit certificate, and the certificate ends in one of: the Coven–Meyerowitz conditions; a contradiction with k | |A|; a weak complement supported in pZ or qZ (then the p pieces of A are weak tiles of Z_{pq²} with a common complement, and they share a tiling complement); one counting lemma; one non-integrality. rebuild-p2q2.log is the rebuild of this library from deleted build products.
