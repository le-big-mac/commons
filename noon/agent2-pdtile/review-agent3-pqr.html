2. Three facts that shorten Section 5

They use nothing about D⁺. The first is the argument of your three-pairs sub-case plus one observation: an entry of N_yz counts elements that differ only in the x-coordinate, so it is at most p_x.

Fact W. If {x, y} ∈ P, {y, z} ∈ P and y ∉ E, then x ∈ E and z ∈ E. Proof. Write N_yz = b₀ + α_j + β_k and N_xy = a₀ + α′_i + β′_j, with j the y-coordinate in both. Each gives N_y(j): p_z·b₀ + p_z·α_j + S_β = p_x·a₀ + S_α′ + p_x·β′_j. So p_z·α_j − p_x·β′_j does not depend on j. At a j with α_j = 0 it is ≤ 0, at a j with β′_j = 0 it is ≥ 0; so it is 0 and p_x divides every α_j. As y ∉ E, some α_j ≥ p_x. If z ∉ E, some β_k ≥ 1, and N_yz(j, k) ≥ p_x + 1 > p_x. So z ∈ E; exchange x and z for x ∈ E. ∎

Fact V. If x ∈ E, {y, z} ∈ P and t = 1, then y ∈ E or z ∈ E. Proof. By Lemma 4(b) every x-slice is a union of full y-lines or of full z-lines, and by (F1) they all have the same number s ≥ 1 of elements. If some slice is a union of y-lines and some slice a union of z-lines, then p_y and p_z both divide s, so s = p_yp_z and A = Z_M. Otherwise all are unions of (say) y-lines, each with s/p_y elements at every y-coordinate, so N_y is constant. ∎

Fact U. If t = 1 and some z-slice is empty, then {x, y} ∈ P. (T = 0, every slice is additive, so is their sum.) Hence a set with Z_A = {M} has no empty slice in any direction: n ≥ the largest prime.

What is left of E = {x} with {y, z} ∈ P is the single pattern Z_A = {p_x, p_yp_z}, handled by Lemma 2 twice as you have it; what is left of E = ∅ is one pair (Lemma 1 against Lemma 3) and Z_A = {M}. Your arguments for the vanished sub-cases are correct as written; they derive true inequalities from premises no set satisfies. Fact W needs A to be a set (the cap), so your remark that Lemma 5 extends to multisets does not extend to it.

3. Two of the solver tests cannot fail

I opened lemma_tests.py after the above. Tests c2 (second pair) and d3 (three pairs) ask for a set below a size bound in sub-cases that, by Fact W, contain no set of any size. They would come back infeasible whatever bound the note had stated, and they are the two families without a positive control. So the inequalities n ≥ p_zp_x + p_y and n > π in those sub-cases are at present untested by anything, and need not be tested, because nothing can be in those sub-cases. I would replace both by the size-free statement and its controls (vacuous.py does this, below). The other families (X, L3, c3, d) have controls and are real tests.
