What is proved so far, part 1 (Pnq/Tree.lean, 600 lines, no sorry)

A subset of Z_{pⁿ} × Z_q is stored as a p-ary tree of depth n: the children of a node are the residue classes of the next base-p digit, lowest digit first, and a leaf holds the q counts of one residue u mod pⁿ. The level conditions are defined by recursion on the tree, which is Lemma 0 of the note turned into a definition:

inductive Tree (p q : ℕ) : ℕ → Type
  | leaf : (Fin q → ℕ) → Tree p q 0
  | node {n : ℕ} : (Fin p → Tree p q n) → Tree p q (n + 1)

def E : {n : ℕ} → Tree p q n → ℕ → Prop          -- E t ℓ  is  Φ_{p^ℓ} ∣ A   (1 ≤ ℓ ≤ n)
  | _, .leaf _, _ => False
  | _, .node _, 0 => False
  | _, .node ch, 1 => ∀ c c', size (ch c) = size (ch c')
  | _, .node ch, ℓ + 2 => ∀ c, E (ch c) (ℓ + 1)

def F : {n : ℕ} → Tree p q n → ℕ → Prop          -- F t ℓ  is  Φ_{p^ℓ q} ∣ A   (0 ≤ ℓ ≤ n)
  | _, t, 0 => ∀ j j', lay t j = lay t j'
  | _, .leaf _, _ + 1 => False
  | _, .node ch, 1 => ∀ c c' j j', lay (ch c) j + lay (ch c') j' = lay (ch c) j' + lay (ch c') j
  | _, .node ch, ℓ + 2 => ∀ c, F (ch c) (ℓ + 1)

With e t the number of levels 1..n at which E holds, for 2 ≤ p, 2 ≤ q, p and q coprime:

  • pow_e_dvd_size, pow_e_mul_q_dvd_size: p^e divides |A|, and p^e·q does if Φ_q ∣ A (the note's (I1)).
  • lemma3: Lemma 3. ¬F t 0, F t (a+1), ¬E t (a+1) ⟹ p^e (p + q) ≤ |A|.
  • lemma4: Lemma 4. |A| > 0, F t 0, |A| = p^e q, F t (b+1), ¬E t (b+1) ⟹ for every a < b, E t (a+1) → F t (a+1).
  • counting: Section 5. If |A| > 0 obeys the three upper bounds (U1) |A| ≤ p^e q, (U2) |A| ≤ p^e when Φ_q ∤ A and F ⊆ E, (L2) |A|·min(p, q) ≤ p^e q when Φ_q ∣ A, a ∈ E ∖ F and E, F agree above a, then (T1) and (T2) hold.

lake build succeeds and #print axioms gives [propext, Classical.choice, Quot.sound] for all four. The leaves hold natural numbers, so the three statements are proved for multisets; primality of p and q is not used, only coprimality and p, q ≥ 2.

What a Lean check of this part is worth

The kernel has checked that Lemmas 3 and 4 and the case analysis follow from the definitions above. Those two lemmas and their inductions are what three readings by instances of one model could not settle. It has not checked that E t ℓ and F t ℓ are the cyclotomic conditions for the tree of a set. That is a statement about the bridge, not yet formal. In its place for now: validate/tree_vs_cyclo.py evaluates the same recursive definitions, transcribed from the Lean source, on the trees of 706,984 sets in 13 groups (every subset containing 0 for M = 6, 10, 12, 18, 20; samples up to M = 96, up to 116 distinct patterns per group) and compares them with exact division of the mask polynomial by Φ_d: no mismatch.

Added at 09:41 UTC: the three bounds, from a step complement (Pnq/Step.lean, 590 lines, no sorry)

A step complement is γ : ℕ → Bool → ℝ: γ d true is the weight of an element that agrees with the point on exactly the lowest d digits and lies in the same layer, γ d false of one in another layer (d = n: the same residue). The identity 1_A ∗ f = 1 is written by recursion on the tree:

def Tiles (γ : ℕ → Bool → ℝ) : {n : ℕ} → ℕ → Tree p q n → (Fin q → ℝ) → Prop
  | _, d, .leaf f, ext =>
      ∀ w, ext w + γ d true * (f w : ℝ) + γ d false * ((∑ j, (f j : ℝ)) - (f w : ℝ)) = 1
  | _, d, .node ch, ext => ∀ c, Tiles γ (d + 1) (ch c) (extChild γ d ch c ext)

def StepTiling (γ : ℕ → Bool → ℝ) {n : ℕ} (t : Tree p q n) : Prop :=
  (∀ d b, 0 ≤ γ d b) ∧ γ n true = 1 ∧ Tiles γ 0 t (fun _ => 0)

theorem step_structure (hp : 2 ≤ p) (hq : 2 ≤ q) (hpq : Nat.Coprime p q) {n : ℕ} (t : Tree p q n)
    (γ : ℕ → Bool → ℝ) (hst : StepTiling γ t) :
    size t = p ^ e t * (if F t 0 then q else 1) ∧ (F t 0 → ∀ ℓ, E t (ℓ + 1) → F t (ℓ + 1))

So: a set with a step weak-tiling complement satisfies (T1) and (T2), kernel-checked, with no character or Fourier transform anywhere. tiles_sum sums the identity over a subtree (|A|·Γ = pⁿq at the root); XY_of_not_E and X_of_not_F are the linear relations between the weights that a failing level condition forces (what f̂ = 0 at order p^ℓ or p^ℓ q would say); G_mul, K_mul, L2_step turn them into "a level outside E multiplies the total by p" and into the clique bound without a clique; step_U1, step_U2, step_L2 are the note's three bounds; step_structure feeds them to counting. All nine theorems in Check.lean depend only on propext, Classical.choice, Quot.sound.

A check that Tiles says what it should (validate/tiles_vs_convolution.py): for 3,000 random sets and random weights of either sign in 10 groups, the left-hand sides built by the same recursion equal the convolution computed directly in Z_M to 1e-14; and on every subset containing 0 of Z_6 (both ways), Z_10, Z_12 and Z_18 (9, 9, 23, 90 and 553 sets respectively), the sets that admit a step complement (a linear program) are exactly the sets that tile, and exactly those with (T1) and (T2) in the Lean definitions. So the hypothesis of step_structure is met by real sets and by the right ones.

What is still missing before this is the theorem

  1. From a weak complement on the group to a step complement on the tree: Galois conjugation and averaging over the unit dilations of Z_{pⁿ} and Z_q (as in Noon's Pqr/Fourier.lean), and the definition of the tree of a set in ZMod (p^n) × ZMod q with a proof that the group identity becomes Tiles.
  2. (T1) and (T2) give a tiling: the complement has a free digit exactly at the levels outside E; existence and uniqueness of a + b = v go digit by digit, with carries.
  3. Until 1 is formal, that E and F are the cyclotomic conditions is supported only by the numerical comparison above. The final theorem will not need that sentence at all: its statement will mention only WeakTiling and IsTiling, and the tree will be internal to the proof.
