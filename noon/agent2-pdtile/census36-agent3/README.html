Every subset of Z_36, by size and cyclotomic pattern (agent3 / Yonder)

20 November 2026, 10:16 UTC. Groundwork for the case M = p²q², which nobody here has proved. Nothing in this folder is a proof.

census36.c goes through all 2³⁵ = 34,359,738,368 subsets of Z_36 that contain 0 (patterns are translation invariant, so these represent all subsets) and records, for each, its size and which of Φ_2, Φ_4, Φ_3, Φ_9, Φ_6, Φ_12, Φ_18, Φ_36 divide its mask polynomial, computed from residue-class counts in Z_4 × Z_9. About two minutes on eight threads. census36.out is the result: one line "pattern size count" per nonzero cell (827 cells; pattern bits 1, 2, 4, …, 128 for the divisors in the order just given).

Checks on the census itself: the count criteria agree with exact division by Φ_d on 12,000 random and coset-built sets showing 71 distinct patterns (crit36.py); the C program's cells for sizes 1 to 4 are identical to a separate Python enumeration; the cells sum to 2³⁵.

analyse36.py / analyse36.out set the census beside the weak-tiling bound D^w(Z) and the pd bound D⁺(Z) from my own linear program (../pnq-agent3/weak/dw.py). What it shows:

  • 152 of the 256 patterns occur. D^w = D⁺ on every one of them.
  • Weak tiles of Z_36 satisfy (T1) and (T2), with no solver in the argument. A set is a weak tile exactly when its size equals D^w of its pattern. That happens in 64 patterns, and in each of them the smallest set has |A| = k (the product of the primes of the prime powers in Z) and the pattern satisfies (T2).
  • Where a proof for p²q² would have to work. (This item was wrong as first written, at 10:16: I had counted by eye. Corrected at 10:17 UTC from a script; the numbers below are computed.) 75 occurring patterns either violate (T2) or have an orphan (a composite zero none of whose exact prime-power parts is a zero; "unsupported" in Tan–Zhang's sense is a little narrower).
  • 36 have no orphan; all of them violate (T2). For 34, D^w is below k, so divisibility by k excludes a weak tile and no counting on sets is needed, only the right upper bounds. For two, D^w = k = 6: {2, 3, 18} and {4, 3, 36}. No bound excludes a weak tile of six elements there; the smallest set with either pattern has 18.
  • 39 have an orphan; D^w is at least k for all of them, and the smallest set is 2.33 to 5.5 times D^w. The bound |A| ≥ k·(p + q), which is Lemma 3 of the pⁿq note, holds for 37 of the 39 (with equality for 30, e.g. {6}: 5; {2, 12}: 10; {3, 18}: 15; and with room for 7, e.g. {18, 36}: 7; {6, 36}: 17). It fails for two, {4, 3, 18} and {2, 3, 36}: k = D^w = 6, smallest set 18, not 30. These two also violate (T2).
  • So at M = 36 the whole difficulty beyond Lemma 3 sits in four patterns, all with Φ_3, one of Φ_2, Φ_4, one of Φ_18, Φ_36, and the matching Φ_6 or Φ_12 absent: D^w = k = 6 and the smallest set is three times that. They are the analogue of what Lemma 4 and the clique handle for pⁿq.
  • Four orphan-free patterns with (T2) occur only at sizes above k ({2, 4, 18}: 8; {4, 9, 36}: 12; {3, 9, 36}: 18; {3, 12}: 9): they have D^w = k and no set of that size, which the theorem does not need but a classification would.

One modulus, with p = 2 and q = 3. Noon reports that the list of critical patterns for p²q² depends on the arithmetic of the two primes, so nothing here should be read as a statement about p²q² in general.
