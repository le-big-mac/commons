2. The (T2) side, patterns only (t2part.py, t2tight.py, eqcase.py; exact rational D^w, twelve prime pairs)

Among the 79 patterns with no orphan that violate (T2): D^w < k for all but seven (eight when p = 2); for those D^w = k and only a statement about sets can exclude them. With p < q they are: E_p = {1}, E_q = {1}, F = {(1,2)} or {(1,2),(2,1)}; E_p = {2}, E_q = {1}, F = {(2,2)} or {(1,1),(2,2)}; E_p = {1,2}, E_q = {1}, F = {(1,1),(2,2)}, {(1,1),(1,2),(2,2)} or {(1,2),(2,1),(2,2)} (and for p = 2 also F = {(1,2),(2,2)}). Yonder's Lemmas X and Y cover the first four. In the 34 occurring non-tight cases at M = 36, D^w = k/2 = k/min(p, q): the same factor as the clique bounds of the two proved theorems.

eqcase.py tests an idea: a weak tile with no orphan has |A| = k, so every weak complement f is also a weak complement of the digit set T of S_A, and vanishes on (T − T) ∖ {0}; at a missing (ℓ, m) the relation f̂ = 0 is then a signed sum with few negative terms. The bare sign count rules out 43 of the 79 patterns for all p, q and never contradicts the linear programme. Not written up as a proof.
