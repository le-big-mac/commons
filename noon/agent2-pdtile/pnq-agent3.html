1. Statement

Theorem. Let p ≠ q be primes, n ≥ 1, M = pⁿq. If A ⊂ Z_M pd-tiles Z_M, then A satisfies (T1) and (T2) relative to Z_M (as in flatness.md, Section 2), and therefore tiles Z_M.

So tiles and pd-tiles coincide in Z_{pⁿq}. (Since spectral sets pd-tile, this also gives "spectral ⇒ tile" in Z_{pⁿq}; that direction of Fuglede's conjecture in these groups is already a theorem of Malikiosis and Kolountzakis, Discrete Analysis 2017, which I cite from the bibliography of Kadir–Fan and have not read.)

2. Notation and ingredients

Coordinates: Z_M ≅ Z_{pⁿ} × Z_q, x ↦ (u, w). An element with Δu ≠ 0 of p-adic valuation v and Δw arbitrary has order p^{n−v}, times q if Δw ≠ 0. For a set A, the layer A_j is {u : (u, j) ∈ A}. For 0 ≤ ℓ ≤ n, N_ℓ(r, j) is the number of u ∈ A_j with u ≡ r (mod p^ℓ), and N_ℓ(r) = Σ_j N_ℓ(r, j).

E(A) = { ℓ ∈ {1,…,n} : Φ_{p^ℓ} | A },     F(A) = { ℓ ∈ {0,…,n} : Φ_{p^ℓ q} | A },     e(A) = |E(A)|.

So Z_A = {p^ℓ : ℓ ∈ E} ∪ {p^ℓ q : ℓ ∈ F}, and 0 ∈ F means Φ_q | A. In this notation, for M = pⁿq: (T1) is |A| = p^e·q^{[0 ∈ F]}, and (T2) is: if 0 ∈ F then E ⊆ F.

(I1) [flatness.md, Prop. 1 and Fact 4]. For every nonempty set A: D⁺(Z_A) ≤ |A|; A pd-tiles iff D⁺(Z_A) = |A|; and p^{e(A)}·q^{[0 ∈ F(A)]} divides |A|. D⁺ is monotone in Z.

(I2) Two kinds of upper bound, valid in any Z_M. (S) If A′ is a set with Z_{A′} ⊇ Z, then D⁺(Z) ≤ D⁺(Z_{A′}) ≤ |A′|, by monotonicity and (I1). (C) If no two distinct elements of B ⊂ Z_M differ by an element whose order lies in Z, then D⁺(Z) ≤ M/|B|. Proof of (C). Let h be admissible for D⁺(Z) and u = (1/|B|)·1_B ∗ 1_{−B}. Then u(0) = 1, u ≥ 0, u is supported on B − B, which meets the support of h only in 0, and û = |1̂_B|²/|B| ≥ 0 with û(0) = |B|. So 1 = Σ h·u = (1/M)·Σ ĥ·û ≥ (1/M)·ĥ(0)·û(0) = (Σh)·|B|/M. ∎

A consequence of (I1) and (S) worth saying on its own: a pd-tiling set has the smallest cardinality among all sets whose mask polynomial has at least the same cyclotomic factors Φ_d, d | M.

(I3) [flatness.md, Facts 1 and 2, for M = pⁿq]. For ℓ ≥ 1: ℓ ∈ E(A) iff N_ℓ(r + i·p^{ℓ−1}) = N_ℓ(r) for all r, i; ℓ ∈ F(A) iff for every r the p × q array (i, j) ↦ N_ℓ(r + i·p^{ℓ−1}, j) has the form u(i) + w(j); 0 ∈ F(A) iff all layers have the same size.

(I4) Fact 5 (normal form). A p × q array of nonnegative integers of the form u(i) + w(j) can be written a₀ + α_i + β_j with integers a₀, α_i, β_j ≥ 0 and min α = min β = 0. Its total is pq·a₀ + q·S_α + p·S_β (S_α = Σα_i, S_β = Σβ_j); its row sums are q·a₀ + q·α_i + S_β; its column sums are p·a₀ + S_α + p·β_j. So the row sums are all equal iff α ≡ 0, and the column sums are all equal iff β ≡ 0.

(I5) (T1) and (T2) imply that A tiles Z_M (flatness.md, end of the proof of Proposition 2).

Lemma 0 (subtrees)

Let n ≥ 1. For ρ ∈ {0, …, p − 1} put A^ρ = {(u′, w) ∈ Z_{p^{n−1}} × Z_q : (ρ + p·u′, w) ∈ A}, a subset of Z_{p^{n−1}q} ([referee:] in the product coordinates of that group; E(A^ρ) and F(A^ρ) are read through (I3) in those coordinates). Then |A| = Σ_ρ |A^ρ| and:

(a) for ℓ ≥ 2: ℓ ∈ E(A) iff ℓ − 1 ∈ E(A^ρ) for every ρ with A^ρ ≠ ∅; and ℓ ∈ F(A) iff ℓ − 1 ∈ F(A^ρ) for every ρ with A^ρ ≠ ∅; (b) 1 ∈ E(A) iff all |A^ρ| are equal; 1 ∈ F(A) iff the p × q array (ρ, j) ↦ |A^ρ_j| has the form u(ρ) + w(j); 0 ∈ F(A) iff Σ_ρ |A^ρ_j| does not depend on j.

Proof. For r = ρ + p·r′ the elements of A_j congruent to r mod p^ℓ correspond to the elements of (A^ρ)_j congruent to r′ mod p^{ℓ−1}, and adding i·p^{ℓ−1} to r adds i·p^{ℓ−2} to r′. So the conditions of (I3) at level ℓ ≥ 2 for A are the conditions at level ℓ − 1 for the A^ρ, taken together (an empty A^ρ contributes nothing). (b) is (I3) at ℓ = 1 and ℓ = 0, since N_1(ρ, j) = |A^ρ_j|. ∎

3. Two upper bounds and one clique

For E ⊆ {1, …, n} let T_E = { Σ_{ℓ ∈ E} d_ℓ·p^{ℓ−1} : 0 ≤ d_ℓ < p } ⊂ Z_{pⁿ}, a set of p^{|E|} elements.

Lemma 1. For every nonempty A ⊂ Z_M with E = E(A), F = F(A), e = e(A): (U1) D⁺(Z_A) ≤ p^e·q; (U2) if 0 ∉ F and F ⊆ E, then D⁺(Z_A) ≤ p^e.

Proof. For ℓ ∈ E the digit d_ℓ of an element of T_E is free, so the number of elements of T_E in a class mod p^ℓ does not change when i·p^{ℓ−1} is added to the class: Φ_{p^ℓ} | T_E. (U1): A′ = T_E × Z_q has all layers equal to T_E. So N_ℓ(r, j) does not depend on j (hence ℓ ∈ F(A′) for every ℓ ≥ 1, and 0 ∈ F(A′)), and E(A′) ⊇ E. So Z_{A′} ⊇ Z_A and |A′| = p^e·q; apply (S). (U2): A″ = T_E × {0} has E(A″) ⊇ E, and for ℓ ∈ E the array (i, j) ↦ N_ℓ(r + i·p^{ℓ−1}, j) does not depend on i, so F(A″) ⊇ E. If 0 ∉ F and F ⊆ E then Z_{A″} ⊇ Z_A, and |A″| = p^e. ∎

Lemma 2 (a clique). Let A be a nonempty set with 0 ∈ F and E ⊄ F, where E = E(A), F = F(A) ([referee:] the hypothesis 0 ∈ F is not used in the proof; it is only the case in which the lemma is applied). Let a = max(E ∖ F) and suppose that no ℓ > a lies in F ∖ E. Then D⁺(Z_A) ≤ p^e·q / min(p, q).

Proof. Write u = Σ_{i=0}^{n−1} d_i·p^i; digit position i corresponds to level ℓ = n − i, in the sense that two elements whose lowest differing digit is at position i differ by an element of order p^{n−i}. Let t = min(p, q) and let B be the set of all (u, w) with - d_{n−a} ∈ {0, …, t − 1} and w = d_{n−a}; - at positions i < n − a (levels ℓ > a): d_i arbitrary if ℓ ∉ E ∪ F, and d_i = 0 otherwise; - at positions i > n − a (levels ℓ < a): d_i arbitrary if ℓ ∉ E, and d_i = 0 otherwise.

[referee:] The digits are legal because t ≤ p; the second coordinate w = d_{n−a} is a function of u, so distinct elements of B have distinct u; and distinct values of d_{n−a} are distinct in Z_q because t ≤ q. Take two distinct elements of B and let ℓ be the level of their lowest differing digit. If ℓ > a, then ℓ ∉ E ∪ F, so their difference has order p^ℓ or p^ℓ q, neither in Z_A. If ℓ = a, their second coordinates differ, so the order is p^a q, and a ∉ F. If ℓ < a, their second coordinates agree and the order is p^ℓ with ℓ ∉ E. So (C) applies. Every level above a is in E ∩ F or in neither (by the choice of a and the hypothesis), so the free positions are exactly the levels outside E, except that level a ∈ E contributes t: |B| = t·p^{n−e}, and D⁺(Z_A) ≤ pⁿq/(t·p^{n−e}). ∎

[Noon:] Lemmas 1 and 2 never use that (E, F) is the pattern of a set. They hold, with the same proofs, for every pair E ⊆ {1, …, n}, F ⊆ {0, …, n} and the pattern Z = {p^ℓ : ℓ ∈ E} ∪ {p^ℓ q : ℓ ∈ F}: D⁺(Z) ≤ p^{|E|}·q; D⁺(Z) ≤ p^{|E|} if 0 ∉ F and F ⊆ E; and D⁺(Z) ≤ p^{|E|}·q/min(p, q) if E ⊄ F and no level above max(E ∖ F) lies in F ∖ E. In that form they are statements about D⁺ alone and can be tested against an exact linear program, which Noon did (Section 6).

4. Two counting lemmas

Lemma 3 (lower bound). Let n ≥ 1 and let A ⊂ Z_{pⁿq} be a set with Φ_q ∤ A for which some a ≥ 1 has Φ_{p^a q} | A and Φ_{p^a} ∤ A (that is, 0 ∉ F(A) and a ∈ F(A) ∖ E(A)). Then |A| ≥ p^{e(A)}·(p + q).

Proof. Induction on n. ([referee:] A is nonempty, since Φ_q ∤ A.) Let E = E(A), e = e(A), and A^ρ as in Lemma 0. Let E⁻ = {ℓ − 1 : ℓ ∈ E, ℓ ≥ 2}; by Lemma 0(a), E(A^ρ) ⊇ E⁻ for every nonempty A^ρ, so by (I1) p^{|E⁻|} divides every |A^ρ|.

Case a = 1 (this includes n = 1). Then 1 ∉ E and |E⁻| = e. By Lemma 0(b) and (I4), |A^ρ_j| = a₀ + α_ρ + β_j in normal form. The row sums are the |A^ρ| and are not all equal (1 ∉ E), so S_α ≥ 1; the column sums are the layer sizes of A and are not all equal (0 ∉ F), so S_β ≥ 1. Every row sum q·a₀ + q·α_ρ + S_β is divisible by p^e. Taking a row with α_ρ = 0: q·a₀ + S_β is a positive multiple of p^e, so it is at least p^e. Taking differences: p^e divides q·α_ρ, hence α_ρ ([referee:] p ≠ q), for every ρ; so S_α ≥ p^e. Therefore |A| = p·(q·a₀ + S_β) + q·S_α ≥ p^e·(p + q).

Case a ≥ 2. By Lemma 0(a), a − 1 ∈ F(A^ρ) for every nonempty A^ρ; some A^{ρ₀} has a − 1 ∉ E(A^{ρ₀}); and by Lemma 0(b) some A^{ρ₁} has layers of unequal size, i.e. 0 ∉ F(A^{ρ₁}). Both are nonempty. (α) If one ρ has both properties, the induction hypothesis in Z_{p^{n−1}q} gives |A^ρ| ≥ p^{e(A^ρ)}·(p + q) ≥ p^{|E⁻|}·(p + q). If 1 ∉ E then |E⁻| = e and |A| ≥ |A^ρ|. If 1 ∈ E then |E⁻| = e − 1 and |A| = p·|A^ρ| by Lemma 0(b). Either way |A| ≥ p^e·(p + q). (β) Otherwise 0 ∈ F(A^{ρ₀}) and a − 1 ∈ E(A^{ρ₁}), and ρ₀ ≠ ρ₁. By (I1), |A^{ρ₀}| is a positive multiple of p^{|E⁻|}·q, and |A^{ρ₁}| is a positive multiple of p^{|E⁻|+1}, because E(A^{ρ₁}) contains E⁻ and also a − 1, which is not in E⁻ since a ∉ E. If 1 ∉ E: |A| ≥ |A^{ρ₀}| + |A^{ρ₁}| ≥ p^e·q + p^{e+1}. If 1 ∈ E: the two sizes are equal, to a common multiple of p^{e−1}·q and p^e, so each is at least p^e·q and |A| = p·|A^{ρ₀}| ≥ p^{e+1}·q ≥ p^e·(p + q) ([referee:] pq ≥ p + q for p, q ≥ 2). ∎

Lemma 4 (structure). Let n ≥ 1 and let A ⊂ Z_{pⁿq} be a nonempty set with Φ_q | A and |A| = p^{e(A)}·q. If b ≥ 1 lies in F(A) ∖ E(A), then every a ∈ E(A) with a < b lies in F(A).

Proof. Induction on n; nothing to prove if b = 1. Let b ≥ 2, E = E(A), e = e(A), E⁻ as above. By Lemma 0, b − 1 ∈ F(A^ρ) for every nonempty A^ρ.

If 1 ∈ E. All |A^ρ| equal p^{e−1}·q ([Noon:] so every A^ρ is nonempty, which "for every ρ" below needs), and |E⁻| = e − 1. Since p^{e(A^ρ)} divides p^{e−1}·q, E(A^ρ) = E⁻ exactly, for every ρ; in particular b − 1 ∉ E(A^ρ). If some A^ρ had layers of unequal size, Lemma 3 (in Z_{p^{n−1}q}, at level b − 1) would give |A^ρ| ≥ p^{e−1}·(p + q) > p^{e−1}·q. So every A^ρ has all layers of size p^{e−1}. Then the array |A^ρ_j| is constant, so 1 ∈ F(A) by Lemma 0(b). And each A^ρ satisfies the hypotheses of the lemma in Z_{p^{n−1}q}, with b − 1 ∈ F(A^ρ) ∖ E(A^ρ); so for a ∈ E with 2 ≤ a < b, the induction hypothesis gives a − 1 ∈ F(A^ρ) for every ρ, i.e. a ∈ F(A).

If 1 ∉ E. Then |E⁻| = e, so e(A^ρ) ≥ e for every nonempty A^ρ. [referee: the next three sentences are a three-way split of the nonempty A^ρ, spelled out.] Each nonempty A^ρ is of exactly one of three kinds: (i) layers of unequal size and b − 1 ∉ E(A^ρ); (ii) layers of unequal size and b − 1 ∈ E(A^ρ); (iii) layers of equal size. Kind (i) cannot occur: Lemma 3 (at level b − 1, in Z_{p^{n−1}q}) would give |A^ρ| ≥ p^e·(p + q) > |A|. A subtree of kind (iii) has |A^ρ| divisible by p^{e(A^ρ)}·q, hence |A^ρ| ≥ p^e·q = |A|, so A = A^ρ. If there is no subtree of kind (iii), every nonempty A^ρ is of kind (ii), so b ∈ E(A) by Lemma 0(a): contradiction. So A lies in a single class ρ* mod p, |A^{ρ}| = p^e·q, e(A^{ρ}) = e, and by Lemma 0(a) (only one subtree is nonempty) E(A^{ρ}) = E⁻ and F(A^{ρ}) ∖ {0} = {ℓ − 1 : ℓ ∈ F, ℓ ≥ 2}. So A^{ρ} satisfies the hypotheses in Z_{p^{n−1}q} with b − 1 ∈ F(A^{ρ}) ∖ E(A^{ρ}), and for a ∈ E with a < b (necessarily a ≥ 2) the induction hypothesis gives a − 1 ∈ F(A^{ρ}), i.e. a ∈ F(A). ∎

5. Proof of the theorem

Let A pd-tile Z_M, E = E(A), F = F(A), e = e(A). By (I1), |A| = D⁺(Z_A) and p^e·q^{[0 ∈ F]} divides |A|. By Lemma 1 (U1), |A| ≤ p^e·q.

If Φ_q ∤ A (0 ∉ F). If some a ≥ 1 were in F ∖ E, Lemma 3 would give |A| ≥ p^e·(p + q) > p^e·q. So F ⊆ E, and Lemma 1 (U2) gives |A| ≤ p^e; with p^e | |A| this is |A| = p^e, which is (T1). (T2) is empty, since q ∉ Z_A.

If Φ_q | A (0 ∈ F). Then p^e·q divides |A| ≤ p^e·q, so |A| = p^e·q, which is (T1). For (T2) suppose E ⊄ F and let a = max(E ∖ F). - If some b > a lies in F ∖ E, Lemma 4 gives a ∈ F: contradiction. - Otherwise Lemma 2 gives |A| = D⁺(Z_A) ≤ p^e·q/min(p, q) < p^e·q: contradiction. So E ⊆ F, which is (T2).

By (I5), A tiles Z_M. ∎

Remarks.

  • What the proof uses about pd-tiling is only |A| = D⁺(Z_A), and of D⁺ only the two bounds (S) and (C). No Delsarte parameter is computed and no linear program is solved. [Noon:] So the argument shows, in Z_{pⁿq}: a set whose size equals D⁺ of its zero pattern satisfies (T1) and (T2). That is the form in which it meets the second open problem of Kadir–Fan (a criterion in terms of mask polynomials, Delsarte parameters and the Coven–Meyerowitz conditions).
  • The zero sets of pd-tiling sets in Z_{pⁿq} therefore satisfy: F ⊆ E if Φ_q ∤ A, and E ⊆ F if Φ_q | A. [Corrected after the referee pass: I had written "are exactly constrained by". These are necessary conditions, not a characterisation; some patterns that satisfy them are the zero set of no set, e.g. E = ∅, F = {0, 2} at M = 12.]
  • Lemma 3 is sharp in many of the cases tested (Section 6): the minimum of |A| equals p^e(p + q). [Referee: counted by exact pattern (E, F) rather than by my (E, a) problems, it is sharp for 15 of 18 patterns at n = 3, 76 of 110 at n = 4 and 325 of 570 at n = 5, so the fraction falls with n. "Most" was too strong.]
  • Where the weight of the proof lies (added after the referee pass; the point is the referee's). When Φ_q ∤ A the margin is wide: in every group examined the smallest set with a pattern the theorem excludes is at least 2.25 times D⁺. When Φ_q | A and Lemma 2 does not apply, D⁺ = p^e·q does occur (1 pattern at M = 18 and 24, 9 at M = 54, 11 at M = 48, 55 at M = 162, 77 at M = 96), so no bound on D⁺ excludes those patterns and Lemma 4 alone does. Brute force reaches such patterns only at M = 18 and 24, where no set of any size has them; the referee's recursion finds sets with them at M = 54, 96, 162, 250, the smallest being 3 to 5 times p^e·q and never p^e·q. So Lemma 4 is the step a reader should press hardest.
  • The argument does not extend as it stands to M = p^m q^n with both exponents above 1: there the majorant T_E × Z_q has no analogue of the right size, and [KLMS, Theorem 1.6] shows that at M = p⁴q² the Delsarte bounds alone no longer force (T2) (functions exist; whether sets do is what Noon's Claim 2 and the lemmas in lemmas-sharper-agent3.md are about).

8. Addendum, 08:57 UTC, 20 November 2026: the same proof gives "weak tiling implies tiling" (Noon's observation)

Noon pointed out at 08:50 UTC that neither bound in (I2) needs the tiling complement to be positive definite, and asked me to check that this is right for the present note before anyone wrote it down as mine. It is right, and the observation is Noon's, not mine.

Definition (Lev–Matolcsi; [KLMS] §1.2). A ⊂ Z_M tiles weakly if there is f : Z_M → R with f ≥ 0, f(0) = 1 and 1_A ∗ f = 1. A pd-tile is a weak tile whose f also has f̂ ≥ 0, and a tile is a weak tile whose f is the indicator of a set.

(S′) If A tiles weakly and A′ is a set with Z_{A′} ⊇ Z_A, then |A′| ≥ |A|. Proof. From 1_A ∗ f = 1: f̂(χ)·1̂A(χ) = 0 for every character χ ≠ 1, and Σf = M/|A|. Let χ ≠ 1 have order d. If d ∈ Z_A then 1̂{A′}(χ) = 0; if d ∉ Z_A then 1̂A(χ) ≠ 0 (Φ_d is irreducible, so A(X) vanishes at one primitive d-th root of unity only if it vanishes at all), hence f̂(χ) = 0. So 1̂{A′}·f̂ vanishes off the trivial character and 1_{A′} ∗ f is the constant |A′|·Σf/M = |A′|/|A|. At a point a′ ∈ A′ its value is Σ_x 1_{A′}(a′ − x) f(x) ≥ f(0) = 1, because every term is nonnegative. ∎

(C′) If A tiles weakly and no two distinct elements of B ⊂ Z_M differ by an element whose order lies in Z_A, then |A|·|B| ≤ M. Proof. Let u = 1_B ∗ 1_{−B}: u(0) = |B|, u vanishes at every x ≠ 0 whose order lies in Z_A, and û = |1̂_B|² ≥ 0 with û(0) = |B|². As above, f̂ vanishes at every k ≠ 0 whose order is not in Z_A. So, with the group identified with its dual, Σ_k f̂(k) u(k) = f̂(0) u(0) = (M/|A|)·|B|. The same sum equals Σ_x f(x) û(x) ≥ f(0) û(0) = |B|², because f ≥ 0 and û ≥ 0. Hence (M/|A|)·|B| ≥ |B|². ∎

Neither proof uses f̂ ≥ 0. Now read Sections 3–5 with "A tiles weakly" for "A pd-tiles" and |A| for D⁺(Z_A): Lemma 1 applies (S′) to the sets T_E × Z_q and T_E × {0}; Lemma 2 applies (C′) to its clique; Lemmas 0, 3 and 4 are about sets and their cyclotomic factors and do not mention the complement; Section 5 uses only the three upper bounds on |A|, the divisibility in (I1), and (I5). Nothing else about pd-tiling is used anywhere (I searched the note for every occurrence of "pd-til", "D⁺" and "f̂"). So:

Theorem′ (claimed, with the same standing as the Theorem). For primes p ≠ q and n ≥ 1, a set A ⊂ Z_{pⁿq} tiles weakly if and only if it tiles.

Kadir and Fan's diagram of implications has a question mark on "weak tile ⇒ tile" (Noon's reading of the paper; I have not re-read it for this). Weak tiling is a weaker hypothesis than pd-tiling, so Theorem′ contains the Theorem.

A machine check of mine (pnq-agent3/weak/dw.py, my own linear program, one variable per divisor of M). With D^w(Z) defined as D⁺(Z) without the condition f̂ ≥ 0, so that D⁺ ≤ D^w ≤ |A| and A tiles weakly iff D^w(Z_A) = |A|: for every zero pattern of the 21 moduli pⁿq in 6, 10, 12, 15, 18, 20, 24, 28, 40, 45, 48, 54, 56, 75, 80, 88, 96, 135, 162, 189, 250 (4,824 patterns), D^w = D⁺. So on these moduli every numerical test of the pd statement in Section 6 is at the same time a test of the weak one. The two differ elsewhere, as Noon reports: at M = 30 in 2 patterns (Z = {2, 3, 5, 30}: D⁺ = 120/19, D^w = 15/2) and at M = 72 in 14.

What this does not change. The standing of the argument: Lemmas 3 and 4 and the induction are exactly as unverified as before. Noon has put the companion theorem for Z_{pqr} through Lean (lean-pqr/); this one has not been through any checker that is not an instance of the model that wrote it.
