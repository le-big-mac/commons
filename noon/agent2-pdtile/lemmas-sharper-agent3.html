Notation and Facts 1–4 are those of flatness.md, Section 6: p ≠ q primes, M = p⁴q², and N_{a,b}(r, t) is the number of elements of the set congruent to r mod p^a and to t mod q^b. By Fact 2, Φ_{p^a q^b} divides the mask polynomial exactly when every p × q array

(i, l)  ↦  N_{a,b}(r + i·p^{a−1}, t + l·q^{b−1})        (i ∈ Z_p, l ∈ Z_q)

has the form u(i) + w(l).

1. One more fact

Fact 5 (normal form). Let N be a p × q array of nonnegative integers with N(i, l) = u(i) + w(l) for some real u, w. Then N(i, l) = a + α_i + β_l with integers a ≥ 0, α_i ≥ 0, β_l ≥ 0 and min α = min β = 0. The sum of its entries is pq·a + q·Σα_i + p·Σβ_l, its row sums are q·a + q·α_i + Σβ, its column sums p·a + Σα + p·β_l.

Proof. Let i₀ minimise u and l₀ minimise w. Put a = N(i₀, l₀), α_i = N(i, l₀) − a = u(i) − u(i₀), β_l = N(i₀, l) − a = w(l) − w(l₀). ∎

I also use this triviality twice: if β, β′ ≥ 0 both have minimum 0 and β − c·β′ is constant for some c > 0, the constant is 0 (compare the minima).

2. Lemma A with four hypotheses, and what the sets look like

Lemma A⁺. Let p ≠ q be primes, M = p⁴q², A ⊂ Z_M, |A| = p²q, and suppose Φ_q, Φ_{p³q²} and Φ_{p²q²} divide A(X). Then for every j ∈ Z_q there are ρ_j ∈ Z_p and t_j ∈ Z_{q²} with t_j ≡ j (mod q) such that the elements of A congruent to j mod q are p² in number, all ≡ ρ_j (mod p), all ≡ t_j (mod q²), and one in each of the p² classes mod p³ that lie over ρ_j. Consequently A(X) is divisible by neither Φ_{p⁴} nor Φ_p. In particular A(X) is not divisible by all of Φ_q, Φ_{p⁴}, Φ_{p³q²}, Φ_{p²q²}.

Proof. Fix j. By Fact 1 for q, exactly p² elements of A are ≡ j (mod q).

Step 1. For each c ∈ {0, …, p² − 1}, Fact 2 at p³q² and Fact 5 give a normal form

N_{3,2}(c + i·p², j + l·q) = a_c + α^c_i + β^c_l        (i ∈ Z_p, l ∈ Z_q).

Write A_c = Σ_i α^c_i and B_c = Σ_l β^c_l.

Step 2. Summing over i, N_{2,2}(c, j + l·q) = p·a_c + A_c + p·β^c_l. By Fact 2 at p²q², if c ≡ c₂ (mod p) then N_{2,2}(c, j + l·q) − N_{2,2}(c₂, j + l·q) does not depend on l; so β^c − β^{c₂} is constant, hence zero. So β^c depends only on c mod p, and Σ_c B_c = p·b, where b is the sum of B_{c′} over one representative c′ of each class mod p.

Step 3. Count the class: p² = Σ_c (pq·a_c + q·A_c + p·B_c) = q·(p·Σa_c + ΣA_c) + p²·b. So b ≤ 1. If b = 0 then q divides p², which is false. So b = 1 and p·Σa_c + ΣA_c = 0: every a_c and every α^c_i vanishes, and exactly one β^{c′}l equals 1, say for c′ = ρ_j and l = l_j, the rest being 0. With t_j = j + l_j·q: N{3,2}(r, t) = 1 if r ≡ ρ_j (mod p) and t = t_j, and N_{3,2}(r, t) = 0 for all other (r, t) with t ≡ j (mod q). That is the structure claimed.

Step 4. So N_{3,0}(r) = #{j ∈ Z_q : ρ_j ≡ r (mod p)} =: n(r mod p), and Σ_{ρ ∈ Z_p} n(ρ) = q. If Φ_{p⁴} divided A(X), Fact 1 would give N_{3,0}(r) = p·N_{4,0}(r) ∈ pZ, so p | q. If Φ_p divided A(X), Fact 1 would make N_{1,0}(ρ) = p²·n(ρ) the same for all ρ, so p·n = q, again p | q. ∎

Remarks.

  • The converse of the structure statement holds too (on each box at level (3,2) and at level (2,2) the count depends on l only), so this is a complete description: the sets of p²q elements with Φ_q, Φ_{p³q²}, Φ_{p²q²} are exactly those made by choosing, for each j, a class ρ_j mod p, a lift t_j of j to Z_{q²}, and one element ≡ t_j (mod q²) in each class mod p³ over ρ_j (free choice of the lift to Z_{p⁴}).
  • No condition between p and q is used beyond p ≠ q. (My first version, in the referee report's Section 2, remark 4, needed p < q and kept Φ_{p³q}; this supersedes it.)
  • Lemma A of flatness.md follows, since its divisors include these four. (Wording corrected after the referee pass: I had written "its six divisors"; the lemma had six in the version I refereed and has five since Noon's revision.)

3. Lemma B with four hypotheses, three ways

Lemma B⁺. Let p ≠ q be primes, M = p⁴q², B ⊂ Z_M, |B| = p²q. Then B(X) is not divisible by all of

  • (B1) Φ_{p²}, Φ_{p³}, Φ_{q²}, Φ_{pq}; nor by all of
  • (B2) Φ_{p²}, Φ_{p³}, Φ_{pq}, Φ_{pq²}; nor by all of
  • (B3) Φ_{p³}, Φ_{q²}, Φ_{pq}, Φ_{p²q}.

Proof. In each case Φ_{pq} divides B(X), so by Fact 2 and Fact 5

N_{1,1}(ρ, j) = a + α_ρ + β_j   in normal form  (ρ ∈ Z_p, j ∈ Z_q),      pq·a + q·S_α + p·S_β = p²q,   (∗)

where S_α = Σα_ρ and S_β = Σβ_j. The row sums are N_{1,0}(ρ) = q·a + q·α_ρ + S_β and the column sums are N_{0,1}(j) = p·a + S_α + p·β_j.

(B1) and (B2). Φ_{p²} and Φ_{p³} give N_{1,0}(ρ) = p·N_{2,0} = p²·N_{3,0} ∈ p²Z (Fact 1 twice). Two rows differ by q·(α_ρ − α_ρ′) ∈ p²Z, so every α_ρ is a multiple of p² ([referee:] because p and q are coprime and the smallest α_ρ is 0; the same two facts are used for β in (B3)). If S_α = 0, all rows are equal, so N_{1,0}(ρ) = pq for every ρ, which is not a multiple of p². Contradiction. If S_α > 0 then S_α ≥ p², and (∗) forces S_α = p², a = 0, S_β = 0: one class ρ₀ mod p holds all of B, with p² elements in each class mod q. Under (B1): Φ_{q²} gives N_{0,1}(j) = q·N_{0,2} ∈ qZ, but N_{0,1}(j) = p². Contradiction. Under (B2): translate so that B = pB′ with B′ ⊂ Z_{p³q²} ([referee:] a translation multiplies B(X) by a power of X modulo X^M − 1 and so keeps every Φ_d | B, d | M). By Fact 3 with p and q exchanged, B′ is divisible by Φ_p (from Φ_{p²}), Φ_{p²} (from Φ_{p³}), Φ_q (from Φ_{pq}) and Φ_{q²} (from Φ_{pq²}). By Fact 4, p²q² divides |B′| = p²q. Contradiction.

(B3). Φ_{q²} gives N_{0,1}(j) ∈ qZ; two columns differ by p·(β_j − β_j′), so every β_j is a multiple of q. By Fact 2 at p²q (where b = 1, so the box is {ρ + ip} × Z_q) and Fact 5, for each ρ write N_{2,1}(ρ + i·p, j) = a^ρ + α^ρ_i + β^ρ_j in normal form. Summing over i, N_{1,1}(ρ, j) = p·a^ρ + Σ_i α^ρ_i + p·β^ρ_j. Comparing with N_{1,1}(ρ, j) = a + α_ρ + β_j, the difference β_j − p·β^ρ_j does not depend on j, hence is zero. So every β_j is a multiple of p as well, hence of pq. If S_β = 0, all columns are equal, N_{0,1}(j) = p², not a multiple of q. Contradiction. If S_β > 0 then S_β ≥ pq, and (∗) forces S_β = pq, a = 0, S_α = 0: all of B lies in one class mod q. Translate so that B = qB′ with B′ ⊂ Z_{p⁴q}. By Fact 3, B′ is divisible by Φ_{p³} (unchanged), Φ_q (from Φ_{q²}), Φ_p (from Φ_{pq}) and Φ_{p²} (from Φ_{p²q}). By Fact 4, p³q divides |B′| = p²q. Contradiction. ∎

Remarks.

  • Lemma B of flatness.md follows from any one of the three. Its two hypotheses that the solver found indispensable, Φ_{p³} and Φ_{pq}, are the two common to B1, B2 and B3.
  • (B1) is the plainest: three prime-power divisors, which already use up |B| = p²q in the sense of Fact 4, and then Φ_{pq} is one divisor too many. Its proof needs neither Fact 3 nor a translation.

5. If this survives checking, what it changes in flatness.md

  • Claim 2 can be stated with four divisors on each side (and for the second, any of three fours). The Corollary is unchanged: the two zero lists of [KLMS, Theorem 1.6] contain {q, p⁴, p³q², p²q²} and all of B1, B2, B3.
  • "So the hypotheses as stated are not minimal" can become a statement of which ones are.
  • The proof of Lemma A drops from four steps to one count, and gives more: all sets with the three mixed divisibilities, not only the absence of one with a fourth.
  • For the Corollary, part (i), A⁺ says a little more than needed: a set with Φ_q, Φ_{p³q²}, Φ_{p²q²} cannot have Φ_p either, and the function f of [KLMS] has all of p, q, p⁴, p³q², p²q² among its zeros.

What I have not done: found out whether any of this is in the literature. Fact 2 is a form of the standard cuboid test for cyclotomic divisibility ([KLMS], Section 3, recall it and attribute it to Steinberger and, later, to Łaba and Londner), and counting arguments of this size about M = p^α q^β may well be known to the people who work on it.

A fresh instance of the same model, own code, none of mine (p2q-agent3/referee/, files sharper_*).

  • No wrong step in Fact 5, the "compare the minima" remark, Lemma A⁺ Steps 1–4, or B1, B2, B3; each re-derived before reading my justification.

The middle steps of B⁺ likewise for ten prime pairs. With a solver at (2,3), (3,2), (2,5): B1, B2, B3 infeasible; every maximal subset of Lemma B's six divisors containing none of them has a set (verified exactly); A⁺'s four each necessary. One gap in its own evidence, which it states: adding Φ_{p⁴} at (2,5) got no answer from the solver in 40 seconds.
