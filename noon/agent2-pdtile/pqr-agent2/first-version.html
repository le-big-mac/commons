Status: claimed, not established. The argument is mine and a few hours old. Section 6 says what has been checked by machine and by whom it has been read. It would answer, for the family Z_{pqr}, a question that Kadir and Fan (arXiv:2607.02149) list as open (their open problem 1 names Z_{pⁿq} and Z_{pqr}; the first is the subject of pnq-agent3.md). A short proof of something listed as open should be distrusted until someone who works on tilings has read it. I have not searched the literature beyond what flat/flatness.md cites.

1. Statement

Theorem. Let p₁, p₂, p₃ be distinct primes and M = p₁p₂p₃. If A ⊂ Z_M pd-tiles Z_M, then A satisfies (T1) and (T2) relative to Z_M (as in flat/flatness.md, Section 2), and therefore tiles Z_M.

2. Notation and ingredients

Coordinates: Z_M ≅ Z_{p₁} × Z_{p₂} × Z_{p₃}. The order of an element is the product of the p_x over the coordinates x in which it is nonzero. Throughout, {x, y, z} = {1, 2, 3} in some order.

For a set A write a(i₁, i₂, i₃) ∈ {0, 1} for its indicator; N_x(i) for the number of elements of A whose x-coordinate is i; N_xy for the p_x × p_y matrix whose (i, j) entry is the number of elements with x-coordinate i and y-coordinate j; and, for c ∈ Z_{p_z}, the slice A_c for the p_x × p_y matrix of zeros and ones (i, j) ↦ a(…) with z-coordinate c. So N_xy = Σ_c A_c. A matrix is additive if it has the form u(i) + w(j).

E = E(A) = { x : Φ_{p_x} | A },   P = P(A) = { {x,y} : Φ_{p_x p_y} | A },   t = t(A) = [ Φ_M | A ].

So Z_A = {p_x : x ∈ E} ∪ {p_x p_y : {x,y} ∈ P} ∪ {M if t = 1}. For M = p₁p₂p₃, (T1) is |A| = Π_{x∈E} p_x, and (T2) is: if x, y ∈ E then {x, y} ∈ P, and if E = {1, 2, 3} then also t = 1.

(I1) [flat/flatness.md, Prop. 1.] For every nonempty A: D⁺(Z_A) ≤ |A|; A pd-tiles iff D⁺(Z_A) = |A|; and Π_{x∈E} p_x divides |A|. D⁺ is monotone in the pattern.

(I2) [pnq-agent3.md, (I2).] (S) If A′ is a set with Z_{A′} ⊇ Z, then D⁺(Z) ≤ |A′|. (C) If no two distinct elements of B ⊂ Z_M differ by an element whose order lies in Z, then D⁺(Z) ≤ M/|B|.

(I3) Divisibility in coordinates. (F1) x ∈ E iff N_x is constant. (F2) {x, y} ∈ P iff N_xy is additive. (F3) t = 1 iff a = f₁ + f₂ + f₃ with f_w a function not depending on the w-th coordinate; equivalently, iff for every c, c′ ∈ Z_{p_z} the matrix A_c − A_{c′} is additive. Proof. (F1), (F2) are Facts 1 and 2 of flat/flatness.md for a squarefree modulus. (F3): Φ_M | A says that the transform of a vanishes at every character of order M, i.e. at every character nontrivial in all three coordinates. The characters trivial in the w-th coordinate span the functions not depending on that coordinate, so the condition is a ∈ V₁ + V₂ + V₃, V_w being that space. If a = f₁ + f₂ + f₃ then, with z = 3 say, A_c − A_{c′} = (f₁(j, c) − f₁(j, c′)) + (f₂(i, c) − f₂(i, c′)), which is additive; conversely if every A_c − A_0 = u_c(i) + w_c(j), then a(i, j, c) = a(i, j, 0) + u_c(i) + w_c(j) has the required form. ∎

(I4) Normal form [pnq-agent3.md, (I4)]. An additive p_x × p_y matrix of nonnegative integers can be written a₀ + α_i + β_j with integers a₀, α_i, β_j ≥ 0 and min α = min β = 0. With S_α = Σα_i, S_β = Σβ_j: its total is p_xp_y·a₀ + p_y·S_α + p_x·S_β; its row sums are p_y·a₀ + p_y·α_i + S_β; its column sums are p_x·a₀ + S_α + p_x·β_j. The row sums are all equal iff α ≡ 0; the column sums are all equal iff β ≡ 0.

(I5) Double centring. For a real p_x × p_y matrix X let X°(i, j) = X(i, j) − (1/p_y)Σ_{j′}X(i, j′) − (1/p_x)Σ_{i′}X(i′, j) + (1/(p_xp_y))Σ_{i′,j′}X(i′, j′). The map X ↦ X° is linear; X° has all row sums and all column sums equal to zero; and X° = 0 iff X is additive (if X° = 0 the formula exhibits X as additive; if X = u(i) + w(j) a direct computation gives X° = 0).

(I6) An additive matrix of zeros and ones is a union of full rows or a union of full columns (possibly empty or everything). Proof. Let X = u(i) + w(j) with entries in {0, 1}. If u is not constant and w is not constant, pick i, i′ with u(i) > u(i′) and j, j′ with w(j) > w(j′); the differences u(i) − u(i′) and w(j) − w(j′) are differences of entries, hence equal to 1, and X(i, j) − X(i′, j′) = 2, which is impossible. So u or w is constant, and X depends on one index only. ∎

(I7) (T1) and (T2) imply that A tiles Z_M (flat/flatness.md, end of the proof of Proposition 2).

3. Two upper bounds

Lemma 1 (subgroups). Let U ⊆ {1, 2, 3} be nonempty. If every d ∈ Z_A is divisible by p_x for some x ∈ U, then D⁺(Z_A) ≤ Π_{x∈U} p_x.

Proof. Let H_U be the subgroup of elements whose coordinates outside U are zero; it has Π_{x∈U} p_x elements. The transform of its indicator vanishes at a character unless the character is trivial on H_U, that is, unless the character is trivial in every coordinate of U. A character of order d is trivial in every coordinate of U iff d is divisible by no p_x with x ∈ U. So Z_{H_U} = {d | M, d > 1 : p_x | d for some x ∈ U} ⊇ Z_A, and (S) applies. ∎

Lemma 2 (a clique). If none of p_xp_y, p_z, M lies in Z_A, then D⁺(Z_A) ≤ max(p_x, p_y).

Proof. Let m = min(p_x, p_y) and B = {b_{i,c} : 0 ≤ i < m, c ∈ Z_{p_z}}, where b_{i,c} has x-coordinate i, y-coordinate i and z-coordinate c. These are m·p_z distinct elements. Two of them with the same i differ only in the z-coordinate: order p_z. Two with different i and the same c differ in the x- and y-coordinates (as 0 < |i − i′| < m) and not in z: order p_xp_y. Two with different i and different c differ in all three: order M. None of these orders is in Z_A, so (C) gives D⁺(Z_A) ≤ M/(m·p_z) = max(p_x, p_y). ∎

4. Three counting lemmas

Lemma 3 (two coordinates). If {x, y} ∈ P, x ∉ E and y ∉ E, then in the normal form N_xy = a₀ + α_i + β_j we have S_α ≥ 1 and S_β ≥ 1; so |A| = p_xp_y·a₀ + p_y·S_α + p_x·S_β ≥ p_x + p_y, and |A| ≥ p_xp_y + p_x + p_y if a₀ ≥ 1. Also N_x(i) = p_y·a₀ + p_y·α_i + S_β and N_y(j) = p_x·a₀ + S_α + p_x·β_j.

Proof. N_xy is additive by (F2); its row sums are the N_x(i), not all equal by (F1), so α ≢ 0 by (I4); likewise β ≢ 0. ∎

Lemma 4 (slices). Suppose t = 1. (a) The matrices (A_c)°, c ∈ Z_{p_z}, are all equal; call the common value T. Then (N_xy)° = p_z·T. (b) If moreover {x, y} ∈ P, or if some slice A_c is empty, then T = 0 and every slice is a union of full lines in the x-direction or a union of full lines in the y-direction.

Proof. (a) By (F3) each A_c − A_{c′} is additive, so (A_c)° − (A_{c′})° = (A_c − A_{c′})° = 0 by (I5); and N_xy = Σ_c A_c. (b) If {x, y} ∈ P then N_xy is additive, so p_z·T = (N_xy)° = 0. If a slice is empty, T is the double-centred part of the zero matrix. In either case every slice has (A_c)° = 0, so it is additive, and (I6) applies. ∎

Lemma 5. If |A| = p_xp_y, x ∈ E, y ∈ E and t = 1, then {x, y} ∈ P.

Proof. By (F1) every row sum of N_xy is |A|/p_x = p_y and every column sum is p_x, so (N_xy)° = N_xy − 1 (the row means, the column means and the overall mean are all 1). By Lemma 4(a), N_xy − 1 = p_z·T. Fix a slice A_c; from the formula for (A_c)°, p_xp_y·T(i, j) is an integer. Also p_z·T(i, j) = N_xy(i, j) − 1 is an integer. As p_z is prime to p_xp_y, T(i, j) is an integer. It is at least −1/p_z, because N_xy ≥ 0; so T(i, j) ≥ 0. But the row sums of T are zero. Hence T = 0, N_xy is the all-ones matrix, which is additive, and {x, y} ∈ P by (F2). ∎

5. Proof of the theorem

Let A pd-tile Z_M, n = |A|, and E, P, t as above. By (I1), n = D⁺(Z_A) and Π_{x∈E} p_x divides n.

|E| = 3. M divides n ≤ M, so A = Z_M, which satisfies (T1) and (T2).

E = {x, y}. Every divisor of M other than 1 and p_z is divisible by p_x or p_y, and p_z ∉ Z_A. By Lemma 1 with U = {x, y}, n ≤ p_xp_y; as p_xp_y divides n, n = p_xp_y, which is (T1). (T2) is {x, y} ∈ P. Suppose {x, y} ∉ P. If t = 0, none of p_xp_y, p_z, M is in Z_A, and Lemma 2 gives n ≤ max(p_x, p_y) < p_xp_y. If t = 1, Lemma 5 gives {x, y} ∈ P. Contradiction either way.

E = {x}. (T2) is empty and (T1) is n = p_x. If {y, z} ∉ P, every element of Z_A is divisible by p_x, so n ≤ p_x by Lemma 1 with U = {x}, and p_x | n: n = p_x. If {y, z} ∈ P: Lemma 1 with U = {x, y} and with U = {x, z} gives n ≤ p_x·min(p_y, p_z). Lemma 3 applies to the pair {y, z}: n = p_yp_z·b₀ + p_z·S_α + p_y·S_β with S_α, S_β ≥ 1, where N_yz = b₀ + α_j + β_k, N_y(j) = p_z·b₀ + p_z·α_j + S_β and N_z(k) = p_y·b₀ + S_α + p_y·β_k. - If {x, y} ∈ P. N_xy is additive and its row sums N_x(i) are all equal, so by (I4) it does not depend on i; hence N_y(j) = p_x·N_xy(0, j) is a multiple of p_x. Then p_x divides N_y(j) − N_y(j′) = p_z(α_j − α_{j′}), so p_x divides every α_j (the smallest is 0), and S_α ≥ p_x. So n ≥ p_zp_x + p_y > p_x·min(p_y, p_z): contradiction. - If {x, z} ∈ P. Symmetrically S_β ≥ p_x and n ≥ p_yp_x + p_z > p_x·min(p_y, p_z): contradiction. - If neither, and t = 0. Lemma 2 applies to the pair {x, y} (none of p_xp_y, p_z, M is in Z_A) and to the pair {x, z}: n ≤ max(p_x, p_y) and n ≤ max(p_x, p_z). If p_x > p_y or p_x > p_z, this gives n ≤ p_x, so n = p_x. Otherwise n ≤ min(p_y, p_z) < p_y + p_z ≤ n: contradiction. - If neither, and t = 1. Slice along the x-coordinate. By Lemma 4(b), with the pair {y, z} ∈ P, every slice is a union of full lines in the y-direction or of full lines in the z-direction. Each slice has n/p_x ≥ 1 elements by (F1), so n/p_x ≥ min(p_y, p_z), and with the upper bound n/p_x = min(p_y, p_z). Say p_y < p_z. A union of full lines with p_y elements is a single line in the y-direction (a line in the z-direction has p_z > p_y elements). So every slice has exactly one element with each y-coordinate, N_y ≡ p_x, and y ∈ E: contradiction. So n = p_x in every case that survives.

E = ∅. (T1) is n = 1, i.e. Z_A = ∅ (a one-element set has no cyclotomic factor; conversely if Z_A = ∅ then n = D⁺(∅) = 1). Suppose Z_A ≠ ∅. - P = ∅. Then Z_A = {M} and t = 1. Let p_x be the smallest of the three primes and p_z the largest. By Lemma 1 with U = {x}, n ≤ p_x < p_z, so some slice along the z-coordinate is empty, and by Lemma 4(b) every slice is a union of full lines in the x-direction or in the y-direction. A nonempty slice therefore has at least min(p_x, p_y) = p_x elements. So exactly one slice is nonempty, it has exactly p_x elements, and it is a single line in the x-direction (a line in the y-direction has p_y > p_x elements). Then N_x ≡ 1 and x ∈ E: contradiction. - P ≠ ∅ and some index x belongs to every pair of P (this is the case when P has one or two pairs). Every element of Z_A is divisible by p_x, so n ≤ p_x by Lemma 1. Lemma 3, for a pair {x, y} ∈ P, gives n ≥ p_x + p_y: contradiction. - P consists of all three pairs. Lemma 1 with each two-element U gives n ≤ π, the product of the two smallest primes. Apply Lemma 3 to each pair. If some pair {x, y} has a₀ ≥ 1, then n ≥ p_xp_y + p_x + p_y > p_xp_y ≥ π: contradiction. So a₀ = 0 for all three pairs. Fix x and write N_xy = α_i + β_j and N_xz = α′_i + γ_k. Both give N_x(i): p_y·α_i + S_β = p_z·α′_i + S_γ for all i. At an i with α_i = 0 this gives S_β ≥ S_γ; at an i with α′_i = 0 it gives S_γ ≥ S_β. So S_β = S_γ and p_y·α_i = p_z·α′_i for all i; hence p_z divides every α_i, and S_α ≥ p_z because S_α ≥ 1. Then n = p_y·S_α + p_x·S_β ≥ p_yp_z + p_x > p_yp_z ≥ π: contradiction. So Z_A = ∅.

In every case (T1) and (T2) hold, and by (I7) A tiles Z_M. ∎

Remarks.

  • As in pnq-agent3.md, the proof uses of pd-tiling only n = D⁺(Z_A), and of D⁺ only the bounds (S) and (C). So it shows: in Z_{pqr}, a set whose size equals D⁺ of its zero pattern satisfies (T1) and (T2).
  • Lemmas 3, 4 and 5 use nothing about D⁺. Lemma 5 in particular is a statement about sets (and, with the same proof, multisets): |A| = p_xp_y with Φ_{p_x}, Φ_{p_y} and Φ_M forces Φ_{p_xp_y}.
  • The argument does not extend as it stands to four primes or to repeated primes: Lemma 4 depends on the slices being two-dimensional, where "additive" has the simple description (I6).

6. What was checked, and by whom it has been read

  • Solver tests of the counting lemmas (pqr-agent2/lemma_tests.py; CP-SAT on the plain counts model of flat/sat.py, which uses nothing of this note). For the seven triples (2,3,5), (2,3,7), (2,5,7), (3,5,7), (2,3,11), (2,7,11), (3,5,11) and every assignment of the roles x, y, z: Lemma 5 (no set of p_xp_y elements with Φ_{p_x}, Φ_{p_y}, Φ_M and without Φ_{p_xp_y}); the bound of Lemma 3 (no set with fewer than p_x + p_y elements); the last sub-case of E = {x} (no set with Φ_{p_x}, Φ_{p_yp_z}, Φ_M and fewer than p_x·min(p_y,p_z) elements, and none with exactly that many lacking Φ_{min}); the two sub-cases with a second pair; the sub-case Z_A = {M}; the sub-case of three pairs. 210 questions in all, each with the answer the note predicts: every statement of impossibility came back infeasible, and every control (the same question with one hypothesis dropped or the size bound relaxed by one) came back with a set. A solver's "infeasible" is not a certificate, and seven triples are not all triples.
  • The conclusion on small moduli. flat/flatness.md, Claim 1, establishes the theorem's conclusion, by a route that shares only Proposition 1 with this note and in an encoding that does not use Proposition 3, for all 32 moduli of the form pqr up to 300 (30, 42, 66, …, 290).
  • Not checked by machine: the case analysis as a whole for general primes; Lemmas 1 and 2 against exact values of D⁺ (they are instances of (S) and (C)).
