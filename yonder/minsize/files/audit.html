The claim to be audited

For primes p ≠ q and n ≥ 0, and a multiset A on the cyclic group Z_M, M = pⁿq, with mask polynomial A(X) = Σ (multiplicity of a)·X^a, the "pattern" of A is the set of d | M, d > 1, such that the cyclotomic polynomial Φ_d divides A(X). The divisors d > 1 of M are p^ℓ (1 ≤ ℓ ≤ n), q, and p^ℓ·q (1 ≤ ℓ ≤ n). Write E = {ℓ : Φ_{p^ℓ} | A}, F = {ℓ ≥ 1 : Φ_{p^ℓ q} | A}, and say whether Φ_q | A. The note (/srv/commons/agent2-pdtile/minsize-agent3/README.md: read "In short" and sections 1, 2 and 3; in the note level 0 of F means Φ_q | A) claims a formula for the least size of a nonempty multiset with EXACTLY a given pattern, for every pattern:

  • Φ_q ∤ A: p^|E| if F ⊆ E, and p^|E|·(p^|F∖E| + q) otherwise.
  • Φ_q | A and F = all of 1..n: q·p^|E|.
  • Φ_q | A and a₀ the first level in 1..n not in F: q·p^|E|·(p^k′ + x), with k′ the number of levels beyond a₀ in F and not in E, and x = 0 if one of four clauses holds (see the note's section 3) and x = 1 otherwise.

The Lean statements said to express this are the three theorems minsize_unbalanced_zmod, minsize_balanced_all_zmod, minsize_balanced_zmod in Pnq/MinGroup.lean, with the definitions they rest on: maskW (in Pnq/Weighted.lean), levelsEW, levelsFW (Pnq/MinGroup.lean), gOf, xOf, minU, minB (Pnq/Rule.lean). Copies for reading are in /srv/commons/agent2-pdtile/minsize-agent3/lean-min/ together with a log (lean-min-26nov-agent3.log) that prints the definitions and statements as Lean elaborates them. A private copy of the whole built project for you to run things in is ~/lean/min-audit/ (Lean 4 with Mathlib, already built).

1. Literal reading

Lean notions, as elaborated (lean/AuditPrint.out, with pp.all): - [Fact p.Prime] [Fact q.Prime], hpq : p ≠ q: p and q are distinct primes. - ZMod (p ^ n * q): the integers mod M = pⁿq. M ≥ 2, so it is finite with M elements; finiteness comes from the instance NeZero (p ^ n * q) of Pnq/Group.lean (a proposition). - w : ZMod M → ℕ: a multiplicity for each residue, i.e. a finite multiset. ∑ a, w a is its number of elements. - a.val: the representative of a in [0, M). - maskW w = ∑ a, C (w a : ℤ) * X ^ a.val: the polynomial in ℤ[X] whose coefficient at X^k is w(k) for k < M and 0 for k ≥ M (proved: Audit.maskW_coeff). - Polynomial.cyclotomic d ℤ ∣ maskW w: divisibility in ℤ[X] by Mathlib's Φ_d. I proved it equivalent to ∑ w(a)·e^{2πi·a/d} = 0 (Audit.cyclotomic_dvd_maskW_iff), the usual meaning. - Finset.Icc 1 n: {1, …, n}, empty for n = 0. - Finset.filter under open Classical: ℓ is in the result iff ℓ ∈ {1..n} and the divisibility holds; the classical decidability instance does not affect membership. - IsLeast S m: m ∈ S and m ≤ s for every s ∈ S, so each theorem also asserts that some multiset has the pattern. - {s | ∃ w, …}: the set of sizes of the multisets satisfying the conditions. - \ is set difference and .card the number of elements. No natural-number subtraction or division occurs in any of the seven definitions or three statements. - The if in xOf and minU is decided by the standard instances (instDecidableOr, instDecidableAnd, Finset.decidableEq, Finset.decidableMem, Finset.instDecidableLE, Nat.decLe, and the two finset quantifier instances).

Definitions. - levelsEW w = {ℓ ∈ 1..n : Φ_{p^ℓ} | A}. - levelsFW w = {ℓ ∈ 1..n : Φ_{p^ℓ q} | A}. - gOf Es Fs a0 = {ℓ ∈ Fs∖Es : a0 < ℓ}. - minU p q Es Fs = p^|Es| if Fs ⊆ Es, else p^|Es|·(p^|Fs∖Es| + q). - minB p q Es Fs a0 = q·p^|Es|·(p^|gOf| + xOf). - xOf p Es Fs a0 = 0 if one of four clauses holds, else 1: 1. gOf = ∅; 2. some ℓ ∈ Es has ℓ < a0; 3. a0 ∈ Es and 3 ≤ p; 4. a0 ∈ Es, p = 2, and some b ∈ Es∖Fs has a0 < b and b < g for every g ∈ gOf.

Clause by clause against the note's section 3. - (1) is k′ = 0. - (2) is the same, because Es ⊆ 1..n. - (3) is the same; for a prime p, exactly one of 3 ≤ p and p = 2 holds. - (4): when gOf is not empty, "b < every g" is "b < the first level of F∖E beyond a₀", and b > a0 is strict, so b = a0 does not count. When gOf is empty the coded clause can hold where the note's has no meaning, but clause (1) already gives x = 0.

Theorems. For distinct primes p, q, any n ≥ 0, and Es, Fs ⊆ {1..n}: - minsize_unbalanced_zmod: minU p q Es Fs is the least size of a multiset with Φ_q ∤ A, Φ_{p^ℓ} | A exactly for ℓ ∈ Es and Φ_{p^ℓ q} | A exactly for ℓ ∈ Fs (ℓ over 1..n). - minsize_balanced_all_zmod: q * p ^ Es.card is the least positive size with Φ_q | A, E exactly Es, and every level of 1..n in F. - minsize_balanced_zmod: given a0 with 1 ≤ a0 ≤ n, every ℓ in [1, a0) in Fs and a0 ∉ Fs, minB p q Es Fs a0 is the least size with Φ_q | A and E, F exactly Es, Fs.

The points you asked about. - Exactness. levelsEW w = Es with Es ⊆ 1..n is exactly "for every ℓ in 1..n, Φ_{p^ℓ} | A iff ℓ ∈ Es" (Audit.levelsEW_eq_iff, likewise for F). It says nothing about ℓ outside 1..n, and Φ_{p^0·q} = Φ_q never enters through levelsFW. Every divisor d > 1 of M is constrained and no other polynomial appears. My script asserts, for each of 28 triples (p, q, n), that (Φ_q or not, E, F) runs over every subset of the divisors > 1 exactly once. - Coverage. The a0 hypotheses hold for exactly one number when Fs ≠ 1..n and for none when Fs = 1..n (Audit.a0_unique, Audit.a0_exists), so the third theorem cannot be applied with a wrong a0. The three cover every pattern exactly once (Audit.every_pattern, derived from the three theorems, with "not empty" in every case and without levelsEW/levelsFW). - Empty multiset. Its mask is 0, so its pattern is "everything" (Audit.empty_pattern). It is excluded by 0 < s in the second theorem and by the pattern itself in the first and third. - n = 0. Es = Fs = ∅ is forced; the first theorem gives 1, the second q, and the third has no instance. That is right, and matches Z_2, Z_3, Z_5. - Exponents in [0, M). Harmless: Φ_d | X^M − 1 for d | M. Translating a multiset left the pattern unchanged in 41,259 multisets I divided by hand-written long division. - Hypotheses. None is stronger than needed in a way that excludes part of the claim, and none makes a theorem vacuous. I instantiated Z_12, E = {1}, F = {2}, Φ_3 | A, giving 18.

Meaning-changing constructs (your item 2). - The eleven files contain no instance, notation, macro, syntax, attribute, @[…], set_option or local/scoped line. They have only open Finset, two open Classical in, variable lines and namespaces. - Walking the three statements and the bodies of every project definition they reach (lean/AuditModules.out) gives 11 project constants: the three theorems, the seven definitions, and the NeZero instance. 3. Brute force

Method. - Cyclotomic polynomials come from my own long division (cyc.py), checked against sympy for n ≤ 200 and against ∏{d|n} Φ_d = Xⁿ − 1. - Plain (enumA.c): every multiset up to the size bound, no symmetry used. The pattern comes from remainders mod each Φ_d; the count at each size equals C(M+s−1, s). On 60,088 small multisets the tallies equal one-by-one long division (crosscheck_longdiv.out). - Per pattern (enumB.c): for each pattern P, every multiset of size ≤ Lean's value with all of P dividing. The low coefficients are forced by the high ones modulo ∏{d∈P} Φ_d. This finds the least size if it is ≤ Lean's value, and otherwise shows none exists that small. - Every least-size witness was divided again in Python. - The two programs agree on the number of multisets containing each pattern at each common size: 6,111 comparisons, none bad. - Where the full per-pattern list was too large I used a "window bound": some translate has at most ⌊s(M−D)/M⌋ elements in the high part. It rests on translation invariance and gave the same answers on all 262 patterns run both ways.

Lean's values are from #eval (lean/AuditEval.lean → lean-values.txt), with a0 found by search and the theorem's hypotheses decided true by Lean on every row.
